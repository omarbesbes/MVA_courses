8. What to remember

Summary
  • A language model writes one token per pass, but one pass scores every position of a sequence. Checking a draft of $\ga$ tokens costs about one pass.
  • Greedy case: keep the longest prefix of the draft that matches the target's argmax, then write the target's token. Same text as the target alone.
  • Sampling case: keep a drafted token $x$ with probability $\min(1,p(x)/q(x))$; after a rejection, draw from the residual $\pos{p-q}$ renormalised. The output is an exact sample of $p$.
  • The draft is kept with probability $\be=\sum_v\min(p(v),q(v))=1-\TV(p,q)$, and no exact rule keeps it more often: the rule is a maximal coupling.
  • With acceptance rate $\al$ and draft length $\ga$, a round gives $\frac{1-\al^{\ga+1}}{1-\al}$ tokens; with a drafter of relative cost $c$ the speed-up is $\frac{1-\al^{\ga+1}}{(1-\al)(\ga c+1)}$. It exceeds 1 for some $\ga$ if and only if $\al>c$.
  • Speculative decoding trades compute for latency, and assumes spare parallel capacity.
  • Exactness caps the acceptance rate at the overlap. Beyond that: better drafts (page 2) or lossy acceptance (pages 3–5).

Reflexes

  • “Lossless” → the output distribution of the target is unchanged; quality is exactly the target's, for better or worse.
  • An acceptance rule → ask what is drawn after a rejection. The pair (acceptance probability, replacement distribution) determines the output distribution.
  • An acceptance rate → it is an overlap of distributions, $1-\TV$; a drafter is good if it is close to the target, not if it is good in itself.
  • A speed-up number → find $\al$ (or tokens per round), $c$, $\ga$, the batch size and the hardware before believing it.
  • “Tokens accepted per step” versus “tokens generated per step” → they differ by one.
  • A greedy target → the test is an exact match with the argmax; a deterministic drafter → its $q$ is a point mass.

Glossary

target model
The large model whose output we want ($\Mp$). Also: verifier, main model, original model.
draft model
The fast predictor that writes the guesses ($\Mq$). Also: drafter, approximation model, assistant model, small model.
round
One draft followed by one parallel call of the target. Also: step, iteration, verification cycle.
draft length $\ga$
Number of tokens drafted per round. Also: lookahead, speculation length, $K$.
acceptance rate $\al$
Average probability that a drafted token is kept. Also: token acceptance rate.
tokens per round
Average number of tokens output per call of the target. Also: block efficiency, mean generated length; “mean accepted tokens” is usually one less.
residual distribution
$\pos{p-q}$ renormalised: what the replacement token is drawn from after a rejection.
lossless / exact / unbiased
The output distribution is exactly the target's.
lossy / approximate / relaxed
It is not: some tokens are accepted that the exact rule would have replaced.
coupling
A way to draw two random tokens together, one with distribution $q$ and one with distribution $p$. Maximal coupling: one that makes them equal as often as possible, $1-\TV(p,q)$.
cost coefficient $c$
Time of a drafter call divided by time of a target call.
