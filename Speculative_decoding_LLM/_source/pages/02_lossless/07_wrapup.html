9. What to remember

Summary
  • Every exact method pulls one of three levers of the law of page 1: a higher acceptance $\al$, a cheaper drafter $c$, or more tokens out of each call of the target.
  • Drafters. A separate small model, improved by distillation (+10–45%); a head on the target fed with its hidden state (the EAGLE line: 3× to 5.6× in its authors' tables); a lookup (free, strong on repeated text); since 2026, block drafters that write a whole draft in one pass (about 5× on average, up to 9.6× on mathematics).
  • Trees. Several candidates per position are scored in the same pass. The number of tokens kept grows like the logarithm of the size of the tree. With sampling, exactness needs the recursive rule: after each rejection the target becomes the residual; candidates are best drawn without replacement.
  • Block verification caps the running product of the ratios instead of each ratio: exact, optimal for one chain, 5–8% faster, nothing with greedy decoding.
  • Draft length should follow the drafter's uncertainty: 7–22% over the best fixed length, without training.
  • Under load the gain shrinks, because verification uses capacity that is no longer idle: 1.1× to 2× at batch 32 on production engines, and a loss for long drafts, wide trees and weak drafters.
  • Three ceilings: the overlap $1-\TV(p,q)$, the drafter's cost, the load. No exact rule rejects less than the rule of page 1; keeping more tokens from the same draft means changing the output distribution.

Reflexes

  • A speed-up → ask for the batch size, the temperature, the target, the kind of text, and who measured.
  • A new drafter → ask whether it must be trained for each target, and what it costs in memory.
  • A tree → ask how many nodes are scored for each token kept.
  • “Lossless” with sampling and several candidates → look for the residual in the rule.
  • A lossy method → ask which exact method it was compared with.

What comes next

Glossary

drafter
Whatever proposes the draft: a small model, a head, a lookup, a block model.
head
A small network attached to the target and fed with its hidden states.
tree attention
A mask that lets the target score all the nodes of a tree of candidates in one pass, each node seeing only its ancestors.
recursive rejection sampling
The exact rule for several candidates: test a candidate; on rejection, replace the target by the residual and test the next.
block efficiency, $\tau$
Average number of tokens produced per call of the target.
block drafter
A drafter that writes all the tokens of a draft in one pass.
multi-token prediction (MTP)
Extra output heads trained with the model itself to predict several tokens ahead; some models ship with them.
memory-bound, compute-bound
A pass limited by reading the weights from memory (extra positions are almost free), or by the arithmetic (they are not).
