6. Monge's problem between measures, and three ways it fails OT4ML §2.3, pp. 25–28

Monge's problem asks for a map $T$ with $\pf{T}{\al}=\be$ minimising the average cost $\int c(x,T(x))\,\dd\al(x)$; because a map cannot split mass, there may be no admissible map at all, the problem is not symmetric, and even when maps exist the infimum may not be attained.

The problem

In the course OT4ML §2.3 and Def. 2.14, p. 25

Monge's problem asks for a deterministic map transporting one law onto another while minimizing a prescribed cost. […] It is geometrically direct, because every source point is assigned one destination, but it is also analytically fragile: the feasible set is non-convex, it can be empty, and a map cannot split mass. These limitations are precisely what motivate Kantorovich's relaxation in the next chapter.

Definition 2.14 (Monge problem and Monge map). For $\al\in\M(\X)$, $\be\in\M(\Y)$ and measurable $c:\X\times\Y\to[0,+\infty]$, define

$$\mathcal M_c(\al,\be)=\inf_{T:\X\to\Y\text{ measurable}}\Big\{\int_\X c\big(x,T(x)\big)\,\dd\al(x)\ ;\ \pf{T}{\al}=\be\Big\}.\qquad(2.5)$$

A feasible $T$ is a Monge map; a minimizer is an optimal Monge map. The value is $+\infty$ if no feasible map exists.

$\al$, $\be$
Source and target: where the mass is, and where it must go. Any probability measures — discrete, densities, mixed.
$c(x,y)\in[0,+\infty]$
The price of moving a unit of mass from $x$ to $y$; the value $+\infty$ is allowed (to forbid some moves).
$\pf{T}{\al}=\be$
The constraint: after moving every bit of mass of $\al$ from $x$ to $T(x)$, we get exactly $\be$ (§5). An equality between measures — infinitely many scalar constraints, one per set $B$.
$\int c(x,T(x))\,\dd\al(x)$
The total cost: each bit of mass at $x$ pays $c(x,T(x))$. With $X\sim\al$ it is $\E\big[c(X,T(X))\big]$, the average price paid by a random particle.
$\inf$
An infimum, not a minimum: we will see that it need not be attained. The name $\mathcal M_c$ is the book's (not to be confused with $\M(\X)$, the set of probability measures).
Worked example — the feasible set is not convex

Take $\al=\be=\frac12\delta_0+\frac12\delta_1$. The identity $T_0(x)=x$ and the swap $T_1$ ($T_1(0)=1$, $T_1(1)=0$) are both feasible. Their average $T(x)=\frac12\big(T_0(x)+T_1(x)\big)=\frac12$ sends both points to $\frac12$, so $\pf{T}{\al}=\delta_{1/2}\ne\be$. The set of Monge maps is not convex: you cannot average two admissible maps. This is the continuous analogue of “half of a permutation is not a permutation”, and the deep reason why the problem is hard.

Discrete measures: the meaning of the constraint

In the course CompOT Remark 2.4, pp. 13–14

Remark 2.4 (Monge problem between discrete measures). For discrete measures $\al=\sum_{i=1}^na_i\delta_{x_i}$ and $\be=\sum_{j=1}^mb_j\delta_{y_j}$, the Monge problem [1781] seeks a map that associates to each point $x_i$ a single point $y_j$ and which must push the mass of $\al$ toward the mass of $\be$, namely, such a map $T:\{x_1,\dots,x_n\}\to\{y_1,\dots,y_m\}$ must verify that

$$\forall j\in[\![m]\!],\qquad b_j=\sum_{i:\,T(x_i)=y_j}a_i,\qquad(2.4)$$

which we write in compact form as $\pf{T}{\al}=\be$. Because all the elements of $b$ are positive, that map is necessarily surjective.

Decoding. Group the sources according to their destination: the group sent to $y_j$ must have total mass exactly $b_j$. So a Monge map between discrete measures is a partition of the sources into groups with prescribed total masses. Surjective: every target with $b_j>0$ must receive at least one source.

Worked example — counting Monge maps
  • $a=(0.2,\,0.3,\,0.5)$ and $b=(0.5,\,0.5)$: the groups must weigh $0.5$ each. Exactly two maps: $\{x_1,x_2\}\to y_1$, $x_3\to y_2$, or $x_3\to y_1$, $\{x_1,x_2\}\to y_2$. (A script checking the $2^3=8$ maps confirms these two.)
  • $a=(0.5,\,0.5)$ and $b=(0.3,\,0.7)$: no group of sources weighs $0.3$. No Monge map, the value is $+\infty$, although nothing is wrong with the measures.
In the course OT4ML Prop. 2.15, p. 26

Proposition 2.15 (Empirical Monge maps and matchings). Assume that the source atoms $x_1,\dots,x_n$ are distinct and that $\al=\frac1n\sum_{i=1}^n\delta_{x_i}$, $\be=\frac1n\sum_{j=1}^n\delta_{y_j}$. If $\pf{T}{\al}=\be$, then for each distinct target value $z$ in the support of $\be$, exactly $n\be(\{z\})$ source atoms are mapped to $z$. In particular, if the $y_j$ are distinct, then there exists a permutation $\sigma\in\mathrm{Perm}(n)$ such that $T(x_i)=y_{\sigma(i)}$ for all $i$. Conversely, every such assignment of source atoms to target atoms with the correct masses defines a feasible Monge map on the support of $\al$, and in the distinct-target case $\int_\X c(x,T(x))\,\dd\al(x)=\frac1n\sum_{i=1}^nc(x_i,y_{\sigma(i)})$. […] If source locations are repeated, they should first be merged into atoms with larger masses; such atoms cannot be split by a Monge map.

So with $n$ distinct points of mass $\frac1n$ on each side, Monge's problem is the optimal assignment problem of §2: the same matching problem, now written with measures. The general problem adds unequal weights (which can make the constraint impossible) and continuous measures.

Failure 1: there may be no admissible map — and the problem is not symmetric

In the course OT4ML Remark 2.17, p. 26

Remark 2.17 (Feasibility versus optimality). An optimal map solving (2.5) might fail to exist for two distinct reasons. First, the constraint set can be empty, for instance if $\al=\delta_x$ and $\be$ is not a single Dirac mass. Proposition 2.16 shows that non-atomicity of the source removes this feasibility obstruction. Second, even when feasible maps exist, the infimum may fail to be attained because the class of maps is not closed under weak limits.

Why $\delta_x$ cannot be split. Whatever $T$, $\pf{T}{\delta_x}=\delta_{T(x)}$ (§5): one Dirac. So $\delta_0$ can never be sent onto $\frac12\delta_{-1}+\frac12\delta_1$. In the other direction it is easy: $T\equiv0$ sends $\frac12\delta_{-1}+\frac12\delta_1$ onto $\delta_0$. More generally, a discrete source $\sum_ia_i\delta_{x_i}$ is sent to $\sum_ia_i\delta_{T(x_i)}$, again discrete: no map sends a discrete measure to a measure with a density (Exercise 3 of the sheet). Conversely, from a source without atoms one can reach anything:

In the course OT4ML Prop. 2.16 and Example 2.19, pp. 26–27

Proposition 2.16 (Existence of transport maps from atomless sources). Let $\al$ and $\be$ be Borel probability measures on Polish spaces, and assume that $\al$ is atomless. Then there exists a measurable map $T$ such that $\pf{T}{\al}=\be$.

Example 2.19 (Semi-discrete Monge maps). The Monge formulation is not symmetric in $\al$ and $\be$. It makes sense, for instance, when $\al$ has a density with respect to Lebesgue measure and $\be$ is discrete. On $\X=\Y=\R^d$, let $\be=\sum_jb_j\delta_{y_j}$ be supported on $\{y_1,\dots,y_m\}$. A map $T$ such that $\pf{T}{\al}=\be$ defines a segmentation of the space into cells $C_j=T^{-1}(y_j)$ satisfying $\al(C_j)=b_j$. This is the semi-discrete setting. […] If one exchanges the roles of $\al$ and $\be$ so that $\al$ is discrete, then no valid $T$ exists in general: it is not possible to push forward a discrete measure to a measure with density.

atomless
No point carries positive mass (§4). Densities are atomless, but so is the uniform measure on a segment of $\R^2$.
“there exists”
Only feasibility: some admissible map exists, maybe a very irregular one, and maybe no optimal one (Failure 2). On the line, the proof is the quantile map of §9: from $\mathcal U[0,1]$, $T=C_\be^{-1}$ reaches any $\be$.
cells $C_j=T^{-1}(y_j)$
A map to a discrete measure cuts the source into regions of prescribed masses: all the mass of $C_j$ goes to $y_j$. The optimal cells are Laguerre cells (Lesson 4).
In machine learning — why generators start from continuous noise

A push-forward generative model $\pf{(G_\theta)}{\zeta}$ (§5) can only produce what Monge maps can reach from its latent law $\zeta$. If $\zeta$ were discrete (say, $1000$ possible noise values), the model could only output $1000$ different images: a discrete source cannot reach a continuous target. With an atomless latent law such as $\N(0,I_k)$, Proposition 2.16 says that every target law is reachable by some map — in 1D, explicitly $G=C_\be^{-1}\circ\Phi$, with $\Phi$ the CDF of $\N(0,1)$ (§9). The difficulty of generative modelling is therefore not whether a map exists, but finding a regular, learnable one; Brenier's theorem (§7) provides a canonical choice, and §7's regularity remark explains why it can still be irregular.

Failure 2: the infimum may not be attained

In the course OT4ML Example 2.18, p. 26

Example 2.18 (A splitting obstruction). Let $\al$ be uniform on $\{0\}\times[0,1]$ and let $\be$ be the average of the uniform laws on $\{-1\}\times[0,1]$ and $\{1\}\times[0,1]$. For the squared Euclidean cost, the relaxed plan that sends $(0,t)$ equally to $(-1,t)$ and $(1,t)$ has cost $1$, which is the smallest possible value because every target point is at horizontal distance $1$ from the source segment.

No deterministic map can attain this value. Indeed, equality would force the vertical coordinate to remain equal to $t$ almost everywhere. If $A\subset[0,1]$ were the set of levels sent to the right segment, the target marginal would then require $\abs{A\cap B}=\abs{B}/2$ for every Borel set $B\subset[0,1]$, which is impossible by taking $B=A$. Feasible maps nevertheless approach cost $1$: partition $[0,1]$ into $n$ equal cells, send the lower half of each cell affinely onto the corresponding full cell on the left segment, and send the upper half similarly to the right segment. The vertical displacement is at most $1/(2n)$, so the costs converge to $1$. Thus the Monge infimum equals the relaxed value but is not attained.

$\{0\}\times[0,1]$
A vertical segment in the plane; $\al$ spreads its mass uniformly on it (atomless, but no density in $\R^2$).
$\be$
Half of the mass uniformly on the parallel segment at $x=-1$, half on the one at $x=+1$.
relaxed plan
Split every point in two halves, one to the left, one to the right. Not a map — a coupling (Lesson 2).
$\abs{A\cap B}$
The length (Lebesgue measure) of $A\cap B$.
Idea of the proof

Three facts. (1) Every plan costs at least $1$ (horizontal distance). (2) The $n$-cell maps cost $1+\frac1{12n^2}$, so the infimum is $1$. (3) Cost exactly $1$ would force purely horizontal moves, i.e. a set $A$ of heights sent right with $\abs{A\cap B}=\frac12\abs{B}$ for all $B$ — impossible.

Full proof (with the exact cost of the $n$-cell maps)
  1. For any map $T$ with $\pf{T}{\al}=\be$, write $T(0,t)=(\pm1,\,s(t))$. Then $\norm{(0,t)-T(0,t)}^2=1+(t-s(t))^2\ge1$, so the cost $\int\big(1+(t-s(t))^2\big)\,\dd t\ge1$.$\be$ lives on the two lines $x=\pm1$, so $T(0,t)$ lies on them (except on a null set); the horizontal displacement is exactly $1$.
  2. The $n$-cell map. In the cell $[\frac kn,\frac{k+1}n]$, a point at height $\frac kn+r$ with $0\le r\le\frac1{2n}$ goes to $(-1,\frac kn+2r)$ (vertical move $r$); a point at height $\frac kn+\frac1{2n}+r$ goes to $(+1,\frac kn+2r)$ (vertical move $\frac1{2n}-r$).Each half cell, of mass $\frac1{2n}$, is stretched by $2$ onto a full cell of length $\frac1n$, which carries mass $\frac12\cdot\frac1n$ in $\be$: the constraint holds cell by cell.
  3. $$\text{cost}=1+2n\int_0^{1/(2n)}r^2\,\dd r=1+2n\cdot\frac{1}{3}\Big(\frac1{2n}\Big)^3=1+\frac1{12n^2}.$$The vertical moves on the $2n$ half cells all have the same distribution: $r$ uniform on $[0,\frac1{2n}]$ (or $\frac1{2n}-r$, same squares). Numerically: $1.0833$ for $n=1$, $1.0208$ for $n=2$, $1.00083$ for $n=10$ (checked by quadrature).
  4. So $\mathcal M_c(\al,\be)=1$.Steps 1 and 3: the infimum is $\ge1$ and $\le1+\frac1{12n^2}$ for every $n$.
  5. Suppose a map attains $1$. Then $\int(t-s(t))^2\,\dd t=0$, so $s(t)=t$ for almost every $t$: $T(0,t)=(\pm1,t)$.Step 1: the cost is $1$ plus a nonnegative integral.
  6. Let $A=\{t:T(0,t)=(1,t)\}$. For every Borel $B\subset[0,1]$, the mass sent to $\{1\}\times B$ is $\abs{A\cap B}$, and $\be$ requires $\frac12\abs B$.$\al$ is uniform in $t$, and heights are preserved.
  7. With $B=A$: $\abs A=\frac12\abs A$, so $\abs A=0$. With $B=[0,1]$: $\abs A=\frac12$. Contradiction: no map attains the infimum. $\square$The two requirements are incompatible.
What goes wrong, and what fixes it

Minimising sequences of maps “oscillate” faster and faster between left and right; their limit is not a map but the splitting plan. Kantorovich's relaxation (Lesson 2) allows exactly this object, and its minimum is attained. Note also that $\al$ has no density in $\R^2$: this is precisely the hypothesis of Brenier's theorem that fails here (§7).

Failure 3: optimal maps need not be unique

In the course OT4ML Example 2.21, p. 28

Example 2.21 (Book-shifting in the Monge problem). […] Let $\al=\frac12\ind_{[0,2]}(x)\,\dd x$ and $\be=\frac12\ind_{[1,3]}(y)\,\dd y$. The monotone translation $T_{\mathrm{tr}}(x)=x+1$ pushes $\al$ to $\be$. For the cost $\abs{x-y}$, it is not the only optimal Monge map. The book-shifting map $T_{\mathrm{book}}(x)=x+2$ for $0\le x\le1$ and $T_{\mathrm{book}}(x)=x$ for $11$, strict convexity selects the monotone translation.

This is the continuous version of the book-shifting example of §3, and it is Exercise 5 of the sheet, solved in §11 (with a whole family of optimal maps). For the squared cost the translation costs $1$ and the book-shifting map $2$.

The Monge value as a directed distance

With $c=d^p$ for a distance $d$, does the Monge value behave like a distance between distributions?

In the course OT4ML Def. 2.20 and Prop. 2.22, pp. 27–28

Definition 2.20 (Directed Monge distance). Let $(\X,d)$ be a metric space and $1\le p<+\infty$. For probability measures with finite $p$th moments, define

$$\widetilde{\mathcal W}_p(\al,\be)^p=\inf_{T:\X\to\X\text{ measurable}}\Big\{\int_\X d\big(x,T(x)\big)^p\,\dd\al(x)\ ;\ \pf{T}{\al}=\be\Big\}.\qquad(2.6)$$

The value is $+\infty$ when the constraint set is empty.

Proposition 2.22 (Directed Monge distance). Let $\X=\Y$ be a Polish metric space and $1\le p<+\infty$. On probability measures with finite $p$-th moment, the quantity $\widetilde{\mathcal W}_p$ is nonnegative, vanishes only on the diagonal, and satisfies the triangle inequality. It is therefore a directed extended distance: it need not be symmetric and may take the value $+\infty$.

finite $p$-th moment
$\int d(x_0,x)^p\,\dd\al(x)<\infty$ for some (hence every) point $x_0$: the mass does not spread too far.
vanishes only on the diagonal
$\widetilde{\mathcal W}_p(\al,\be)=0$ iff $\al=\be$.
directed
$\widetilde{\mathcal W}_p(\al,\be)$ and $\widetilde{\mathcal W}_p(\be,\al)$ may differ: $\widetilde{\mathcal W}_p(\frac12\delta_{-1}+\frac12\delta_1,\ \delta_0)=1$ (the constant map moves each half by $1$), but $\widetilde{\mathcal W}_p(\delta_0,\ \frac12\delta_{-1}+\frac12\delta_1)=+\infty$.
extended
It may be $+\infty$.
Reminder — Minkowski's inequality

For $p\ge1$, $\big(\int\abs{f+g}^p\,\dd\al\big)^{1/p}\le\big(\int\abs f^p\,\dd\al\big)^{1/p}+\big(\int\abs g^p\,\dd\al\big)^{1/p}$: the triangle inequality of the $L^p(\al)$ norm. It fails for $p<1$. More: Reminders — inequalities; it is used the same way for $W_p$ in Lesson 3.

Full proof of Proposition 2.22

Nonnegativity is clear ($d\ge0$). $\widetilde{\mathcal W}_p(\al,\al)=0$: the identity map is admissible and costs $0$.

Definiteness.

  1. If $\widetilde{\mathcal W}_p(\al,\be)=0$, there are admissible maps $T_k$ with $\int d(x,T_k(x))^p\,\dd\al\to0$.Definition of an infimum equal to $0$.
  2. For every bounded $1$-Lipschitz $h$: $\abs{\int h\,\dd\be-\int h\,\dd\al}=\abs{\int\big(h(T_k(x))-h(x)\big)\dd\al}\le\int d(x,T_k(x))\,\dd\al\le\Big(\int d(x,T_k(x))^p\,\dd\al\Big)^{1/p}\to0$.(2.3) for $\be=\pf{T_k}{\al}$; $\abs{h(y)-h(x)}\le d(x,y)$; Jensen's inequality $\big(\int u\big)^p\le\int u^p$ for the probability $\al$ and $p\ge1$.
  3. So $\int h\,\dd\al=\int h\,\dd\be$ for every bounded Lipschitz $h$, hence $\al=\be$.Bounded Lipschitz functions determine a probability measure on a metric space (they approximate indicators of closed sets).

Triangle inequality $\widetilde{\mathcal W}_p(\al,\be)\le\widetilde{\mathcal W}_p(\al,\ga)+\widetilde{\mathcal W}_p(\ga,\be)$:

  1. If the right side is infinite there is nothing to prove. Otherwise, for $\eps>0$ take admissible $S$ ($\pf{S}{\al}=\ga$) and $T$ ($\pf{T}{\ga}=\be$) whose costs, to the power $\frac1p$, are within $\eps$ of $\widetilde{\mathcal W}_p(\al,\ga)$ and $\widetilde{\mathcal W}_p(\ga,\be)$.Definition of the infimum.
  2. $T\circ S$ is admissible from $\al$ to $\be$.Composition: $\pf{(T\circ S)}{\al}=\pf{T}{(\pf{S}{\al})}=\pf{T}{\ga}=\be$ (§5).
  3. $$\widetilde{\mathcal W}_p(\al,\be)\le\Big(\int d\big(x,T(S(x))\big)^p\dd\al\Big)^{\frac1p}\le\Big(\int\big[d(x,S(x))+d\big(S(x),T(S(x))\big)\big]^p\dd\al\Big)^{\frac1p}.$$Any admissible map gives an upper bound; triangle inequality of $d$ and monotonicity of $u\mapsto u^p$.
  4. $$\le\Big(\int d(x,S(x))^p\,\dd\al\Big)^{\frac1p}+\Big(\int d\big(S(x),T(S(x))\big)^p\,\dd\al\Big)^{\frac1p}.$$Minkowski's inequality in $L^p(\al)$.
  5. The last integral equals $\int d(z,T(z))^p\,\dd\ga(z)$, so the sum is $\le\widetilde{\mathcal W}_p(\al,\ga)+\widetilde{\mathcal W}_p(\ga,\be)+2\eps$; let $\eps\to0$. $\square$(2.3) with $h(z)=d(z,T(z))^p$ and $\ga=\pf{S}{\al}$.

Compare with Lesson 3: for couplings the triangle inequality needs a “gluing” construction; for maps, plain composition is enough. What maps cannot give is symmetry and finiteness. Kantorovich's $W_p$ (Lessons 2–3) has both, and it gives the same value as $\widetilde{\mathcal W}_p$ when the space is compact and the source is atomless (OT4ML Prop. 4.15, p. 79). In the closed forms of §8–§9 (Gaussians, the line) the two values agree for a more direct reason: there the optimal coupling is itself carried by the optimal map (Brenier's theorem, §7; Theorem 2.41, §9), so the costs computed with maps are the Wasserstein distances.

Reflexes
  • Monge between discrete measures → partition the sources into groups of the right masses; if impossible, the value is $+\infty$.
  • A source with an atom and a target without → no map. A source without atoms → maps exist (Proposition 2.16), optimal ones need more (§7).
  • To prove that an infimum is not attained → a lower bound, a minimising sequence, and a contradiction when equality is forced.

Compute $\widetilde{\mathcal W}_1(\mathcal U[0,1],\ \frac12\delta_0+\frac12\delta_1)$ with the map “left half to $0$, right half to $1$”. Is it optimal? What is the value in the other direction?

Answer

The cost is $\int_0^1\min(x,1-x)\,\dd x=\frac14$. It is optimal: every admissible map sends a set of mass $\frac12$ to $0$ and the rest to $1$, and each point $x$ pays at least $\min(x,1-x)$, the distance to the nearest of $0$ and $1$ — with equality exactly for our map. In the other direction no map exists (a discrete source cannot reach a density): $+\infty$.
