7. Brenier's theorem: the optimal map is the gradient of a convex function OT4ML §2.4, pp. 28–33

For the quadratic cost and a source with a density, Monge's problem has exactly one solution, and it is characterised by a single property: it is the gradient of a convex function — the multi-dimensional version of a nondecreasing map.

The problem: what replaces sorting in dimension $d\ge2$?

On the line, optimal maps are nondecreasing (§3), and a nondecreasing function is the derivative of a convex function (refresher). In $\R^d$ there is no order to sort by. What do optimal maps look like? Exchanges give the answer step by step.

  • Swaps. For $c=\norm{x-y}^2$, swapping the destinations of two points changes the cost by $2\ps{x-x'}{T(x)-T(x')}$ (§2). So an optimal map is monotone: $\ps{x-x'}{T(x)-T(x')}\ge0$ for all $x,x'$ — exactly the property of nondecreasing functions on $\R$.
  • Cycles. In dimension $d\ge2$ swaps are not enough (pitfall of §2: a three-cycle can help when no swap does). Asking that no cyclic exchange helps gives the stronger property below.

In the course StatOT Def. 1.9 and Thm. 1.10, p. 31

Definition 1.9. A set $A\subset\R^d\times\R^d$ is said to be cyclically monotone if for any integer $k\ge2$, and points $(x_i,y_i)\in A$, $i=1,\dots,k$, it holds

$$\sum_{i=1}^k\ps{x_i-x_{i+1}}{y_i}\ \ge\ 0,\qquad(1.11)$$

with the convention that $x_{k+1}=x_1$.

Theorem 1.10 (Rockafellar). A set $A\subset\R^d\times\R^d$ is cyclically monotone if and only if there exists a closed convex function $\varphi:\R^d\to\R\cup\{\infty\}$ such that $A\subseteq\partial\varphi$.

$(x_i,y_i)\in A$
Pairs “source → destination” used by a transport.
(1.11)
Expanding squares, it is equivalent to $\sum_i\norm{x_i-y_i}^2\le\sum_i\norm{x_{i+1}-y_i}^2$ (StatOT (1.12)): passing the destinations around the cycle $x_1\to x_2\to\dots\to x_k\to x_1$ never lowers the quadratic cost. For $k=2$ it is the swap test.
$A\subseteq\partial\varphi$
Every destination is a subgradient of one convex function at its source: $y\in\partial\varphi(x)$, i.e. “$y=\nabla\varphi(x)$” where $\varphi$ is differentiable.

So the pairs used by an optimal transport lie in the graph of the (sub)gradient of a convex function. Brenier's theorem turns this picture into a statement about maps between measures.

The theorem

In the course OT4ML §2.4 and Thm. 2.23, p. 29

Brenier's theorem ensures that, in $\R^d$ for the quadratic cost, absolute continuity of the source is enough for Monge's problem to have a unique solution. It also gives the decisive structural description of this solution: the optimal map is not an arbitrary map, but the gradient of a convex potential.

Theorem 2.23 (Brenier). Let $\al,\be\in\M(\R^d)$ have finite second moments, and assume that $\al$ is absolutely continuous with respect to Lebesgue measure. For the quadratic cost $c(x,y)=\norm{x-y}^2$, there exists a convex function $\varphi:\R^d\to\R\cup\{+\infty\}$ such that

$$T=\nabla\varphi,\qquad\pf{T}{\al}=\be,$$

and $T$ is the unique optimal Monge map $\al$-almost everywhere. The optimal Kantorovich plan is $\pf{(\Id,T)}{\al}$.

finite second moments
$\int\norm x^2\,\dd\al<\infty$ and $\int\norm y^2\,\dd\be<\infty$. It makes the cost of every admissible map finite (for instance $\norm{x-T(x)}^2\le2\norm x^2+2\norm{T(x)}^2$), so that “optimal” has a meaning.
$\al$ absolutely continuous
$\al$ has a density (§4). Only the source is constrained: $\be$ can be anything with a finite second moment — a density, a point cloud, a mixture. The problem is asymmetric, like Monge's problem itself (§6).
$\varphi$ convex, values in $\R\cup\{+\infty\}$
The Brenier potential. It may be $+\infty$ outside a convex set (think of a target with bounded support: $\varphi$ can be anything outside where it matters). A convex function is differentiable almost everywhere, hence $\al$-almost everywhere since $\al$ has a density: $\nabla\varphi$ is well defined where the mass is.
$T=\nabla\varphi$, $\pf{T}{\al}=\be$
Existence: a gradient of a convex function does the transport.
unique optimal Monge map $\al$-a.e.
Any optimal map coincides with $\nabla\varphi$ except on a set of $\al$-mass zero (where it does not matter). In particular the infimum of §6 is attained: none of the three failures of §6 can occur.
$\pf{(\Id,T)}{\al}$
The coupling “$Y=T(X)$”, carried by the graph of $T$. Saying that it is the optimal Kantorovich plan means: even if mass were allowed to split (Lesson 2), it would not split. Monge and Kantorovich give the same answer.
Intuition — “convex gradient” is “nondecreasing” in $\R^d$

On $\R$: $T=\varphi'$ with $\varphi$ convex $\iff$ $T$ nondecreasing. Brenier says: in $\R^d$, replace “nondecreasing” by “gradient of a convex function”. Two consequences to keep in mind. A linear map $x\mapsto Ax$ is a convex gradient iff $A$ is symmetric positive semi-definite ($\varphi(x)=\frac12\ps{Ax}{x}$); a translation $x\mapsto x+v$ is the gradient of $\frac12\norm x^2+\ps vx$, so it is always optimal.

Gradients of convex functions are monotone, but not all monotone maps are gradients

Monotonicity of gradients. If $\varphi$ is convex and differentiable, write the tangent inequality at $x$ and at $x'$:

$$\varphi(x')\ge\varphi(x)+\ps{\nabla\varphi(x)}{x'-x},\qquad\varphi(x)\ge\varphi(x')+\ps{\nabla\varphi(x')}{x-x'} .$$

Adding them, the values of $\varphi$ cancel and $\ps{\nabla\varphi(x)-\nabla\varphi(x')}{x-x'}\ge0$: convex gradients are monotone. The converse fails in dimension $2$ and more:

In the course OT4ML Remark 2.24, p. 29

Remark 2.24 (Monotone fields need not be gradients). In dimensions larger than one, not all monotone fields are gradients of convex functions. Consider in $\R^2$ the rotation matrix $R_\theta=\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}$. The linear map $x\mapsto R_\theta x$ is monotone as soon as $\abs\theta\le\pi/2$, because $\ps{R_\theta x-R_\theta x'}{x-x'}=\ps{R_\theta(x-x')}{x-x'}=\cos(\theta)\norm{x-x'}^2\ge0$. However, for $\theta\ne0$, $R_\theta$ is not symmetric and therefore cannot be the gradient of a scalar potential. Indeed, if a linear field $Ax$ equals $\nabla\varphi(x)$, then its Jacobian $A$ must be symmetric […]. Thus monotonicity is weaker than Brenier optimality in dimension $d\ge2$.

Jacobian must be symmetric
The Jacobian of $\nabla\varphi$ is the Hessian $\nabla^2\varphi$, whose entries $\partial_i\partial_j\varphi=\partial_j\partial_i\varphi$ are symmetric (Schwarz). A gradient field has no “rotation” part.
Worked example — a monotone, admissible, non-optimal map

Let $\al=\be$ be the uniform law on the unit disk and $T=R_\theta$ with $\theta=30°$. A rotation maps the disk onto itself and preserves areas, so $\pf{T}{\al}=\al$: $T$ is admissible. It is monotone: $\ps{R_\theta v}{v}=\cos30°\,\norm v^2\approx0.866\norm v^2$. But its cost is $\E\norm{X-R_\theta X}^2=2(1-\cos\theta)\,\E\norm X^2=(1-\cos30°)\approx0.134$ (using $\E\norm X^2=\frac12$ for the uniform disk), while the identity — the gradient of $\frac12\norm x^2$ — costs $0$. The rotation only circulates the mass, and Brenier's characterisation rejects it: $R_\theta-R_\theta\T$ has off-diagonal entries $\mp2\sin30°=\mp1\ne0$.

Why it is true (1): the easy half, fully proved

The half of Brenier's theorem that you use in practice — to prove that a candidate map is optimal — has a short and complete proof.

In the course StatOT Thm. 1.16, p. 42

Theorem 1.16 (Improved Brenier), last part. […] Moreover, $\nabla\varphi$ is unique in the sense that if there exists a convex function $\psi$ such that $\nabla\psi(X)\sim\nu$, then $\nabla\psi(X)=\nabla\varphi(X)$, almost surely. In particular, any valid coupling $\gamma\in\Gamma_{\mu,\nu}$ of the form $(X,\nabla\psi(X))\sim\gamma$ for some convex function $\psi$, must be the unique optimal coupling between $\mu$ and $\nu$.

(StatOT writes $\mu,\nu$ for $\al,\be$ and $\Gamma_{\mu,\nu}$ for the couplings.) We prove the part about maps: a convex gradient that does the transport is optimal.

Reminder — the convex conjugate and the Fenchel–Young inequality

The convex conjugate (Legendre transform) of $\varphi$ is $\varphi^*(y)=\sup_{x}\big(\ps xy-\varphi(x)\big)$. Directly from the definition (take the particular $x$ in the sup):

$$\ps xy\ \le\ \varphi(x)+\varphi^*(y)\qquad\text{for all }x,y\qquad\text{(Fenchel–Young),}$$

with equality iff $y\in\partial\varphi(x)$: indeed $y\in\partial\varphi(x)$ means $\varphi(x')\ge\varphi(x)+\ps y{x'-x}$ for all $x'$, i.e. $\ps y{x'}-\varphi(x')\le\ps yx-\varphi(x)$ for all $x'$, i.e. the sup defining $\varphi^*(y)$ is attained at $x$. Example: $\varphi=\frac12\norm\cdot^2$ gives $\varphi^*=\frac12\norm\cdot^2$ and Fenchel–Young is $\ps xy\le\frac12\norm x^2+\frac12\norm y^2$, with equality iff $y=x$. More: Reminders — Legendre transform.

Proposition (convex gradients are optimal)

Let $\al,\be$ have finite second moments, $\varphi$ convex, and $T=\nabla\varphi$ (defined $\al$-a.e.) with $\pf{T}{\al}=\be$. Then $\int\norm{x-T(x)}^2\,\dd\al\le\int\norm{x-S(x)}^2\,\dd\al$ for every map $S$ with $\pf{S}{\al}=\be$.

Idea of the proof

Expanding the square, minimising the cost means maximising the correlation $\int\ps x{S(x)}\,\dd\al$. Fenchel–Young bounds every correlation by $\int\varphi\,\dd\al+\int\varphi^*\dd\be$, a number that does not depend on $S$; and the bound is an equality for $S=\nabla\varphi$.

Full proof
  1. For every admissible $S$, $$\int\norm{x-S(x)}^2\dd\al=\int\norm x^2\dd\al+\int\norm y^2\dd\be-2\int\ps x{S(x)}\,\dd\al(x).$$Expand $\norm{x-S(x)}^2=\norm x^2+\norm{S(x)}^2-2\ps x{S(x)}$ and use (2.3): $\int\norm{S(x)}^2\dd\al=\int\norm y^2\dd\be$ because $\pf{S}{\al}=\be$. The first two terms are the same for all admissible $S$.
  2. So $T$ is optimal iff $\int\ps x{T(x)}\,\dd\al\ge\int\ps x{S(x)}\,\dd\al$ for all admissible $S$.Step 1: the cost is a constant minus twice the correlation.
  3. $\ps x{S(x)}\le\varphi(x)+\varphi^*(S(x))$ for every $x$.Fenchel–Young with $y=S(x)$.
  4. $$\int\ps x{S(x)}\,\dd\al\le\int\varphi\,\dd\al+\int\varphi^*\big(S(x)\big)\,\dd\al(x)=\int\varphi\,\dd\al+\int\varphi^*\,\dd\be .$$Integrate step 3 against $\al$; then (2.3) again with $h=\varphi^*$. The right-hand side no longer depends on $S$.
  5. For $S=T=\nabla\varphi$, step 3 is an equality at every $x$ where $\varphi$ is differentiable, i.e. $\al$-almost everywhere; so step 4 is an equality: $\int\ps x{T(x)}\,\dd\al=\int\varphi\,\dd\al+\int\varphi^*\,\dd\be$.Equality case of Fenchel–Young: $\nabla\varphi(x)\in\partial\varphi(x)$.
  6. Hence $\int\ps x{T(x)}\,\dd\al\ge\int\ps x{S(x)}\,\dd\al$ for every admissible $S$, and $T$ is optimal by step 2. $\square$Steps 4 and 5.

Fine print. The integrals of $\varphi$ and $\varphi^*$ must make sense; with finite second moments this can be arranged (StatOT handles it with affine lower bounds of convex functions). Remarks. The density of $\al$ was used only to make $\nabla\varphi$ defined $\al$-a.e.; with $T(x)\in\partial\varphi(x)$ the same proof works for any $\al$ (we use this on the line in §9). And replacing $S(x)$ by a random $Y$ coupled with $X$, the same proof shows that $T$ beats every coupling — the Kantorovich statement of Lesson 2.

Worked example — certifying optimal maps in one line
  • $T(x)=3+2x$ pushes $\N(0,1)$ to $\N(3,4)$ and is the derivative of the convex $x^2+3x$: it is optimal, and its cost is $\E(X-3-2X)^2=\E(X+3)^2=9+1=10$ (Monte Carlo with $10^6$ draws: $9.996$). §8 does this in any dimension.
  • $T(x)=Ax$ with $A$ symmetric positive semi-definite is optimal from $\al$ to $\pf{A}{\al}$, whatever $\al$ (Exercise 6 of the sheet).

Why it is true (2): the idea of the existence proof

Idea of the proof of existence and uniqueness (StatOT's route; the book's proof by duality is in Lesson 4)
  1. An optimal coupling $\pi$ exists (compactness, Lesson 2).
  2. Its support is cyclically monotone: otherwise, moving a little mass around a cycle of pairs would lower the cost (StatOT Prop. 1.11).
  3. By Rockafellar's theorem, the support lies in the graph of $\partial\varphi$ for a convex $\varphi$.
  4. A convex function is differentiable almost everywhere, and $\al$ has a density, so $\partial\varphi(x)=\{\nabla\varphi(x)\}$ for $\al$-almost every $x$: each source point has one possible destination. The coupling is carried by the graph of $\nabla\varphi$ — it is a map. This is the only place where the density is used.
  5. Uniqueness: if $T_1$ and $T_2$ were both optimal, the half-half mixture of their couplings would be optimal too (the cost is linear in the coupling), hence carried by a map; but it sends $x$ to $T_1(x)$ and $T_2(x)$ with probability $\frac12$ each, so $T_1=T_2$ $\al$-a.e. (StatOT Thm. 1.16).

For a complete proof in the finite case (an assignment is optimal iff it is cyclically monotone iff its targets are subgradients of a piecewise-affine convex function), see the first companion, Lesson 1 §7.

What each hypothesis is for

In the course OT4ML Def. 2.25 and Remark 2.26, p. 29

Definition 2.25 (Measures not charging hypersurfaces). A Borel measure $\al$ on $\R^d$ does not charge hypersurfaces if $\al(S)=0$ for every countably $(d-1)$-rectifiable set $S$, i.e. every set that can be covered, up to an $\mathcal H^{d-1}$-null set, by countably many $C^1$ hypersurfaces.

Remark 2.26 (A sharp source hypothesis). The absolute-continuity assumption in Brenier's theorem can be weakened: for the quadratic cost, it is enough that $\al$ does not charge hypersurfaces. The reason is that the set where a convex potential has a genuinely multi-valued subdifferential is contained in a countable union of lower-dimensional pieces. This condition is close to sharp. If the source gives positive mass to a segment or a hypersurface, the subdifferential may be multi-valued on a set of positive $\al$-mass, and the optimal relaxed plan may need to split mass, as in Example 2.18.

  • The density of $\al$ (or: no mass on hypersurfaces). Without it, splitting may be optimal: the segment example of §6 charges a line of $\R^2$, the optimum splits every point, and no optimal map exists.
  • The quadratic cost. For $\abs{x-y}$ optimal maps exist on the line but are not unique (book-shifting, §3, §6). For other strictly convex costs $h(x-y)$ a unique optimal map exists, but it is not a gradient (OT4ML §2.5, beyond this course).
  • Finite second moments, so that costs are finite. Nothing on $\be$: the semi-discrete case ($\be$ discrete) is covered, and the Brenier map is then piecewise constant, constant on cells (Lesson 4).
  • Symmetric situations. If $\be$ also has a density, the Brenier map from $\be$ to $\al$ is $\nabla\varphi^*$, and $\nabla\varphi^*\circ\nabla\varphi=\Id$ $\al$-a.e.: the two maps are inverse to each other.

A use of the theorem: radial measures. If $\al$ and $\be$ are invariant under all rotations and reflections, and $\al$ has a density, the Brenier map only moves the radius, $T(x)=\tau(\norm x)\frac x{\norm x}$, with $\tau$ the one-dimensional monotone map between the laws of the radii (OT4ML Prop. 2.27, p. 30). This is Exercise 13 of the sheet, solved in §11; between two uniform balls it gives the dilation $T(x)=\frac{R_\be}{R_\al}x$.

Regularity: when is the Brenier map smooth? (remark)

Brenier's theorem gives a map defined almost everywhere, as the gradient of a convex function that may have kinks. When is it a smooth deformation?

Remark 2.32 (first lines). Caffarelli's theorem should be read as a warning as well as a theorem. Brenier's theorem gives existence and uniqueness under mild assumptions, but smoothness requires density bounds, smoothness and convex geometry that are rarely satisfied by empirical, manifold-supported or neural generative distributions.

A bounded convex set whose boundary is curved in every direction (a disk or an ellipse, not a square, not a dumbbell).

The map $\nabla\varphi$ is continuously differentiable: a genuine smooth deformation.

The convexity of the target is essential. Send a disk onto two disks joined by a thin bridge: neighbouring points of the disk must be sent to the two different lobes, and the Brenier map tears the disk along a curve (OT4ML Fig. 2.7, p. 33). The outline of the course mentions the regularity theory of Caffarelli and Figalli: Caffarelli proved the theorem above (in the 1990s); Figalli (Fields Medal 2018) developed, among much else, a partial regularity theory: without any convexity, for densities bounded above and below on bounded open sets, the Brenier map is still regular outside a closed set of zero volume (Figalli and Kim, 2010; De Philippis and Figalli, 2015). Both are beyond this course.

In machine learning — Brenier maps as tools
  • Colour transfer. Give an image the palette of another: the colours of the source image form a cloud of points in the RGB cube $[0,1]^3$ (one point per pixel), and so do those of the target image. Compute an optimal map between (sub-sampled) colour clouds for the squared cost and apply it to every pixel: positions are untouched, only colours move (OT4ML Fig. 2.4, p. 27). Because the map is monotone, $\ps{T(x)-T(x')}{x-x'}\ge0$, two colours are never pushed in opposite directions along their difference: the palette is reshaped without being inverted. Per-channel quantile matching (§9) is the cheap approximation; Gaussian matching (§8) the cheaper one.
  • Domain adaptation. Labelled source features $x_i$ (say, from synthetic images) and unlabelled target features $x'_j$ (real photos): transporting the source cloud onto the target cloud and training the classifier on the transported points, with the source labels, adapts it to the target domain (Courty et al., 2017; OT4ML Example 3.22, p. 61). Because the transport moves the cloud with the smallest average displacement, nearby source points tend to stay nearby, so the classes keep their arrangement.
  • Going further — learning Brenier maps with neural networks. An input-convex neural network (ICNN; Amos, Xu and Kolter, 2017) is a network $\varphi_\theta(x)$ that is convex in $x$ by construction: nonnegative hidden-to-hidden weights and convex nondecreasing activations such as ReLU (OT4ML §8.5, p. 154). Its gradient $\nabla_x\varphi_\theta$, computed by automatic differentiation, is then a monotone map — a candidate Brenier map — and can be trained so that it pushes one sample cloud onto another (Makkuva et al., 2020). Applications include predicting how a population of cells responds to a drug, mapping untreated cells to treated cells (Bunne et al., 2023).
Pitfall — “monotone” is necessary, not sufficient

To show that a map is the Brenier map, it is not enough to check $\ps{T(x)-T(x')}{x-x'}\ge0$: exhibit a convex potential $\varphi$ with $T=\nabla\varphi$ (for a linear map: check that its matrix is symmetric positive semi-definite), and check $\pf{T}{\al}=\be$.

Reflexes
  • Quadratic cost, source with a density → the optimal map exists, is unique, and is $\nabla\varphi$ with $\varphi$ convex.
  • To prove that a candidate map is optimal → find the convex potential (Fenchel–Young does the rest).
  • Linear or affine candidate $x\mapsto Ax+b$ → optimal iff $A$ is symmetric positive semi-definite (and it does the transport).

Is $T(x_1,x_2)=(2x_1+x_2,\ x_1+x_2)$ a Brenier map? Is $S(x_1,x_2)=(x_1+2x_2,\ x_2)$?

Answer

$T$ has matrix $\begin{pmatrix}2&1\\1&1\end{pmatrix}$: symmetric, with trace $3$ and determinant $1$, so both eigenvalues are positive, and $T=\nabla\varphi$ with $\varphi(x)=x_1^2+x_1x_2+\frac12x_2^2$ convex. It is the Brenier map from any $\al$ (with a finite second moment) to $\pf{T}{\al}$. $S$ has matrix $\begin{pmatrix}1&2\\0&1\end{pmatrix}$ (a shear). It is monotone, since $\ps{Sv}{v}=v_1^2+2v_1v_2+v_2^2=(v_1+v_2)^2\ge0$, but its matrix is not symmetric, so it is not a gradient: another monotone map that is not a Brenier map.
