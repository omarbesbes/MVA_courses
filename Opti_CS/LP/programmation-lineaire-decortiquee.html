Cinq questions, une seule géométrie

Devant un programme linéaire $\inf\{c\cdot x : Ax=b,\ x\ge0\}$, le chapitre répond à cinq questions. Chaque résultat se range dans l'une d'elles, et tous reposent sur le même fait géométrique : un coût linéaire sur un polyèdre se joue sur les sommets.

Douze gestes de preuve

Les preuves du chapitre 4 sont courtes, et elles réutilisent toujours les mêmes gestes. Les reconnaître, c'est pouvoir refaire chaque démonstration de tête : « L1 puis L2 », « L4 puis Farkas ». Ils complètent les quinze techniques T1–T15 du premier guide, dont plusieurs reviennent ici (T1 méthode directe, T3 argument du milieu, T6 des directions aux multiplicateurs, c'est-à-dire Farkas, T9 inf sup ≥ sup inf, T10 sous-suites et unicité de la limite).

La méta-règle du chapitre : tout est linéaire, donc tout se décide aux sommets. Une fonction affine sur un segment atteint son minimum en une extrémité ; un polyèdre se découpe en segments ; d'où « l'optimum est au bord, puis au sommet ». Presque chaque preuve est une version soignée de cette phrase.

L1

Perturber dans le noyau

Pour montrer qu'un point n'est pas un sommet, ou pour se déplacer dans $X_{ad}$ sans violer $Ax=b$.

Si les colonnes $\{a_i : x_i\gt0\}$ sont liées, il existe $y\ne0$ avec $Ay=0$ et $y_i=0$ hors du support de $x$ ; alors $A(x\pm\eps y)=b$ et, les $x_i$ du support étant $\gt0$, $x\pm\eps y\ge0$ pour $\eps$ petit. Donc $x=\frac12(x+\eps y)+\frac12(x-\eps y)$ est le milieu de deux points admissibles.

Un point au support lié a du jeu : on peut le bouger dans les deux sens.

Dans le livre : 4.2.5 · 4.2.6 · direction du simplexe · Ex. 4.2.2

L2

Pousser jusqu'au bord (test du ratio)

Pour aller le plus loin possible le long d'une direction admissible, et annuler une coordonnée.

Le long de $x+\eps d$ avec $Ad=0$, seules les composantes où $d_j\lt0$ peuvent devenir négatives. Le plus grand pas admissible est

$$\eps_{\max}=\min_{j\,:\,d_j\lt0}\frac{x_j}{-d_j},$$

atteint en un indice $j$ dont la coordonnée tombe à $0$ : le support perd un élément. Si $d\ge0$, aucun bord n'arrête : on part à l'infini.

Dans le livre : 4.2.6 · simplexe · Diapos : 10 (« $\eps_k$ maximal »)

L3

Éliminer les variables de base

Pour comparer un point admissible quelconque à un sommet, et lire l'optimalité.

Dans une base, $Ax=b$ s'écrit $x_B=B^{-1}(b-Nx_N)$ : les $x_N\ge0$ deviennent des coordonnées libres du polyèdre. On remplace dans le coût :

$$c\cdot x=c\cdot\bar x+\tilde c_N\cdot x_N,\qquad \tilde c_N=c_N-N^*(B^{-1})^*c_B. \tag{4.6}$$

Dans la bonne base, le coût n'est plus qu'une fonction affine des variables hors base.

Dans le livre : 4.2.8 · simplexe · Ex. 4.2.3–4.2.5 · Diapos : 6, 8

L4

La dualité faible en une ligne

Pour minorer une valeur primale, majorer une valeur duale, ou certifier un optimum.

$$c\cdot x\ \ge\ (A^*p)\cdot x\ =\ p\cdot Ax\ =\ p\cdot b .$$

Le « $\ge$ » utilise $x\ge0$ et $A^*p\le c$ ; l'égalité du milieu est la définition de l'adjoint ; la dernière utilise $Ax=b$. Trois hypothèses, trois symboles.

Dans le livre : 4.2.13 · 4.2.14 · Ex. 4.2.7 · Ex. 4.2.10 · version générale : T9

L5

Le saut est une somme de produits positifs

Pour transformer « valeurs égales » en conditions coordonnée par coordonnée (écarts complémentaires).

Forme standard : $c\cdot x-b\cdot p=x\cdot(c-A^*p)=\sum_ix_i\,(c-A^*p)_i$, somme de produits de nombres $\ge0$. Elle est nulle si et seulement si chaque produit l'est : une variable positive force sa contrainte duale à être serrée. Avec des inégalités $Ax\ge b$, il s'ajoute $p\cdot(Ax-b)\ge0$.

Dans le livre : (4.20) · (4.23) · Ex. 4.2.7 · (4.14) · Diapos : 14

L6

Relever d'une dimension

Pour transformer une question sur une valeur (un coût) en une question sur un cône, où Farkas s'applique.

On empile le coût sur les contraintes : $\mathcal A=\begin{pmatrix}c^*\\A\end{pmatrix}$ envoie $x\ge0$ sur le couple (coût, $Ax$). Ou l'on ajoute une coordonnée : $\tilde b=(b,\,-b\cdot\bar p)$, $\tilde p=(p,1)$. L'existence d'une solution optimale ou d'un point admissible devient « tel vecteur est dans tel cône ».

Dans le livre : 4.2.3 · 4.2.13 (preuve de $X_{ad}\ne\emptyset$)

L7

Mettre sous forme standard

Pour appliquer la théorie (ou le simplexe) à n'importe quel programme linéaire.

  1. $\max c\cdot x=-\min(-c)\cdot x$.
  2. $a\cdot x\le\beta$ ⟺ $a\cdot x+s=\beta$, $s\ge0$ (écart) ; $a\cdot x\ge\beta$ ⟺ $a\cdot x-s=\beta$.
  3. Variable libre : $x=x^+-x^-$, $x^\pm\ge0$.
  4. Égalité ⟺ deux inégalités (sens inverse).

Bonus : avec $m$ variables d'écart, la matrice $(A\ \ \mathrm{Id})$ est automatiquement de rang $m$, et $\mathrm{Id}$ est une base toute trouvée.

Dans le livre : (4.2)–(4.4) · Ex. 4.2.3–4.2.4 · (4.32) · Diapos : 4

L8

Ajouter ce qui manque

Pour se ramener à une structure connue en modifiant le problème.

Des variables artificielles $y\ge0$ et le coût $\sum y_i$ (phase I) ; un client fictif qui absorbe le surplus (transport) ; un arc de retour $(p,s)$ de coût $-1$ (flot maximal) ; des contraintes « $=$ » réécrites $0=\sum v_{ij}-1$ pour imiter Kirchhoff (affectation). Le nouveau problème a la même solution (pour la phase I : il fournit un point admissible du problème initial, pas son optimum), et une forme exploitable.

Dans le livre : (4.8) · Rem. 4.3.6 · Ex. 4.3.2 · (4.37) · Diapos : 11, 38, 40

L9

Cramer : déterminant ±1 ⇒ entier

Pour garantir des solutions entières sans contrainte d'intégrité.

$B^{-1}=\frac1{\det B}\,{}^t\mathrm{com}(B)$ et la comatrice d'une matrice entière est entière. Si $\det B=\pm1$, $B^{-1}$ est entière, donc $B^{-1}b\in\mathbb Z^m$ pour tout $b$ entier. Réciproquement, tester $b=e_i$ donne les colonnes de $B^{-1}$, puis $\det B\cdot\det B^{-1}=1$ dans $\mathbb Z$.

Dans le livre : 4.3.1 · 4.3.3 · 4.3.7 · Diapos : 21, 24

L10

Développer selon une colonne, par récurrence

Pour calculer (ou borner) tous les déterminants d'une famille de matrices stable par extraction.

Si une colonne a un seul coefficient non nul ($\pm1$), on développe : $\det=\pm\det(\text{mineur})$, et le mineur est du même type. Si chaque colonne a un $+1$ et un $-1$, la somme des lignes est nulle : $\det=0$. Une colonne nulle : $\det=0$.

Dans le livre : 4.3.5 · Ex. 4.3.1 · Diapos : 23

L11

Barrière, KKT, passage à la limite

Pour approcher un problème à contraintes $x\ge0$ par des problèmes lisses, puis revenir.

  1. Remplacer $x\ge0$ par $-\mu\sum\log x_i$, infini au bord : le minimiseur reste à l'intérieur.
  2. Écrire ses conditions d'optimalité (contraintes affines, donc qualifiées).
  3. Borner ce qui doit l'être (le livre borne $A^*p^\mu$ ; comme $A^*$ est injective, cela borne aussi $p^\mu$).
  4. Extraire une sous-suite et passer à la limite : on retrouve KKT du problème d'origine.

Dans le livre : 4.2.11 · Ex. 4.2.6 · cousin extérieur : pénalisation 3.4.6

L12

Relâcher pour borner

Pour encadrer la valeur d'un problème difficile (entier) par celle d'un problème facile.

Enlever une contrainte agrandit l'ensemble admissible : en minimisation, la valeur relâchée minore la vraie ; en maximisation, elle la majore. Si la solution relâchée satisfait la contrainte oubliée, elle est optimale pour le vrai problème. Toute solution admissible donne l'autre borne.

Le relâché borne d'un côté, une heuristique de l'autre ; on coupe ce qui ne peut plus gagner.

Dans le livre : (4.24) contre (4.1) · (4.37) · Diapos : 17, 49, 53–56

Théorème 2.2.1

Existence d'un minimum en dimension finie

Diapos (ch. II)
Théorème 2.2.1

$K\subset\R^N$ fermé non vide, $J$ continue sur $K$ et infinie à l'infini (2.2) : il existe un point de minimum, et toute suite minimisante a une sous-suite qui converge vers un point de minimum.

Rôle au chapitre 4. Il suffit pour l'exemple (4.5), où $T$ est compact (p. 121), mais pas en général. (1) Pour un programme linéaire, $c\cdot x$ n'est pas toujours infinie à l'infini sur $X_{ad}$ (elle peut rester constante le long d'une demi-droite de $X_{ad}$) ; le Lemme 4.2.3 obtient pourtant l'existence, par la structure polyédrale. (2) Dans la preuve du Lemme 4.2.11, $X^0_{ad}$ n'est pas fermé : on refait la méthode directe à la main (T1).

Clin d'œil : le premier guide, faute d'avoir le chapitre 1, avait supposé à l'Exercice 2.2.4 que l'Exemple 1.2.1 était le problème de transport. La Remarque 4.3.6 le confirme.

Lemme 2.5.19 · étapes 1–2 de sa preuve

Farkas, et la fermeture des cônes finis

Livre · clé
Lemme 2.5.19 (de Farkas)

Soient $a_1,\dots,a_M\in V$, $\mathcal K=\{w : \ps{a_i}{w}\le0,\ 1\le i\le M\}$ et $\hat{\mathcal K}=\{q : \exists\lambda_1,\dots,\lambda_M\ge0,\ q=-\sum_i\lambda_ia_i\}$. Pour tout $p\in V$ : si $\ps{p}{w}\ge0$ pour tout $w\in\mathcal K$, alors $p\in\hat{\mathcal K}$.

Pour le Lemme 4.2.3, ce qui sert n'est pas l'énoncé, mais un morceau de la preuve (étapes 1–2 dans le livre et dans la fiche du guide 1) :

Fermeture

Un cône engendré par un nombre fini de vecteurs, $C=\{\sum_{i=1}^nx_ia_i : x_i\ge0\}$, est fermé.

Idée de la preuve : si les $a_i$ sont libres, les coordonnées d'une suite convergente de $C$ convergent, et restent $\ge0$. S'ils sont liés, on supprime un générateur en poussant le long d'une relation $\sum\mu_ia_i=0$ jusqu'à annuler un coefficient (c'est déjà le geste L2 !) : $C$ est une réunion finie de cônes à générateurs libres, donc fermé.

La forme « PL » du lemme, utilisée pour la dualité (appliquer 2.5.19 aux colonnes de $A$ avec $p=-b$) :

$$\exists x\ge0,\ Ax=b\qquad\text{ou bien}\qquad\exists w,\ A^*w\le0\ \text{et}\ b\cdot w\gt0,$$

et jamais les deux (si $Ax=b$ avec $x\ge0$ et $A^*w\le0$, alors $b\cdot w=x\cdot A^*w\le0$). Lecture géométrique : soit $b$ est dans le cône des colonnes, soit un hyperplan de normale $w$ l'en sépare.

Rôle au chapitre 4. La fermeture fait le Lemme 4.2.3 ; l'énoncé, sous sa forme « PL », fait l'étape « dual de valeur finie ⇒ $X_{ad}\ne\emptyset$ » de la preuve du Théorème 4.2.13 donnée par le livre. Et la réduction du nombre de générateurs est le cousin de la Proposition 4.2.6.

Th. 2.5.17 · Rem. 2.5.16 · Th. 2.5.24

KKT, et les contraintes affines toujours qualifiées

Diapos (ch. II)
Théorème 2.5.17 + Remarque 2.5.16

Si $u$ est un minimum local de $J$ sur $\{F_i\le0\}$, $J,F_i$ dérivables en $u$, contraintes qualifiées en $u$, il existe $\lambda\ge0$ avec $J'(u)+\sum\lambda_iF_i'(u)=0$ et $\lambda_iF_i(u)=0$. Des contraintes affines sont toujours qualifiées ($\bar w=0$ convient).

Rôle au chapitre 4. Toutes les contraintes d'un programme linéaire sont affines : KKT s'applique sans aucune hypothèse. En écrivant $Ax=b$ comme $Ax-b\le0$ et $b-Ax\le0$, et $x\ge0$ comme $-x\le0$, on obtient en un optimum $\bar x$ des multiplicateurs $\alpha,\beta,\lambda\ge0$ avec $c+A^*\alpha-A^*\beta-\lambda=0$, $\lambda\cdot\bar x=0$. En posant $p=\beta-\alpha$ (de signe quelconque) : $c=A^*p+\lambda$. C'est la clé de la preuve courte de la dualité forte, et l'origine de (4.12).

Th. 2.6.4 · Th. 2.6.9 · Rem. 2.6.11 · Cor. 2.6.12

Kuhn–Tucker et dualité, cas convexe

Diapos (ch. II)
Rappels

Th. 2.6.4 (Kuhn–Tucker) : $J,F_i$ convexes, qualifiées en $u$ ; $u$ minimum global ⟺ il existe $p\ge0$ avec $(u,p)$ point-selle du Lagrangien ⟺ KKT (2.63).

Th. 2.6.9 : $(u,p)$ point-selle ⟺ $\mathcal J(u)=\min\mathcal J=\max\mathcal G=\mathcal G(p)$. Rem. 2.6.11 : toujours $\sup\mathcal G\le\inf\mathcal J$ (dualité faible).

Cor. 2.6.12 : cas convexe dérivable qualifié, si $u$ est un minimum global, il existe $p\ge0$ maximum du dual, $(u,p)$ point-selle et KKT.

Le programme linéaire est convexe (coût linéaire, contraintes affines) : les conditions KKT y sont nécessaires et suffisantes, et (4.20) n'est autre que (2.63). Liens : 2.6.4 2.6.9 2.6.12.

Annexe · Th. 5.1.3 · Th. 5.1.12

Projection sur un convexe, séparation d'un point et d'un convexe

Livre · clé
Théorème 5.1.3 (projection)

$K$ convexe fermé non vide d'un Hilbert $V$ : pour tout $x$, il existe un unique $x_K\in K$ avec $\norm{x-x_K}=\min_{y\in K}\norm{x-y}$, caractérisé par $\ps{x_K-x}{x_K-y}\le0$ pour tout $y\in K$ (5.1).

Théorème 5.1.12 (séparation)

Programmation linéaire

Critère et contraintes linéaires : la géométrie devient celle d'un polyèdre, l'optimum se trouve sur un sommet, et un sommet se code par une base. De là le simplexe, la dualité, puis — petit miracle — des solutions entières pour les problèmes de flots.

4.1

Introduction

p. 119–120 · diapos 1–3

La programmation linéaire est le cœur mathématique de la recherche opérationnelle (RO) : planifier, transporter, affecter, ordonnancer au mieux. Le livre insiste sur deux points qu'il faut garder en tête tout le chapitre.

  • C'est une brique de base. Beaucoup d'algorithmes non linéaires linéarisent puis résolvent un programme linéaire à chaque itération : c'est exactement la méthode SLP de la section 3.6.1 (guide 1).
  • L'entier est une autre planète. Imposer $x\in\mathbb Z^n$ rend le problème combinatoire : on pourrait en théorie énumérer, mais c'est illusoire en pratique. La section 4.3 montre deux cas où, par chance structurelle, le problème continu donne déjà la réponse entière.

Les diapos suivent le même plan en quatre parties (diapo 2) : programmation linéaire continue, simplexe, dualité, programmation linéaire discrète. Une seule section du livre est totalement absente des diapos : les points intérieurs (4.2.3) ; le problème d'affectation (4.3.3) n'y est cité que d'un mot (diapo 34). À l'inverse, la dernière partie des diapos (sac-à-dos, voyageur de commerce, séparation-évaluation) n'est pas dans le livre, qui renvoie à l'ouvrage [5] de Bonnans et Gaubert.

(4.1) · (4.2)–(4.4)

La forme standard, et pourquoi elle suffit

Diapos

Diapo 4 : la forme standard et $X_{ad}$Livre p. 120–121 : forme standard, réduction (4.2)–(4.4)

Programme linéaire sous forme standard
$$\inf_{x\in\R^n\ \text{tel que}\ Ax=b,\ x\ge0}\ c\cdot x, \tag{4.1}$$

où $A$ est une matrice $m\times n$, $b\in\R^m$, $c\in\R^n$, et $x\ge0$ signifie que toutes les composantes de $x$ sont positives ou nulles. On suppose $m\le n$ et $\operatorname{rg}(A)=m$.

L'idée

Ne garder qu'un seul type d'inégalité, le plus simple qui soit : $x_i\ge0$. Les équations $Ax=b$ découpent un sous-espace affine, les $n$ inégalités $x_i\ge0$ le rognent en polyèdre. Dans ce format, « être au bord » se lit sur les coordonnées : un point du bord a des composantes nulles.

Pourquoi $\operatorname{rg}(A)=m$ ne coûte rien

Si les lignes de $A$ sont liées, une équation est combinaison des autres : soit le second membre suit la même combinaison et l'équation est redondante (on la supprime), soit il ne la suit pas et les contraintes sont incompatibles ($X_{ad}=\emptyset$). Exemple : avec $x_1+x_2=1$, l'équation $2x_1+2x_2=2$ est redondante, $2x_1+2x_2=3$ est incompatible. Attention : les problèmes de flots de la section 4.3 ont toujours une équation redondante (fiche flots).

Tout programme linéaire se met sous cette forme

Le livre part de $\inf\{c\cdot x : Ax\ge b,\ A'x=b'\}$ et l'amène à (4.1) en trois gestes (L7) :

  1. Égalités en inégalités. $A'x=b'$ ⟺ $A'x\le b'$ et $A'x\ge b'$, d'où la forme $\inf\{c\cdot x : Ax\ge b\}$ (4.2).
  2. Variables d'écart. $Ax\ge b$ ⟺ $Ax=b+\lambda$ avec $\lambda\in\R^m$, $\lambda\ge0$ : c'est (4.3), avec $n+m$ variables et la matrice $(A\ \ {-\mathrm{Id}})$.
  3. Variables libres. $x=x^+-x^-$ avec $x^\pm\ge0$ : c'est (4.4), $\inf\{c\cdot(x^+-x^-) : Ax^+-Ax^-=b+\lambda,\ x^+,x^-,\lambda\ge0\}$, avec $2n+m$ variables.
Pourquoi (4.4) a vraiment la même valeur que (4.2) — le point que le livre survole

Dans (4.4), $x^+$ et $x^-$ sont deux vecteurs positifs indépendants : on n'impose pas $x^+=\max(0,x)$. La correspondance n'est donc pas bijective, mais les valeurs coïncident :

(4.2) → (4.4). Si $Ax\ge b$, on pose $x^+=\max(0,x)$, $x^-=-\min(0,x)$ (composante par composante) et $\lambda=Ax-b\ge0$ : le triplet est admissible pour (4.4) et a le même coût.

(4.4) → (4.2). Si $(x^+,x^-,\lambda)$ est admissible, $x=x^+-x^-$ vérifie $Ax=b+\lambda\ge b$, et $c\cdot x=c\cdot(x^+-x^-)$.

Les deux infima portent donc sur le même ensemble de valeurs. Bonus : en une solution basique de (4.4), on n'a jamais à la fois $x^+_i\gt0$ et $x^-_i\gt0$, car leurs colonnes $a_i$ et $-a_i$ sont liées (Lemme 4.2.5).

Le plan qui balaie : pourquoi l'optimum est au bord

Livre · clé

Livre p. 121 : exemple (4.5), Figure 4.1Diapos : absent

Exemple (4.5)
$$\min_{\substack{x_1\ge0,\,x_2\ge0,\,x_3\ge0\\ 2x_1+x_2+3x_3=6}}\ x_1+4x_2+2x_3 .$$

L'ensemble admissible est un triangle plan $T$ de sommets $(3,0,0)$, $(0,6,0)$, $(0,0,2)$. Compact, donc le minimum $M$ est atteint (Théorème 2.2.1). Les plans parallèles $x_1+4x_2+2x_3=\gamma$, quand $\gamma$ monte depuis $-\infty$, « balaient » l'espace jusqu'à toucher $T$ : le premier contact donne $M$, et il se produit sur le bord.

Coquille du livre

Le livre affirme que le minimum est atteint au sommet $(0,3,0)$. Ce point n'est même pas dans $T$ : $2\cdot0+3+3\cdot0=3\ne6$. Les coûts aux trois sommets sont $3$ en $(3,0,0)$, $24$ en $(0,6,0)$, $4$ en $(0,0,2)$ : le minimum unique est $(3,0,0)$, de valeur $M=3$ (coordonnées permutées dans le livre).

L'idée

Sur un segment, une fonction affine est monotone : elle atteint son minimum à une extrémité. Un polyèdre est fait de segments ; on peut donc toujours pousser vers le bord, puis le long du bord vers un sommet, sans augmenter le coût.

Interactif · le plan qui balaie le triangle

Le triangle $T$ de la Figure 4.1, en perspective. Le curseur fait monter le plan $c\cdot x=\gamma$ ; en bleu, sa trace sur $T$ (un segment, un point, ou rien). Les boutons choisissent le coût $c$ ; le premier est celui de (4.5).

À observer. Pour $c=(1,4,2)$, rien ne touche $T$ tant que $\gamma\lt3$ ; à $\gamma=3$ le plan touche le seul sommet $(3,0,0)$ ; au-delà, la trace est un segment qui balaie $T$ jusqu'à $\gamma=24$. Avec $c=(1,2,\frac32)$, le premier contact se fait le long de toute une arête : les solutions optimales forment un segment, dont les deux extrémités sont des sommets optimaux (c'est la Proposition 4.2.6). Avec $c=(2,1,3)$, le coût vaut $6$ partout : $c$ est orthogonal au plan de $T$, tout point est optimal, y compris à l'intérieur.

Lien avec l'argument du livre. « la fonction $x_1+4x_2+2x_3$ a un gradient non nul dans $T$ donc ses extréma se trouvent sur le bord de $T$ » Précisément : ce qui compte n'est pas $c$, mais sa projection sur le plan de $T$ (sur $\operatorname{Ker}A$). Si elle est non nulle, en tout point intérieur on peut descendre en restant dans $T$, donc l'optimum est au bord ; si elle est nulle (cas $c=(2,1,3)$, colinéaire à la normale $(2,1,3)$), le coût est constant sur $T$.

Cette observation est la « morale » que le livre transforme en théorème : un point de minimum, s'il existe, peut toujours être choisi parmi les sommets. D'où l'idée d'énumérer les sommets — intelligemment : c'est le simplexe.

Admissible, optimal, sommet — et la question des faces

Diapos

Diapo 4 : « solution admissible », « sommet = solution extrémale », et la question « Que sont les faces, arêtes, etc. ? »Livre p. 122

Définition 4.2.1

L'ensemble $X_{ad}=\{x\in\R^n : Ax=b,\ x\ge0\}$ est l'ensemble des solutions admissibles. Un sommet (ou point extrémal) de $X_{ad}$ est un point $\bar x\in X_{ad}$ qui ne se décompose pas en combinaison convexe non triviale de deux autres points de $X_{ad}$ : si $\bar x=\theta y+(1-\theta)z$ avec $y,z\in X_{ad}$ et $\theta\in\,]0,1[$, alors $y=z=\bar x$.

Remarque 4.2.2.Vocabulaire trompeur : une solution (admissible) est un point qui vérifie les contraintes ; un point qui réalise le minimum est une solution optimale (ou point de minimum).

$X_{ad}$ est convexe, et c'est un polyèdre (intersection finie de demi-espaces : $Ax\le b$, $-Ax\le-b$, $-x_i\le0$). Ses points extrémaux sont ses sommets au sens géométrique. Lorsque $X_{ad}$ est vide, on convient que l'infimum vaut $+\infty$ (livre p. 122, juste après la remarque).

L'idée

Un sommet est un point qui n'est au milieu d'aucun segment de $X_{ad}$ : aucune direction ne permet de le bouger à la fois dans un sens et dans l'autre sans sortir de $X_{ad}$.

La question de la diapo 4, résolue : faces et arêtes

La diapo pose la question sans y répondre. En forme standard, la réponse se lit sur les coordonnées. Pour $J\subset\{1,\dots,n\}$, l'ensemble

$$F_J=\{x\in X_{ad} : x_j=0\ \text{pour tout}\ j\in J\}$$

est une face de $X_{ad}$ (on annule certaines coordonnées). Les sommets sont les faces réduites à un point ; les arêtes sont les faces de dimension 1 (segments ou demi-droites). Comme $X_{ad}$ est dans un sous-espace affine de dimension $n-m$, il est de dimension au plus $n-m$ ; en un sommet « ordinaire » (non dégénéré), partent exactement $n-m$ arêtes, une par variable hors base — c'est le long d'elles que marche le simplexe (dictionnaire).

Trois définitions équivalentes d'un sommet (forme standard)

(a) point extrémal (Déf. 4.2.1) ⟺ (b) solution basique, les colonnes de son support sont libres (Lemme 4.2.5) ⟺ (c) seul point de $X_{ad}$ qui annule ses coordonnées nulles : la face $F_J$ avec $J=\{j : \bar x_j=0\}$ est réduite à $\{\bar x\}$, c'est-à-dire que les contraintes actives ($Ax=b$ et $x_j=0$, $j\in J$) ont pour seule solution $\bar x$. La forme (c) est celle qui se transpose à un polyèdre $\{Ax\le b\}$, cadre des diapos 19–20 (qui parlent de « points basiques » sans les définir) : un sommet est un point où $n$ contraintes linéairement indépendantes sont actives.

Lemme 4.2.3

Valeur finie ⇒ solution optimale

Diapos

Diapo 5, point 1 : « Le problème admet au moins une solution si l'infimum est minoré inférieurement »Livre p. 122 : énoncé et preuve par Farkas

Lemme 4.2.3

Il existe au moins une solution optimale (ou point de minimum) du programme linéaire standard (4.1) si et seulement si la valeur du minimum est finie :

$$-\infty\ \lt\ \inf_{x\in\R^n\ \text{tel que}\ Ax=b,\ x\ge0}\ c\cdot x\ \lt\ +\infty .$$
Diapos et livre

La diapo ne garde que « l'infimum est minoré », c'est-à-dire $\inf\gt-\infty$, et n'énonce que le sens « si ». Il manque $\inf\lt+\infty$, c'est-à-dire $X_{ad}\ne\emptyset$ : si les contraintes sont incompatibles, l'infimum vaut $+\infty$ (convention posée p. 122, juste avant le Lemme 4.2.3), il est bien « minoré », et il n'y a évidemment aucune solution. Le sens « seulement si » est immédiat : une solution optimale $\bar x$ donne la valeur finie $c\cdot\bar x$.

L'idée

En programmation linéaire, l'infimum ne peut pas être « approché sans être atteint » : l'ensemble des coûts réalisables est un intervalle fermé. Si le coût est borné inférieurement sur un polyèdre non vide, il atteint sa borne.

Pourquoi c'est remarquable

Comparez avec le Théorème 2.2.1 : il fallait $J$ infinie à l'infini, et $e^x$ sur $\R$ (minorée par 0, minimum jamais atteint) montrait qu'on ne peut pas s'en passer. Ici, $X_{ad}$ peut être non borné et $c\cdot x$ rester constant dans des directions infinies : aucune importance. Exemple : $\min x_1$ sur $\{x\in\R^3_+ : x_1+x_2-x_3=1\}$, non borné : le coût reste nul le long de la demi-droite $(0,1+t,t)$, il n'est donc pas infini à l'infini et le Théorème 2.2.1 ne s'applique pas ; le minimum $0$ est pourtant atteint, par exemple en $(0,1,0)$. La différence avec $e^x$ est une différence de forme : l'épigraphe de $e^x$ est un convexe fermé, mais son « ombre » sur l'axe des valeurs, $]0,+\infty[$, n'est pas fermée. L'ombre d'un polyèdre, elle, est toujours un polyèdre, donc fermée.

Sommets = solutions basiques

Diapos

Diapo 5, point 2 : « Pour une solution extrémale $x$ il existe une permutation des colonnes de $A$ telle que $A=[B\ N]$ […] On dit que $x$ est une solution basique. »Livre p. 123 : définition, puis l'équivalence avec preuve

Définition 4.2.4

Une base associée à (4.1) est une base de $\R^m$ formée de $m$ colonnes de $A$ ; on la note $B$, sous-matrice carrée d'ordre $m$ inversible. Après permutation des colonnes, $A=(B,N)$ avec $N$ de taille $m\times(n-m)$, $x=(x_B,x_N)$, et $Ax=Bx_B+Nx_N$. Les composantes de $x_B$ sont les variables de base, celles de $x_N$ les variables hors base. Une solution basique est un $x\in X_{ad}$ tel que $x_N=0$ ; elle est dégénérée si, de plus, une composante de $x_B$ est nulle.

Lemme 4.2.5

Les sommets du polyèdre $X_{ad}$ sont exactement les solutions basiques.

Diapos et livre

La diapo 5 n'énonce qu'un sens (« sommet ⇒ basique ») et définit au passage la solution basique par $x_N=0$, $x_B=B^{-1}b\ge0$. Le livre démontre l'équivalence. Le sens « basique ⇒ sommet » est pourtant celui dont le simplexe a besoin : il garantit qu'en ne visitant que des bases, on ne visite que des sommets.

L'idée

Un sommet est un point « coincé ». Il est coincé exactement quand les colonnes de $A$ qu'il utilise (celles de ses composantes non nulles) sont libres : alors $Ax=b$ ne laisse aucune liberté sur son support, et $x\ge0$ interdit de bouger hors du support dans les deux sens.

Conséquence immédiate et fondamentale : il y a un nombre fini de sommets, au plus le nombre de façons de choisir $m$ colonnes parmi $n$, $\binom nm$. Une base détermine au plus un sommet ($x_B=B^{-1}b$, s'il est $\ge0$).

Interactif · dix bases, cinq sommets

Le polygone de l'Exercice 4.2.1 : $-3x_1+2x_2\le2$, $-x_1+2x_2\le4$, $x_1+x_2\le5$, $x\ge0$. En forme standard, avec trois écarts $x_3,x_4,x_5$, on a $m=3$ et $n=5$. Choisir une base, c'est choisir les $n-m=2$ variables hors base, mises à zéro ; chacune des cinq variables nulle définit une droite ($x_3=0$ est la droite $-3x_1+2x_2=2$, etc.). Une base, c'est donc l'intersection de deux droites. Cliquez une base (ou un point d'intersection sur la figure).

$X_{ad}$sommet (base admissible)solution basique non admissible

À observer. Les dix bases donnent dix points ; cinq ont $x_B\ge0$ et sont exactement les cinq sommets ; les cinq autres ont une composante de $x_B$ négative et tombent hors du polygone. Ce sont des « solutions basiques non admissibles » : le livre ne les appelle pas solutions basiques, puisqu'il exige $x\in X_{ad}$. Avec la variante $x_1+x_2\le\frac72$, trois droites passent par $(1\,;\,\frac52)$ : trois bases différentes donnent le même sommet, chacune avec une variable de base nulle. C'est un sommet dégénéré — la source du cyclage du simplexe (Lemme 4.2.10).

Lien avec la preuve. Sens « basique ⇒ sommet » : sur la figure, un sommet est intersection de deux droites $x_i=0$, $x_j=0$ ; si $x$ était le milieu d'un segment de $X_{ad}$, les deux extrémités, positives, devraient aussi avoir $x_i=x_j=0$ (une somme de positifs n'est nulle que si chacun l'est) : elles seraient sur les deux droites, donc confondues avec $x$. Sens « sommet ⇒ basique » : un point de $X_{ad}$ qui n'est que sur une droite (ou aucune) peut glisser le long de celle-ci dans les deux sens (L1).

Indice — essayez d'abord

(⇒) Si $\bar x=\theta y+(1-\theta)z$, que valent $y_N$ et $z_N$ ? Puis unicité de la décomposition dans une base. (⇐) Par l'absurde : si les colonnes du support sont liées, perturbez $\bar x$ dans le noyau (L1).

Démonstration (livre, détaillée) L1 noyau

Basique ⇒ sommet. Soit $\bar x$ basique : après permutation, $\bar x=(\bar x_1,\dots,\bar x_m,0,\dots,0)$, $B=(b_1,\dots,b_m)$ et $\sum_{i\le m}\bar x_ib_i=b$. Supposons $\bar x=\theta y+(1-\theta)z$ avec $y,z\in X_{ad}$ et $0\lt\theta\lt1$. Pour $j\gt m$ : $0=\bar x_j=\theta y_j+(1-\theta)z_j$ avec $y_j,z_j\ge0$, donc $y_j=z_j=0$ : c'est ici que sert la positivité. Alors $\sum_{i\le m}y_ib_i=b=\sum_{i\le m}z_ib_i$, et l'unicité des coordonnées dans la base $(b_i)$ donne $y=z=\bar x$.

Sommet ⇒ basique. Soit $\bar x$ un sommet, $k$ le nombre de ses composantes non nulles ; après réarrangement $b=\sum_{i\le k}\bar x_ia_i$ avec $\bar x_i\gt0$. Il suffit de montrer que $(a_1,\dots,a_k)$ est libre : on la complète alors en une base $B$ (possible car $\operatorname{rg}A=m$), et $\bar x$ est la solution basique associée, dégénérée si $k\lt m$. Si elle était liée : $\sum_{i\le k}y_ia_i=0$ avec $y\ne0$, $y_{k+1}=\dots=y_n=0$. Comme $\bar x_1,\dots,\bar x_k\gt0$, pour $\eps\gt0$ petit, $\bar x\pm\eps y\ge0$, et $A(\bar x\pm\eps y)=b$. Donc $\bar x=\frac12(\bar x+\eps y)+\frac12(\bar x-\eps y)$ avec deux points distincts de $X_{ad}$ : contradiction.

□
Les pièges
  • Base ↦ sommet n'est pas injectif en général. Un sommet dégénéré ($k\lt m$ composantes non nulles) peut correspondre à plusieurs bases : toutes les façons de compléter $(a_1,\dots,a_k)$ en une base (parfois une seule : $A=\mathrm{Id}_2$, $b=(1,0)$). C'est pour cela que le simplexe peut « changer de base sans changer de point ».
  • Une base ne donne pas toujours un sommet. Il faut $B^{-1}b\ge0$. Les diapos l'écrivent ; le livre le met dans la définition ($x\in X_{ad}$).
  • Le support d'un sommet a au plus $m$ éléments : plus de $m$ vecteurs de $\R^m$ sont toujours liés. Mais la réciproque est fausse : un point à $k\le m$ composantes non nulles n'est un sommet que si ces colonnes sont libres.

Proposition 4.2.6

S'il existe une solution optimale du programme linéaire standard (4.1), alors il existe une solution optimale basique.

Remarque 4.2.7.Avec $c=0$ (tout point admissible est optimal), on obtient : dès que $X_{ad}$ est non vide, il a au moins un sommet. C'est faux pour un polyèdre général : un demi-plan de $\R^2$ n'a aucun sommet.
L'idée

On fait glisser une solution optimale dans une direction « plate » du noyau, où le coût ne change pas, jusqu'à ce qu'une coordonnée tombe à zéro. Le support a perdu un élément ; on recommence. Au bout du compte, le support est libre : on est sur un sommet, toujours optimal.

Interactif · glisser jusqu'au sommet

Le triangle $T$ de l'exemple (4.5) ($m=1$, $n=3$). Placez le point de départ $x$ (glissez-le dans $T$), choisissez le coût, puis avancez pas à pas. À chaque pas, le widget prend une direction $y$ du noyau ($Ay=0$), supportée par le support de $x$, de coût $c\cdot y\le0$ ; puis il pousse jusqu'au bord (L2).

À observer. Avec $c=(1,2,\frac32)$, les solutions optimales forment l'arête $\{x_2=0\}$ (en vert) ; partez d'un point de cette arête : le support $\{1,3\}$ a 2 éléments, les colonnes $a_1=2$ et $a_3=3$ sont liées dans $\R^1$, la direction $y$ du noyau est forcément plate ($c\cdot y=0$, puisque $x\pm\eps y$ sont admissibles et $x$ optimal), et un seul pas mène à un sommet optimal. Partez de l'intérieur : deux pas (support 3, puis 2, puis 1). Avec $c=(1,4,2)$ et un départ quelconque, chaque pas fait baisser le coût : c'est la version constructive ci-dessous, déjà un simplexe en germe.

Lien avec la preuve. Chaque pas est exactement le geste du livre : $z_\eps=x+\eps y$ reste dans $X_{ad}$ jusqu'à $\eps_0$, où une coordonnée s'annule ; $z_{\eps_0}$ a au plus $k-1$ composantes non nulles et le même coût. On s'arrête quand les colonnes du support sont libres — ici, en dimension $m=1$, quand il ne reste qu'une composante non nulle.

Démonstration (livre, détaillée) L1L2

Soit $x$ une solution optimale, $k$ le nombre de ses composantes non nulles, $b=\sum_{i\le k}x_ia_i$ après réarrangement.

1. Support libre. Si $(a_1,\dots,a_k)$ est libre, $x$ est basique (Lemme 4.2.5) : fini.

2. Support lié : une direction plate. Sinon, $\sum_{i\le k}y_ia_i=0$ avec $y\ne0$, $y_{k+1}=\dots=y_n=0$. Pour $\eps$ petit, $x\pm\eps y\in X_{ad}$ (L1). L'optimalité de $x$ donne $c\cdot x\le c\cdot(x\pm\eps y)$, soit $\pm\eps\,c\cdot y\ge0$ : donc $c\cdot y=0$. Tout point $z_\eps=x+\eps y$ admissible est donc encore optimal.

3. Pousser jusqu'au bord. Quitte à remplacer $y$ par $-y$, $y$ a une composante strictement négative (il est non nul). Quand $\eps$ croît depuis $0$, $z_\eps$ reste dans $X_{ad}$ jusqu'à $\eps_0=\min_{y_j\lt0}x_j/(-y_j)$ (L2), où une coordonnée s'annule : $z_{\eps_0}$ est optimal et a au plus $k-1$ composantes non nulles.

4. Recommencer. On répète avec $z_{\eps_0}$. Le support diminue strictement à chaque fois : après au plus $k$ étapes, il est libre, et l'on a une solution optimale basique.

□
L'idée de preuve des diapos, à corriger

La diapo 5 dit : « si $x$ a $k\gt m$ composantes non nulles alors on peut trouver $x'=x\bmod\ker(A)$ de coût identique et dont $k-1$ composantes sont non nulles ». C'est vrai (plus de $m$ vecteurs de $\R^m$ sont liés), mais insuffisant : l'itération s'arrête à $k\le m$, alors que le point n'est basique que si les colonnes du support sont libres. Exemple : $m=2$, colonnes $a_1=(1,0)$, $a_2=(2,0)$, $a_3=(0,1)$, et $x$ supporté par $\{1,2\}$ : $k=2=m$ mais $a_1,a_2$ sont liées. La bonne condition d'arrêt est « support libre ». Remarque de vocabulaire : « $x'=x\bmod\ker A$ » signifie $x'-x\in\ker A$, d'où $Ax'=Ax=b$.

Une autre preuve du Lemme 4.2.3, sans Farkas — hors livre, mais éclairante

Le même glissement marche en partant d'un point admissible quelconque $x$, à condition de choisir le sens de $y$ pour que $c\cdot y\le0$ :

Cas 1. $y$ a une composante négative : on pousse jusqu'au bord (L2) ; le support diminue et le coût ne monte pas.

Cas 2. $y\ge0$. Si $c\cdot y\lt0$, la demi-droite $x+\eps y$, $\eps\ge0$, est admissible ($Ay=0$, $y\ge0$) et le coût tend vers $-\infty$ : la valeur est $-\infty$. Si $c\cdot y=0$, on utilise $-y$, qui a une composante négative : cas 1.

Conclusion. Si la valeur est finie, tout point admissible est dominé par une solution basique, $c\cdot x\ge c\cdot x_{\mathrm{bas}}$. Les solutions basiques sont en nombre fini (au plus $\binom nm$) : la meilleure d'entre elles atteint l'infimum. Cela redémontre le Lemme 4.2.3 et la Proposition 4.2.6 d'un coup, sans topologie — c'est le germe du simplexe.

□
Pourquoi la Remarque 4.2.7 est vraie en forme standard, et fausse pour un demi-plan

Un polyèdre a un sommet si et seulement s'il ne contient aucune droite entière (résultat classique, hors livre). En forme standard, $X_{ad}\subset\R^n_+$, qui ne contient aucune droite : il y a toujours un sommet. Un demi-plan contient des droites (parallèles à son bord) : aucun point n'est extrémal. Mettre un demi-plan sous forme standard (variables $x^\pm$) crée un polyèdre plus grand qui, lui, a des sommets.

Dû à G. Dantzig (années 1940). Il ne se contente pas d'énumérer les sommets : il passe d'un sommet à un sommet voisin en faisant décroître le coût, et s'arrête quand aucun voisin ne fait mieux. (4.6) · Prop. 4.2.8 · Rem. 4.2.9

Les coûts réduits : la pente du coût le long des arêtes

Diapos

Diapo 6 : la formule et la condition suffisante ; diapo 8 : le calcul de $\tilde c_k$Livre p. 125 : (4.6), condition nécessaire et suffisante, Remarque 4.2.9

Dans une base $B$, tout point admissible s'écrit $x_B=B^{-1}(b-Nx_N)\ge0$, $x_N\ge0$, et le sommet associé est $\bar x_N=0$, $\bar x_B=B^{-1}b$. Avec $c=(c_B,c_N)$ :

$$c\cdot x-c\cdot\bar x=c_B\cdot B^{-1}(b-Nx_N)+c_N\cdot x_N-c_B\cdot B^{-1}b=\big(c_N-N^*(B^{-1})^*c_B\big)\cdot x_N. \tag{4.6}$$
Proposition 4.2.8

Supposons que la solution basique associée à $B$ est non dégénérée, c'est-à-dire $B^{-1}b\gt0$. Une condition nécessaire et suffisante pour qu'elle soit optimale est que

$$\tilde c_N=c_N-N^*(B^{-1})^*c_B\ \ge\ 0. \tag{4.7}$$

Le vecteur $\tilde c_N$ est appelé vecteur des coûts réduits.

Remarque 4.2.9.Si la solution basique est dégénérée, (4.7) reste suffisante mais n'est plus nécessaire.
Diapos et livre

La diapo 6 écrit $\tilde c_N=c_N-{}^t(B^{-1}N)c_B$ et n'en déduit que « $\bar x$ est donc une solution optimale si $\tilde c_N\ge0$ » : le sens suffisant, valable même en cas de dégénérescence. Notations : ${}^t(B^{-1}N)={}^tN\,{}^tB^{-1}=N^*(B^{-1})^*$, c'est la même formule. La nécessité (cas non dégénéré) est dans le livre seulement — et c'est elle qui justifie l'algorithme : tant qu'un coût réduit est négatif, on peut faire mieux.

L'idée

Dans la bonne base, les variables hors base sont des coordonnées libres du polyèdre (il suffit qu'elles soient $\ge0$ et que $x_B$ le reste), et le coût est une fonction affine de ces coordonnées, de pentes $\tilde c_N$. Au sommet, $x_N=0$ : si toutes les pentes sont $\ge0$, on ne peut que monter.

Lecture géométrique

Faire croître la seule variable hors base $x_i$ en laissant les autres nulles, c'est suivre l'arête de direction $d^i=\big(-B^{-1}a_i,\ e_i\big)$ (on vérifie $Ad^i=-a_i+a_i=0$). Le long de cette arête, le coût varie de $c\cdot d^i=c_i-c_B\cdot B^{-1}a_i=\tilde c_i$ par unité de $x_i$. Le coût réduit est la pente du coût le long de l'arête. D'où les deux sens de la proposition : pentes toutes $\ge0$, le sommet est optimal ; une pente $\lt0$, on descend en suivant l'arête — à condition de pouvoir y faire un pas non nul, ce que garantit la non-dégénérescence.

Démonstration (livre, détaillée) L3 éliminer

Suffisance. Si $\tilde c_N\ge0$, pour tout $x\in X_{ad}$, (4.6) donne $c\cdot x-c\cdot\bar x=\tilde c_N\cdot x_N\ge0$ car $x_N\ge0$. Aucune hypothèse de non-dégénérescence ici.

Nécessité. Supposons $\tilde c_N\cdot e_i\lt0$ pour un indice hors base $i$. Pour $\eps\gt0$, posons $x_N(\eps)=\eps e_i$ et $x_B(\eps)=B^{-1}(b-Nx_N(\eps))=B^{-1}b-\eps B^{-1}a_i$. Par construction $Ax(\eps)=b$. Comme $B^{-1}b\gt0$ (non dégénérée), $x_B(\eps)\gt0$ pour $\eps$ assez petit : $x(\eps)\in X_{ad}$. Et $c\cdot x(\eps)=c\cdot\bar x+\eps\,\tilde c_i\lt c\cdot\bar x$ : $\bar x$ n'est pas optimal.

Remarque 4.2.9 : un contre-exemple minimal à la nécessité — cas dégénéré

$A=(1\ \ 1)$, $b=0$, $c=(-1,0)$ : $X_{ad}=\{x\ge0,\ x_1+x_2=0\}=\{(0,0)\}$, un seul point, donc optimal. Dans la base $B=(a_2)=(1)$, $\bar x_B=x_2=0$ : dégénéré. Coût réduit de $x_1$ : $\tilde c_1=c_1-a_1(B^{-1})^*c_B=-1-0=-1\lt0$. Pourtant $\bar x$ est optimal : l'arête de direction $d^1=(1,-1)$ sort immédiatement de $X_{ad}$ (pas de longueur nulle). Dans l'autre base $B=(a_1)$, on trouve $\tilde c_2=0-1\cdot(-1)=1\ge0$ : le certificat existe, mais pas dans toutes les bases du sommet.

Le pont caché : les coûts réduits, c'est la dualité vue d'une base

Posons $p=(B^{-1})^*c_B$, solution de $B^*p=c_B$ (les multiplicateurs du simplexe, hors livre). Alors $\tilde c_N=c_N-N^*p$ et $c_B-B^*p=0$, soit

$$c-A^*p=(0,\ \tilde c_N).$$

Donc $\tilde c_N\ge0$ ⟺ $A^*p\le c$ ⟺ $p$ est admissible pour le dual (4.18), et $p\cdot b=c_B\cdot B^{-1}b=c\cdot\bar x$. Par la dualité faible (L4), $c\cdot x\ge p\cdot b=c\cdot\bar x$ pour tout $x$ admissible : seconde preuve de la suffisance, et certificat d'optimalité. Quand le simplexe s'arrête, il a calculé une solution du dual sans le demander.

Algorithme du simplexe

Initialisation (phase I). Trouver une base $B^0$ dont la solution basique est admissible : $x^0=\big((B^0)^{-1}b,\ 0\big)\ge0$.

Itérations (phase II). À l'étape $k$, on dispose d'une base $B^k$ et de la solution basique admissible $x^k$. On calcule $\tilde c^k_N=c^k_N-(N^k)^*\big((B^k)^{-1}\big)^*c^k_B$. Si $\tilde c^k_N\ge0$, $x^k$ est optimal : fin. Sinon, on choisit une variable hors base $i$ avec $\tilde c_N\cdot e_i\lt0$, de colonne $a_i$, et l'on pose

$$x^k(\eps)=\big(x^k_B(\eps),x^k_N(\eps)\big),\qquad x^k_N(\eps)=\eps e_i,\qquad x^k_B(\eps)=(B^k)^{-1}(b-\eps a_i).$$

— Soit $\eps\gt0$ peut être pris aussi grand que l'on veut avec $x^k(\eps)\in X_{ad}$ : le minimum vaut $-\infty$.
— Soit il existe une valeur maximale $\eps^k\ge0$ et un indice $j$ tels que la $j$-ème composante de $x^k(\eps^k)$ s'annule : $x^{k+1}=x^k(\eps^k)$ est une nouvelle solution basique admissible, de base $B^{k+1}$ obtenue en remplaçant la $j$-ème colonne de $B^k$ par $a_i$. Son coût est inférieur ou égal à celui de $x^k$.

L'idée

Au sommet courant, lire les pentes des arêtes (coûts réduits) ; en prendre une qui descend ; la suivre jusqu'au sommet suivant (test du ratio) ; recommencer. On ne quitte jamais le bord du polyèdre.

Lemme 4.2.10

Si toutes les solutions admissibles basiques $x^k$ produites par l'algorithme du simplexe sont non dégénérées, alors l'algorithme converge en un nombre fini d'étapes.

L'idée

Le coût baisse strictement à chaque pas, donc on ne repasse jamais par le même sommet ; or il n'y en a qu'un nombre fini.

Démonstration

1. Pas non nuls. Si $x^k$ est non dégénéré, $x^k_B\gt0$ et le minimum du test du ratio est $\gt0$ : $\eps^k\gt0$.

2. Décroissance stricte. $c\cdot x^{k+1}=c\cdot x^k+\eps^k\tilde c_i\lt c\cdot x^k$.

3. Pas de répétition. Une base détermine son sommet, et les coûts sont strictement décroissants : aucune base ne revient. Il y en a au plus $\binom nm$ : l'algorithme s'arrête, soit avec $\tilde c_N\ge0$ (optimum), soit avec une arête infinie (valeur $-\infty$).

□
Dégénérescence et cyclage

En un sommet dégénéré, une composante de base est nulle ; si elle a un coefficient positif dans $(B^k)^{-1}a_i$, le test du ratio donne $\eps^k=0$ : on change de base sans bouger (le widget le montre avec $b_3=\frac72$). Rien n'empêche alors, en théorie, de tourner en rond parmi les bases d'un même sommet : c'est le cyclage. Le livre affirme qu'« en pratique le cyclage n'apparaît jamais » ; plus exactement, la dégénérescence est très fréquente (pivots qui « piétinent »), le vrai cyclage est rare, et des règles le rendent impossible.

Comment se prémunir du cyclage — approfondissement, hors livre

Règle de Bland (1977) : faire entrer la variable de plus petit indice parmi celles de coût réduit négatif, et sortir celle de plus petit indice parmi les ex æquo du test du ratio. Avec cette règle, le simplexe termine toujours. Autres remèdes : règle lexicographique, perturbation de $b$ ($b+(\eps,\eps^2,\dots)$ rend tous les sommets non dégénérés). Le premier exemple de cyclage est dû à Hoffman (1953) ; l'exemple classique, plus petit, avec la règle du plus négatif est celui de Beale (1955), avec $m=3$ et $n=7$.

Choix du pivot et complexité

Le livre recommande le coût réduit le plus négatif (règle de Dantzig, celle des diapos). Ce n'est qu'une heuristique : sur le polygone de l'Exercice 4.2.1, elle fait 3 pivots quand la règle du premier indice en fait 2 (widget). Le nombre d'itérations peut, dans de rares exemples académiques, égaler le nombre de sommets, exponentiel en $n$ (l'Exercice 4.2.2 donne un polyèdre à $2^{n-m}$ sommets ; les cubes déformés de Klee et Minty, 1972, forcent la règle de Dantzig à tous les visiter). En pratique, le nombre de pivots croît à peu près linéairement avec la taille : c'est ce qui fait du simplexe un algorithme redoutablement efficace.

On résout un premier programme linéaire dont la seule ambition est de rendre les variables artificielles nulles. S'il y parvient, on tient un sommet du vrai problème ; sinon, le vrai problème n'a pas de point admissible.

Pourquoi ça marche — les trois affirmations du livre

(4.8) a une solution optimale. Il est admissible et sa valeur est $\ge0$ : finie, donc atteinte (Lemme 4.2.3). Le simplexe la trouve, en une solution basique.

Valeur 0 ⟺ $X_{ad}\ne\emptyset$. Si $x\in X_{ad}$, $(x,0)$ est admissible de coût $0$, donc optimal ; et toute solution optimale a alors $k\cdot y=0$, d'où $y=0$ et $Ax=b$. Un sommet de départ. Une solution basique optimale avec $y=0$ fournit un $x$ basique admissible pour (4.1). Inversion de la base · p. 127–128

Ne jamais inverser la base deux fois

Approfondissement

Livre p. 127–128 : forme produit de l'inverseDiapos : absent

Chaque itération demande $(B^k)^{-1}$ (pour $x_B$, $p$ et la colonne entrante), d'ordre $m$ = nombre de contraintes : coûteux pour les grands problèmes. Mais $B^{k+1}$ ne diffère de $B^k$ que par une colonne. Si c'est la $j$-ème qui est remplacée par $a_i$, et si $l=(B^k)^{-1}a_i\in\R^m$ (la colonne déjà calculée pour le test du ratio, avec $l_j\gt0$), alors

$$B^{k+1}=B^kE^k,\qquad E^k=\mathrm{Id}\ \text{dont la }j\text{-ème colonne est remplacée par }l,$$

car $B^kl=a_i$. Et $E^k$ s'inverse à vue : $(E^k)^{-1}$ est l'identité dont la $j$-ème colonne est remplacée par $\frac1{l_j}(-l_1,\dots,-l_{j-1},\,1,\,-l_{j+1},\dots,-l_m)$. D'où la forme factorisée $(B^k)^{-1}=(E^{k-1})^{-1}\cdots(E^0)^{-1}(B^0)^{-1}$ : on stocke des vecteurs $l$, jamais d'inverse complet.

Deux coquilles dans les matrices du livre

(1) Dans l'expression de $(E^k)^{-1}$, le facteur $\frac1{l_j}$ est placé devant toute la matrice : il ne doit porter que sur la $j$-ème colonne (sinon les 1 de la diagonale deviendraient $\frac1{l_j}$). Vérification : avec $E=\mathrm{Id}+(l-e_j)e_j^*$, on a $E^{-1}=\mathrm{Id}-\frac1{l_j}(l-e_j)e_j^*$. (2) Les matrices sont d'ordre $m$, pas $n$ : lire $l_1,\dots,l_m$ au lieu de $l_1,\dots,l_n$.

La barrière logarithmique et la trajectoire centrale

Approfondissement

Sur le programme standard (4.9) (c'est (4.1)), on définit pour $x\gt0$ le potentiel logarithmique et, pour $\mu\gt0$, le problème strictement convexe

$$\pi(x)=-\sum_{i=1}^n\log x_i, \tag{4.10}$$ $$\min_{x\in\R^n\ \text{tel que}\ Ax=b,\ x\gt0}\ \mu\,\pi(x)+c\cdot x. \tag{4.11}$$

La contrainte $x\gt0$ n'en est pas une : elle n'est jamais active, car on ne peut pas s'approcher du bord sans faire exploser $\pi$. C'est une pénalisation intérieure. Le principe : minimiser (4.11) par Newton pour des $\mu$ de plus en plus petits.

Lemme 4.2.11

Soit $X^0_{ad}=\{x\in\R^n : Ax=b,\ x\gt0\}$. On suppose $X^0_{ad}$ borné non vide. Alors (4.11) admet une unique solution optimale $x^\mu$. De plus, si (4.9) admet une unique solution optimale $x^0$, alors $x^\mu\to x^0$ quand $\mu\to0$.

Remarque 4.2.12.$X^0_{ad}\ne\emptyset$ est nécessaire pour que (4.11) ait un point admissible ; on peut avoir $X_{ad}\ne\emptyset$ et $X^0_{ad}=\emptyset$. « $X^0_{ad}$ borné » équivaut à « $X_{ad}=\overline{X^0_{ad}}$ borné » ; sans cette hypothèse, (4.9) peut avoir une solution et (4.11) aucune (Exercice 4.2.6).
L'idée

Au lieu de longer les murs, on reste au milieu de la pièce : la barrière est un mur « mou », infini au bord. Quand $\mu$ diminue, le mur s'amincit et le minimiseur $x^\mu$ glisse continûment vers le sommet optimal, le long d'une courbe lisse — la trajectoire centrale.

Barrière contre pénalisation

Comparez avec la pénalisation 3.4.6 : là, $\frac1\eps\sum\max(F_i,0)^2$ punit la sortie et les $u_\eps$ approchent par l'extérieur (non admissibles) ; ici, $-\mu\sum\log x_i$ interdit la sortie et les $x^\mu$ approchent par l'intérieur (toujours admissibles). Même philosophie, côtés opposés du mur.

Indice — essayez d'abord

Existence : méthode directe sur $X^0_{ad}$, mais il faut empêcher la limite d'atteindre le bord — que fait $\pi$ ? Convergence : écrire Lagrange pour (4.11), multiplier par $x^\mu$, et montrer que $A^*p^\mu$ reste borné (ce qui borne aussi $p^\mu$, puisque $A^*$ est injective).

Démonstration (livre, détaillée) L11 barrière

1. Unicité. $x\mapsto\mu\pi(x)+c\cdot x$ est strictement convexe sur $\{x\gt0\}$ ($-\log$ l'est) et $X^0_{ad}$ est convexe : au plus un minimum (Proposition 2.3.4).

2. Pourquoi pas directement le Théorème 2.2.1. La fonction n'est pas infinie à l'infini (on a besoin de « $X^0_{ad}$ borné ») et surtout $X^0_{ad}$ n'est pas fermé. On refait donc la méthode directe à la main.

3. Existence. Soit $x^n\in X^0_{ad}$ minimisante. Bornée, elle a une sous-suite qui converge vers $x^\mu\in\overline{X^0_{ad}}=X_{ad}$. Si une composante de $x^\mu$ était nulle, $\pi(x^n)\to+\infty$ (une composante tend vers 0, les autres restent bornées, donc $-\log$ minoré), alors que $\mu\pi(x^n)+c\cdot x^n$ tend vers l'infimum, fini car $X^0_{ad}\ne\emptyset$ : contradiction. Donc $x^\mu\in X^0_{ad}$, et par continuité en ce point, $\mu\pi(x^\mu)+c\cdot x^\mu=\lim(\mu\pi(x^n)+c\cdot x^n)=\min$.

4. Conditions d'optimalité. En $x^\mu$, seules les contraintes $Ax=b$ comptent ($x\gt0$ n'est pas active), et $\operatorname{rg}A=m$ les qualifie (Lagrange, Théorème 2.5.6). Il existe $p^\mu\in\R^m$ avec

$$Ax^\mu=b,\qquad c-\mu\frac1{x^\mu}+A^*p^\mu=0, \tag{4.12}$$

où $\frac1x$ désigne le vecteur de composantes $\frac1{x_i}$.

5. Ce qui reste borné. $x^\mu$ est borné ($X_{ad}$ l'est). Le livre affirme qu'« en général la suite $p^\mu$ n'est pas bornée » et ne borne que $A^*p^\mu$ ; c'est inexact ici : comme $\operatorname{rg}A=m$, $A^*$ est injective et $p^\mu=(AA^*)^{-1}A\,(A^*p^\mu)$, donc borner $A^*p^\mu$ borne aussi $p^\mu$. On suit néanmoins la démarche du livre. Minoration : (4.12) donne

$$A^*p^\mu+c=\frac\mu{x^\mu}\ge0. \tag{4.13}$$

Majoration : en multipliant (4.12) par $x^\mu$, avec $A^*p^\mu\cdot x^\mu=p^\mu\cdot Ax^\mu=p^\mu\cdot b$,

$$c\cdot x^\mu-n\mu+A^*p^\mu\cdot x^\mu=c\cdot x^\mu-n\mu+p^\mu\cdot b=0. \tag{4.14}$$

Pour un $y\in X^0_{ad}$ fixé, $y\cdot A^*p^\mu=p^\mu\cdot Ay=p^\mu\cdot b=n\mu-c\cdot x^\mu\le C$. Comme $y\gt0$ et que chaque composante de $A^*p^\mu$ est minorée par $-c_i$, chacune est aussi majorée : $y_i(A^*p^\mu)_i\le C+\sum_{j}y_j|c_j|$.

6. Limite. Le long d'une suite $\mu\to0$, on extrait $x^\mu\to x^0\in X_{ad}$ ($X_{ad}$ fermé) et $A^*p^\mu\to$ une limite, qui est dans $\operatorname{Im}A^*$ (sous-espace, donc fermé) : elle s'écrit $A^*p^0$. Le passage à la limite dans (4.12) (première égalité), (4.13) et (4.14) donne

$$Ax^0=b,\qquad A^*p^0+c\ge0,\qquad c\cdot x^0+A^*p^0\cdot x^0=0 .$$

7. Reconnaître KKT. Avec $q=-p^0$ : $Ax^0=b$, $x^0\ge0$, $A^*q\le c$, $x^0\cdot(c-A^*q)=0$. C'est exactement (4.20) : par le Théorème 4.2.13, $x^0$ est optimal pour (4.9) et $q$ pour le dual. Si la solution optimale est unique, toutes les sous-suites convergentes ont la même limite, et la famille bornée $x^\mu$ converge vers $x^0$ (le geste T10).

Attention au signe du multiplicateur

Le livre conclut que « $p^0$ est un multiplicateur de Lagrange » pour (4.9). Avec la convention de (4.12) (Lagrangien $\mu\pi+c\cdot x+p\cdot(Ax-b)$), c'est $-p^0$ qui est solution du dual (4.18), écrit avec la convention $\Lag(x,p)=c\cdot x+p\cdot(b-Ax)$ de (4.16). Le livre utilise donc deux conventions de signe opposées à deux pages d'intervalle ; aucune conséquence sur le résultat, mais à ne pas mélanger dans un calcul.

Deux trésors cachés dans (4.12) et (4.14)

Centralité. Posons $q^\mu=-p^\mu$ et $s^\mu=c-A^*q^\mu$ (l'écart de la contrainte duale). (4.12) dit $s^\mu=\frac\mu{x^\mu}$, soit $x^\mu_is^\mu_i=\mu$ pour tout $i$. À la limite, $x^0_is^0_i=0$ : ce sont les écarts complémentaires (4.20). La trajectoire centrale, ce sont les écarts complémentaires perturbés d'une même quantité $\mu$.

Un certificat chiffré. $q^\mu$ est admissible pour le dual ($A^*q^\mu=c-\frac\mu{x^\mu}\lt c$), $x^\mu$ pour le primal, et (4.14) s'écrit $c\cdot x^\mu-b\cdot q^\mu=n\mu$. Par la dualité faible, $c\cdot x^\mu-\min(4.9)\le n\mu$ : pour garantir une précision $\eps$, il suffit d'aller jusqu'à $\mu=\eps/n$.

L'algorithme en pratique

On ne résout jamais (4.11) exactement : on fait un ou quelques pas de Newton (pour le problème avec contraintes d'égalité, comme en 3.5), puis on diminue $\mu$, et l'on recommence à partir du point obtenu. Comme $x^\mu$ dépend continûment de $\mu$, le point courant reste dans le bassin de convergence quadratique de Newton pour le $\mu$ suivant, à condition de diminuer $\mu$ assez peu à chaque fois (sur l'exemple du widget, diviser $\mu$ par 2 à chaque pas fait déjà décrocher les itérés). Les meilleures variantes garantissent un nombre d'itérations en $O(\sqrt n\,\log(1/\eps))$ pour atteindre une précision $\eps$ (borne de pire cas, résultat hors livre) — d'où leur intérêt pour les très grands problèmes. Contrepartie : elles rendent un point proche de l'optimum, pas un sommet exact ; pour obtenir une base (et, par exemple, une solution entière dans les cas de la section 4.3), il faut ensuite « arrondir » vers un sommet.

(4.15)–(4.18)

Lagrangien, fonction duale, problème dual

Diapos

Diapos 13–14 : problème primal, Lagrangien, coût dual $G$, problème dualLivre p. 131–132

Le primal est le programme standard $\inf\{c\cdot x : Ax=b,\ x\ge0\}$ (4.15). On ne « dualise » que les égalités : pour $p\in\R^m$,

$$\Lag(x,p)=c\cdot x+p\cdot(b-Ax), \tag{4.16}$$ $$G(p)=\min_{x\ge0}\Lag(x,p)=\begin{cases}p\cdot b & \text{si } A^*p-c\le0,\\ -\infty & \text{sinon,}\end{cases} \tag{4.17}$$ $$\sup_{p\in\R^m\ \text{tel que}\ A^*p-c\le0}\ p\cdot b . \tag{4.18}$$

On note $P_{ad}=\{p\in\R^m : A^*p-c\le0\}$ et, comme avant, $X_{ad}=\{x\in\R^n : Ax=b,\ x\ge0\}$. Les programmes (4.15) et (4.18) sont dits en dualité.

Le calcul de (4.17), « après calcul » dans le livre

On regroupe selon $x$ : $\Lag(x,p)=p\cdot b+(c-A^*p)\cdot x=p\cdot b+\sum_i(c-A^*p)_i\,x_i$, à minimiser sur $x\ge0$, coordonnée par coordonnée.

— Si une composante $(c-A^*p)_i$ est $\lt0$, on fait $x_i\to+\infty$ : $G(p)=-\infty$.
— Si toutes sont $\ge0$, chaque terme est $\ge0$ et le minimum est atteint en $x=0$ : $G(p)=p\cdot b$.

Le dual $\sup G$ ne s'intéresse donc qu'aux $p$ où $G\gt-\infty$, c'est-à-dire à $P_{ad}$, et y maximise $p\cdot b$. (Détail : $G(p)$ est un infimum, qui peut valoir $-\infty$ ; le livre et la diapo écrivent « min ».)

L'idée

Chaque $p\in P_{ad}$ fournit une minoration $c\cdot x\ge p\cdot b$ valable pour tous les points admissibles. Le dual cherche la meilleure de ces minorations. Une seule ligne de calcul suffit à la vérifier — c'est ce qui fait la force de la dualité en pratique.

Interprétation : des prix

Problème du régime (forme de l'Exercice 4.2.7) : $x_j$ = quantité d'aliment $j$, de prix $c_j$ ; $a_{ij}$ = teneur en nutriment $i$ ; on veut au moins $b_i$ de chaque nutriment au moindre coût. Le dual est celui d'un vendeur de pilules qui fixe un prix $p_i\ge0$ par unité de nutriment : pour rester compétitif, chaque aliment doit coûter au moins ce que valent ses nutriments, $\sum_ia_{ij}p_i\le c_j$ ; il maximise sa recette $\sum_ib_ip_i$. La dualité forte dit que le vendeur peut exactement égaler le coût du meilleur régime. Les $p_i$ optimaux sont des prix marginaux : augmenter un peu $b_i$ augmente le coût optimal de $p_i$ par unité, tant que la base optimale ne change pas (le cousin linéaire du Lemme 2.5.12).

Théorème 4.2.13

La dualité forte et les écarts complémentaires

Diapos

Diapo 14 : « Si le problème primal ou dual a une solution finie alors l'autre aussi. De plus il existe un point selle $(\bar x,\bar p)$ du Lagrangien […] Le point vérifie également la condition d'écarts complémentaires $\bar x\cdot(c-{}^tA\bar p)=0$. »Livre p. 132–133 : énoncé complet et preuve

Théorème 4.2.13

Si (4.15) ou (4.18) a une valeur optimale finie, alors il existe $\bar x\in X_{ad}$ solution optimale de (4.15) et $\bar p\in P_{ad}$ solution optimale de (4.18) qui vérifient

$$\Big(\min_{x\in\R^n\ \text{tel que}\ Ax=b,\ x\ge0}c\cdot x\Big)=c\cdot\bar x=\bar p\cdot b=\Big(\max_{p\in\R^m\ \text{tel que}\ A^*p-c\le0}p\cdot b\Big). \tag{4.19}$$

De plus, $\bar x$ et $\bar p$ sont solutions optimales de (4.15) et (4.18) si et seulement si elles vérifient les conditions d'optimalité de Kuhn et Tucker

$$A\bar x=b,\quad\bar x\ge0,\quad A^*\bar p-c\le0,\quad\bar x\cdot(c-A^*\bar p)=0. \tag{4.20}$$

Si (4.15) ou (4.18) a une valeur optimale infinie, alors l'ensemble des solutions admissibles de l'autre problème est vide.

Diapos et livre

La diapo 14 contient l'essentiel (existence, égalité des valeurs, point-selle, écarts complémentaires) mais pas : (1) la réciproque « (4.20) ⇒ optimalité », qui est pourtant ce qu'on utilise pour vérifier une solution ; (2) le cas infini. Inversement, la diapo parle de point-selle du Lagrangien, que le livre ne mentionne pas ici : c'est le Théorème 2.6.9 appliqué à (4.16) sur $\R^n_+\times\R^m$, équivalent à (4.19). « Valeur optimale infinie » s'entend « non bornée » : $-\infty$ pour le primal, $+\infty$ pour le dual (pas la valeur $+\infty$ d'un primal vide).

L'idée

Le primal descend, le dual monte, et le dual est toujours sous le primal (une ligne de calcul). En programmation linéaire, il n'y a jamais d'écart à l'arrivée : dès que l'un des deux a une valeur finie, ils se rejoignent exactement. Et ils se rejoignent quand chaque variable positive « serre » sa contrainte duale.

Démonstration courte, à retenir L4KKT affine

1. Dualité faible. Pour $x\in X_{ad}$ et $p\in P_{ad}$ : $c\cdot x\ge A^*p\cdot x=p\cdot Ax=p\cdot b$ (on utilise $x\ge0$ et $A^*p\le c$, puis $Ax=b$). Donc $\sup(4.18)\le\inf(4.15)$, et l'écart vaut $x\cdot(c-A^*p)\ge0$.

2. Si le primal a une valeur finie. Le Lemme 4.2.3 donne une solution optimale $\bar x$. Toutes les contraintes sont affines, donc KKT s'applique sans hypothèse (rappel) : il existe $\bar p\in\R^m$ et $\lambda\in\R^n_+$ avec $c=A^*\bar p+\lambda$ et $\lambda\cdot\bar x=0$. Alors $A^*\bar p=c-\lambda\le c$ : $\bar p\in P_{ad}$ ; et $c\cdot\bar x-b\cdot\bar p=\bar x\cdot(c-A^*\bar p)=\bar x\cdot\lambda=0$. Par la dualité faible, aucun $p\in P_{ad}$ ne fait mieux que $b\cdot\bar p=c\cdot\bar x$ : $\bar p$ est optimal et (4.19) est démontré.

3. Caractérisation (4.20). Si $\bar x$, $\bar p$ sont admissibles, l'écart $c\cdot\bar x-b\cdot\bar p=\bar x\cdot(c-A^*\bar p)$ est nul si et seulement si les valeurs sont égales, ce qui équivaut à l'optimalité des deux : si $c\cdot\bar x=b\cdot\bar p$, les deux sont optimaux par la dualité faible (étape 1) ; réciproquement, s'ils sont optimaux, $c\cdot\bar x=\min(4.15)=\max(4.18)=b\cdot\bar p$ par l'étape 2. C'est une équivalence complète, sans hypothèse supplémentaire.

4. Si le dual a une valeur finie. Le dual se met sous forme standard (L7 : $p=p^+-p^-$, écarts), donc a une solution optimale (Lemme 4.2.3) et on lui applique l'étape 2 : son propre dual, qui est (4.15) (Exercice 4.2.9), est admissible et de même valeur.

5. Cas infini. Si le primal vaut $-\infty$ et si $P_{ad}$ contenait un $p$, on aurait $c\cdot x\ge p\cdot b$ pour tout $x\in X_{ad}$ : minoré, contradiction. Donc $P_{ad}=\emptyset$. Symétriquement, un dual de valeur $+\infty$ force $X_{ad}=\emptyset$.

  • $t\gt0$ : on divise par $t$ ($\tilde A^*w\le0$ et $\tilde b\cdot w$ sont homogènes) et l'on est dans le cas vérifié par le livre.

Définition (diapo 20)

L'enveloppe convexe $\operatorname{conv}(E)$ d'un ensemble $E$ est le plus petit convexe qui le contient ; c'est l'ensemble des combinaisons convexes finies $\sum\theta_ke_k$ ($\theta_k\ge0$, $\sum\theta_k=1$) de points de $E$.

Lemme (diapo 20), corrigé

(1) Si $P$ est un polyèdre borné, $P$ est l'enveloppe convexe de ses sommets $S$ (théorème de Minkowski). (2) Pour $J$ concave (en particulier linéaire) sur un polyèdre borné, $\min_PJ=\min_SJ$.

Deux imprécisions des diapos

« $P$ est l'enveloppe convexe de ses sommets » demande $P$ borné. Un demi-plan n'a aucun sommet (c'est l'exemple de la Remarque 4.2.7 du livre) ; l'orthant $\R^2_+$ a un seul sommet, $0$, et n'en est pas l'enveloppe convexe. (Pour un polyèdre non borné à sommets, il faut ajouter les directions infinies : $P=\operatorname{conv}(S)+\text{cône de récession}$.)

« Pour $J$ convexe, $\min_PJ=\min_SJ$ » est faux : il faut $J$ concave. Contre-exemple : $J(x)=x^2$ sur $P=[-1,1]$ : $\min_PJ=0$ (en $0$), mais $\min_SJ=1$ (sommets $\pm1$). Pour une fonction convexe, c'est le maximum qui est atteint en un sommet. Pour une fonction linéaire, à la fois convexe et concave, les deux énoncés sont vrais — c'est le cas qui sert.

Démonstration du point (2), une fois (1) admis

Tout $x\in P$ s'écrit $x=\sum\theta_ks_k$, combinaison convexe de sommets. Si $J$ est concave, $J(x)\ge\sum\theta_kJ(s_k)\ge\min_kJ(s_k)\ge\min_SJ$. Donc $\min_PJ\ge\min_SJ$, et l'inégalité inverse est évidente ($S\subset P$).

Pour $P=\{Ax\le b\}$, un sommet est un point où $n$ contraintes linéairement indépendantes sont actives (définition (c) de la fiche 4.2.1).

Lemme 4.3.1

Pour une matrice inversible $A\in\mathbb Z^{n\times n}$, les deux propriétés suivantes sont équivalentes : 1. $\det A=\pm1$ ; 2. pour tout $b\in\mathbb Z^n$, $A^{-1}b\in\mathbb Z^n$.

L'idée

Cramer : résoudre $Ax=b$, c'est diviser des déterminants entiers par $\det A$. Diviser par $\pm1$ ne fait jamais sortir des entiers ; diviser par 2 le fait dès qu'un numérateur est impair.

Démonstration (livre, détaillée) L9 Cramer

1 ⇒ 2. Par Cramer, $x_i=\det A_i/\det A$, où $A_i$ est $A$ dont la $i$-ème colonne est remplacée par $b$ : un déterminant de matrice entière, donc un entier. Divisé par $\pm1$, il reste entier.

2 ⇒ 1. Avec $b=e_i$, la $i$-ème colonne de $A^{-1}$, qui est $A^{-1}e_i$, est entière : $A^{-1}\in\mathbb Z^{n\times n}$. Donc $\det A^{-1}\in\mathbb Z$, et $\det A\in\mathbb Z$. Or $\det A\cdot\det A^{-1}=1$ : $\det A$ est un entier qui divise 1, soit $\pm1$.

□
Pourquoi l'hypothèse « $A$ entière »

La diapo l'omet, mais elle est indispensable dans les deux sens. $A=\operatorname{diag}(2,\frac12)$ a $\det A=1$ et $A^{-1}e_1=(\frac12,0)\notin\mathbb Z^2$ : 1 ⇏ 2. $A=(\frac12)$ (matrice $1\times1$) envoie $\mathbb Z$ dans $\mathbb Z$ par $A^{-1}=2$, mais $\det A=\frac12$ : 2 ⇏ 1.

L'ajout des diapos : « $P$ est l'enveloppe convexe de $P\cap\mathbb Z^n$ »

Pour $P=\{x : Ax\le b\}$ avec $A\in\mathbb Z^{n\times n}$ de déterminant $\pm1$ et $b\in\mathbb Z^n$, c'est vrai, et voici pourquoi (hors livre). En posant $s=b-Ax\ge0$ : $P=\{A^{-1}b-A^{-1}s,\ s\ge0\}$, un cône de sommet $x_0=A^{-1}b$ et d'arêtes dirigées par $g_i=-A^{-1}e_i$. Lemme 4.3.1 : $x_0$ et les $g_i$ sont entiers. Un point $x_0+\sum s_ig_i$ est combinaison convexe des points $x_0+\sum k_ig_i$ avec $k_i\in\{\lfloor s_i\rfloor,\lceil s_i\rceil\}$ (on interpole coordonnée par coordonnée), qui sont entiers et dans $P$. Donc $P\subset\operatorname{conv}(P\cap\mathbb Z^n)$, et l'inclusion inverse vient de la convexité de $P$. C'est le germe de la Proposition 4.3.3 : quand les sommets sont entiers, le polyèdre est l'enveloppe de ses points entiers.

Définition 4.3.2

Unimodulaire, totalement unimodulaire

Diapos

Diapo 22 : « Une telle matrice est dite unimodulaire. Si $m\ne n$ la matrice $A$ est dite totalement unimodulaire si toute sous-matrice carrée est unimodulaire ou non inversible. »Livre p. 135

Définition 4.3.2

Une matrice carrée $A\in\mathbb Z^{n\times n}$ est unimodulaire si $\det A=\pm1$. Une matrice $A\in\mathbb Z^{m\times n}$ est totalement unimodulaire (TU) si toute sous-matrice carrée extraite de $A$ est de déterminant $\pm1$ ou $0$.

Avec les sous-matrices $1\times1$ : les coefficients d'une matrice TU valent $0$ ou $\pm1$. « Extraite » veut dire : on garde $k$ lignes et $k$ colonnes quelconques, pas forcément contiguës.

L'idée

Être unimodulaire, c'est une propriété d'une seule matrice ; être TU, c'est que toutes les bases qu'on pourrait extraire, de toutes les tailles, soient unimodulaires ou singulières. C'est exactement ce qu'il faut pour que le simplexe, qui change de base sans cesse, ne rencontre que des sommets entiers.

Les pièges
  • Unimodulaire n'implique pas TU, même pour une matrice carrée : $\begin{pmatrix}2&1\\1&1\end{pmatrix}$ a pour déterminant $1$ mais contient le coefficient 2. La formulation de la diapo (« si $m\ne n$ ») est trompeuse : la définition de TU vaut aussi pour les matrices carrées.
  • Des coefficients $0,\pm1$ ne suffisent pas : $\begin{pmatrix}1&1\\-1&1\end{pmatrix}$ a pour déterminant 2 ; la matrice d'incidence d'un triangle non orienté, $\begin{pmatrix}1&1&0\\0&1&1\\1&0&1\end{pmatrix}$, aussi (un « cycle impair »).
Opérations qui préservent TU (hors livre, très utiles)

Transposer ; supprimer des lignes ou des colonnes ; permuter ; multiplier une ligne ou une colonne par $-1$ ; dupliquer une ligne ou une colonne ; accoler l'identité, $(A\ \ \mathrm{Id})$ ou $\binom{A}{\mathrm{Id}}$. La dernière permet de passer de $\{Ax\le b\}$ à la forme standard (écarts) et d'ajouter des bornes $x\le u$ sans perdre la propriété. Chacune se vérifie en développant le déterminant d'une sous-matrice selon les lignes ou colonnes ajoutées.

Proposition 4.3.3 · Remarque 4.3.4

Matrice TU et second membre entier ⇒ sommets entiers

Diapos

Diapo 24 (corollaire) : « Soit $A$ totalement unimodulaire et $b\in\mathbb Z^n$ (et $c\in\R^n$). Alors les solutions basiques du problème $\min_{x\in P}c\cdot x$ sont entières. En particulier si le problème possède un minimum alors il existe une solution basique entière qui réalise ce minimum. »Livre p. 135–136 : énoncé en forme standard, preuve, Remarque 4.3.4

Proposition 4.3.3

Soit le programme linéaire en nombres entiers (4.24). On suppose les données $A\in\mathbb Z^{m\times n}$ et $b\in\mathbb Z^m$ entières et la matrice $A$ totalement unimodulaire. Alors toute solution basique $x$ de (4.24) est entière : $x\in\mathbb Z^n$.

Remarque 4.3.4.Si l'on résout (4.24) par le simplexe « usuel » (sur le relaxé), la solution obtenue et toutes les solutions intermédiaires sont entières, car le simplexe n'énumère que des solutions basiques : rien à changer à l'algorithme. La proposition ne dit surtout pas que toutes les solutions optimales sont entières : par linéarité, tout barycentre de solutions optimales est optimal. Enfin, aucune hypothèse sur $c$, qui peut être réel.
L'idée

Une solution basique, c'est $x_B=B^{-1}b$ avec $B$ une sous-matrice carrée de $A$. Si $A$ est TU, $B$ est unimodulaire, et le Lemme 4.3.1 fait le reste. Le coût n'intervient pas : c'est la géométrie du polyèdre qui est entière.

Démonstration (livre) L9

Une solution basique correspond à $A=(B,N)$ (après permutation), $B$ inversible $m\times m$, et $x=(x_B,x_N)$ avec $x_N=0$, $x_B\ge0$, $Bx_B=b$. $B$ est une sous-matrice carrée de $A$, TU, et inversible : $\det B=\pm1$. Par le Lemme 4.3.1, $x_B=B^{-1}b\in\mathbb Z^m$. Et $x_N=0$ : $x\in\mathbb Z^n$.

□
Diapos et livre : deux écritures

La diapo travaille avec $P=\{x : Ax\le b\}$, le livre en forme standard. La diapo ne donne pas de preuve ; celle du livre s'adapte telle quelle : pour $P=\{Ax\le b\}$, un sommet est la solution de $A_Ix=b_I$, où $A_I$ est formée de $n$ lignes de $A$ linéairement indépendantes (contraintes actives) — une sous-matrice carrée inversible, donc de déterminant $\pm1$, et Cramer conclut. Si l'on ajoute $x\ge0$, on travaille avec $\binom{A}{-\mathrm{Id}}$, encore TU. Coquille de la diapo : $b$ a $m$ composantes, lire $b\in\mathbb Z^m$. Et « solution basique » suppose que $P$ a des sommets (vrai en forme standard dès que $X_{ad}\ne\emptyset$, Remarque 4.2.7 ; vrai pour $\{Ax\le b\}$ non vide si $A$ est de rang $n$).

Le petit miracle, en une phrase

Si $A$ est TU et $b$ entier, et si le relaxé (4.1) a une solution optimale, alors il en a une basique (Proposition 4.2.6), donc entière : la valeur de (4.24) est égale à celle de (4.1), et le simplexe la trouve. Attention à la méthode : un algorithme de points intérieurs, qui converge vers le « centre » de la face optimale (widget), peut rendre une solution optimale non entière quand l'optimum n'est pas unique.

Lemme 4.3.5

Le critère de Poincaré

Diapos

Diapo 23 : énoncéLivre p. 136 : énoncé et preuve

Lemme 4.3.5 (Poincaré)

Si $A$ est une matrice à coefficients $\pm1$ ou $0$, avec au plus un coefficient $1$ par colonne et au plus un coefficient $-1$ par colonne, alors $A$ est totalement unimodulaire.

L'idée

Chaque colonne ressemble à un arc de graphe : il part d'un nœud ($+1$) et arrive à un autre ($-1$). Dans une sous-matrice, soit un arc a perdu une extrémité (colonne à un seul coefficient : on développe), soit tous les arcs sont complets et chaque colonne somme à zéro (déterminant nul).

Il n'existe pas de caractérisation simple des matrices TU, mais ce critère suffisant couvre les matrices d'incidence de graphes orientés, et donc tous les problèmes de flots.

Interactif · totalement unimodulaire ? le test de toutes les sous-matrices

Choisissez une matrice, ou modifiez-la : un clic sur un coefficient le fait passer par $0\to1\to-1\to2\to0$. Le widget calcule le déterminant de toutes les sous-matrices carrées, vérifie le critère de Poincaré colonne par colonne (souligné rouge = colonne fautive), et, si la matrice n'est pas TU, encadre une sous-matrice témoin de déterminant hors de $\{0,\pm1\}$. « Dérouler la preuve » applique la récurrence de Poincaré à une sous-matrice carrée tirée au hasard.

À observer. La matrice d'incidence du graphe (un $+1$ et un $-1$ par colonne) passe le critère et le test exhaustif : des milliers de sous-matrices, toutes de déterminant $0$ ou $\pm1$. La matrice du centre d'appels ne passe pas le critère (deux ou trois $1$ par colonne) mais elle est TU quand même : le critère est suffisant, pas nécessaire (ses colonnes ont des 1 consécutifs, mais pas « en haut » : c'est la généralisation, point 6 du corrigé, de l'Exercice 4.3.1). Pour l'affectation, il faut d'abord changer le signe des $N$ dernières lignes, l'astuce du livre : le bouton la montre déjà faite. Le cycle impair a des coefficients $0,1$ mais un déterminant 2. Cliquez un coefficient pour casser la propriété : un seul 2, ou un troisième $\pm1$ mal placé, suffit.

Lien avec la preuve (L10). Le déroulé suit exactement les trois cas du livre : colonne nulle (déterminant $0$), colonne à un seul coefficient non nul (on développe, le mineur vérifie encore l'hypothèse), toutes les colonnes avec un $+1$ et un $-1$ (la somme des lignes est nulle, déterminant $0$). La récurrence porte sur la taille de la sous-matrice, et l'hypothèse « au plus un $+1$ et au plus un $-1$ par colonne » est héréditaire : c'est tout le secret.

Démonstration (livre, détaillée) L10 récurrence

Réduction. L'hypothèse sur les coefficients passe à toute sous-matrice. Il suffit donc de montrer que toute matrice carrée $M$ vérifiant l'hypothèse a un déterminant dans $\{0,\pm1\}$ ; on raisonne par récurrence sur sa taille $k$. Pour $k=1$, c'est l'hypothèse sur les coefficients.

Cas 1. $M$ a une colonne nulle : $\det M=0$.

Cas 2. $M$ a une colonne avec un seul coefficient non nul, $\pm1$. On développe selon cette colonne : $\det M=\pm\det M'$, où $M'$, d'ordre $k-1$, vérifie l'hypothèse. Par récurrence, $\det M'\in\{0,\pm1\}$.

Cas 3. Sinon, chaque colonne a exactement un $1$ et un $-1$ : la somme de chaque colonne est nulle, autrement dit $(1,\dots,1)$ est dans le noyau de $M^*$. $M^*$ n'est pas inversible : $\det M=\det M^*=0$.

□
Pour aller plus loin : un critère plus large — approfondissement, hors livre

Critère de Heller–Tompkins : si chaque colonne a au plus deux coefficients non nuls ($\pm1$), et si l'on peut partager les lignes en deux groupes de sorte que deux coefficients de même signe d'une colonne soient dans des groupes différents et deux coefficients de signes opposés dans le même groupe, alors la matrice est TU. Poincaré est le cas « un seul groupe ». Pour l'affectation (deux $+1$ par colonne, l'un dans les lignes « femmes », l'autre dans les lignes « hommes »), le partage femmes/hommes convient directement : c'est ce que fait, autrement, l'astuce de signe du livre.

Introduction aux problèmes de flots

p. 137–141 · diapos 25–45

Les problèmes de flots modélisent des réseaux : transport, communication, réseaux sociaux. Ils servent ici de prétexte pour illustrer la programmation linéaire en nombres entiers, car leurs matrices vérifient le critère de Poincaré. C'est la partie des diapos la plus développée (21 diapos), et la plus proche du livre.

(4.25)–(4.33)

Graphe, flot, loi de Kirchhoff, matrice d'incidence

Diapos

Diapos 25–37 : graphe orienté (Figure 4.2), capacités, coûts, flot extérieur, flot admissible, propriété « $Ax=b$, $A$ TU », flot de coût minimum, existence, intégralitéLivre p. 137–139

Un graphe orienté $\mathcal G=(\mathcal N,\mathcal A)$ a $m$ nœuds et $n$ arcs ; l'arc $(i,j)$ va de $i$ vers $j$ (et n'est pas l'arc $(j,i)$). Chaque arc porte une capacité $u_{ij}\in\R_+\cup\{+\infty\}$ et un coût unitaire $c_{ij}\in\R$ (éventuellement négatif : une ligne subventionnée). Chaque nœud reçoit un flot extérieur $b_i$ : entrant si $b_i\gt0$, sortant si $b_i\lt0$.

Flot, flot admissible, flot de coût minimum

Un flot est un vecteur $x\in\R^n$, $(i,j)\mapsto x_{ij}$, qui vérifie la loi des nœuds de Kirchhoff et la positivité :

$$b_i+\sum_{j\,:\,(j,i)\in\mathcal A}x_{ji}=\sum_{j\,:\,(i,j)\in\mathcal A}x_{ij}\quad\forall i\in\mathcal N, \tag{4.25}$$ $$0\le x_{ij}\quad\forall(i,j)\in\mathcal A. \tag{4.26}$$

Il est admissible s'il respecte de plus les capacités $x_{ij}\le u_{ij}$ (4.28). Le problème de flot à coût minimum est $\min_{x\in\R^n}\sum_{(i,j)\in\mathcal A}c_{ij}x_{ij}$ sous (4.25), (4.26), (4.28) (4.29).

(4.25) dit « tout ce qui arrive en $i$ (flot extérieur compris) en repart ». En sommant sur tous les nœuds, chaque arc est compté une fois en arrivée et une fois en départ : il reste la condition nécessaire $\sum_ib_i=0$ (4.27), supposée désormais.

Matrice d'incidence nœuds-arcs (4.30)
$$A_{i,(j,k)}=\begin{cases}-1 & \text{si } i=k \ \ (\text{l'arc arrive en } i),\\ \ \ 1 & \text{si } i=j\ \ (\text{l'arc part de } i),\\ \ \ 0 & \text{sinon.}\end{cases}$$

La $i$-ème ligne de $Ax=b$ est la loi de Kirchhoff au nœud $i$ (« ce qui sort moins ce qui entre égale $b_i$ ») ; la colonne de l'arc $(j,k)$ a un $+1$ en $j$ et un $-1$ en $k$. Le problème (4.29) s'écrit $\min\{c\cdot x : Ax=b,\ 0\le x\le u\}$ (4.31), puis, avec un écart $y=u-x\ge0$, sous forme standard :

$$\min_{z\in\R^{2n},\ \tilde Az=\tilde b,\ z\ge0}\ \sum c_{ij}x_{ij},\qquad z=\binom xy,\quad\tilde b=\binom bu,\quad\tilde A=\begin{pmatrix}A&0\\ \mathrm{Id}_n&\mathrm{Id}_n\end{pmatrix}. \tag{4.32–4.33}$$
Diapos et livre

Même définition (diapo 31 : « $A_{i,l}=-1$ si $l=(j,i)$, $A_{i,l}=1$ si $l=(i,j)$ »), même graphe (la Figure 4.2 du livre est celle des diapos 25–29). Les diapos énoncent « $A$ est totalement unimodulaire » comme une propriété (diapo 32) ; le livre la démontre (Lemme 4.3.9) et ajoute la forme standard (4.32).

L'idée

Un flot, c'est une circulation qui se conserve en chaque carrefour. Écrite en matrice, la conservation donne une matrice d'incidence : un $+1$ et un $-1$ par arc. C'est cette structure, pas les nombres, qui rendra les solutions entières.

Deux points que ni le livre ni les diapos ne disent
  1. La matrice d'incidence n'est jamais de rang $m$. Chaque colonne somme à zéro, donc la somme des lignes est nulle : $\operatorname{rg}A\le m-1$ (exactement $m$ moins le nombre de composantes connexes). L'hypothèse permanente « $\operatorname{rg}A=m$ » de la section 4.2 est donc fausse pour les flots ! Le remède est celui du début de 4.2.1 : une équation par composante connexe $C$ est redondante si $\sum_{i\in C}b_i=0$ (c'est (4.27) quand le graphe est connexe ; sinon le système est incompatible, voir le point 2), on la supprime. La matrice réduite est encore TU (sous-matrice) et de rang plein.
  2. « Admet toujours une solution si $c_{ij}\ge0$ ou si $u_{ij}\lt+\infty$ » suppose qu'il existe un flot admissible. $\sum b_i=0$ ne suffit pas : deux nœuds sans arc entre eux, avec $b=(1,-1)$, n'ont aucun flot. Sous réserve d'admissibilité : si $c\ge0$, le coût est minoré par $0$ et le Lemme 4.2.3 conclut ; si $u$ est fini, $X_{ad}$ est borné, fermé, donc compact (Théorème 2.2.1). La diapo 36 reprend l'énoncé du livre tel quel.

Remarque 4.3.6

Le transport est un flot

Livre · clé

Livre p. 139 : Remarque 4.3.6Diapo 38 : l'exemple du constructeur automobile, qui l'applique (« on introduira un concessionnaire imaginaire »)

Remarque 4.3.6.Le problème de transport de l'Exemple 1.2.1 est un flot à coût minimum : les nœuds sont les $M$ entrepôts et les $N$ clients (notés $j'$), les arcs vont des entrepôts aux clients avec le coût $c_{ij}$, et les capacités sont infinies. Un graphe biparti, entrepôts à gauche, clients à droite : la marchandise « s'écoule ». Le client imaginaire est le geste L8 : on complète le problème pour que la conservation soit exacte.

Théorème 4.3.7 · Remarque 4.3.8 · Lemme 4.3.9

Données entières ⇒ flot optimal entier

Diapos

Diapo 32 : « $A$ est totalement unimodulaire » ; diapo 37 : « Si $u$ et $b$ sont entiers alors l'algorithme du simplexe fournit une solution optimale entière »Livre p. 140 : théorème, remarque, lemme et preuves

Théorème 4.3.7

On suppose les flots extérieurs entiers, $b_i\in\mathbb Z$, ainsi que les capacités, $u_{ij}\in\mathbb N\cup\{+\infty\}$. Alors les solutions basiques de (4.32) sont entières. En particulier, le problème (4.29) de flot à coût minimal admet une solution optimale entière $x\in\mathbb N^n$.

Précision du guide, omise par le livre : « dès qu'il admet une solution optimale » ; sinon l'énoncé est faux, par exemple si aucun flot n'est admissible, ou si un cycle de coût négatif a une capacité infinie.

Lemme 4.3.9

La matrice d'incidence nœuds-arcs $A$ d'un graphe, définie par (4.30), est totalement unimodulaire.

Remarque 4.3.8.On peut donc résoudre les problèmes de flots entiers par le simplexe : la valeur optimale est la même sur $\R$ et sur $\mathbb Z$, et toutes les solutions visitées sont entières.
L'idée

Un arc, une colonne, un départ et une arrivée : Poincaré. Les capacités ne gâchent rien, car sur un arc saturé ou vide le flot vaut un entier ($u_{ij}$ ou $0$), et sur les autres arcs on est ramené à la matrice d'incidence.

Démonstration du Lemme 4.3.9

Chaque arc a un unique nœud de départ et un unique nœud d'arrivée : chaque colonne de $A$ a exactement un $1$ et un $-1$. Le Lemme 4.3.5 de Poincaré conclut.

□
Démonstration du Théorème 4.3.7, et le trou de la preuve du livre L1L9

Capacités infinies. Pas de contrainte $x\le u$ : (4.31) est déjà sous forme standard (après suppression des lignes redondantes, voir la fiche précédente), $A$ est TU (Lemme 4.3.9), donc ses solutions basiques sont entières (Proposition 4.3.3) ; s'il y a une solution optimale, il y en a une basique (Proposition 4.2.6), donc entière.

Capacités finies : l'argument du livre. « Si une solution basique $z$ vérifie $\tilde Az=\tilde b$, alors $Ax=b$ et $y=u-x$. Comme $A$ est TU, $x$ est entier. » Tel quel, c'est insuffisant : $Ax=b$ a une infinité de solutions non entières ; il faut utiliser que $z$ est basique.

Capacités finies : l'argument complet. Soit $z=(x,y)$ basique. Partageons les arcs en trois : vides ($x_{ij}=0$), saturés ($x_{ij}=u_{ij}$) et libres ($0\lt x_{ij}\lt u_{ij}$, donc $x_{ij}\gt0$ et $y_{ij}\gt0$). Sur les deux premières classes, $x_{ij}$ est entier. Les colonnes de $A$ des arcs libres sont libres : sinon, $Aw=0$ avec $w\ne0$ porté par les arcs libres, et $z\pm\eps(w,-w)$ resterait dans l'ensemble admissible de (4.32) pour $\eps$ petit, ce qui contredit que $z$ est un sommet (L1). Donc $x_F$ (arcs libres) est l'unique solution de $A_Fx_F=b-A_Su_S$ ($S$ = arcs saturés), système à second membre entier. On extrait de $A_F$ autant de lignes que de colonnes, formant une matrice carrée inversible : sous-matrice de $A$, elle est de déterminant $\pm1$, et Cramer donne $x_F$ entier (L9). Enfin $y=u-x$ est entier.

Lien avec la preuve. Les arcs saturés (en rouge) portent $x_{ij}=u_{ij}$, entier ; les arcs vides portent $0$ ; sur les arcs restants (ni vides ni saturés), le flot est déterminé par Kirchhoff : c'est la décomposition « vides, saturés, libres » de la preuve complétée ci-dessus.

Flot maximal (livre)

On distingue une source $s$ sans prédécesseur et un puits $p$ sans successeur. Pour $v\in\R_+$, un flot admissible de $s$ à $p$ de valeur $v$ est une solution de $Ax=b$, $0\le x\le u$, avec $b_s=v$, $b_p=-v$, $b_i=0$ sinon (4.34). Le problème du flot maximal est de trouver un tel flot de valeur $v$ maximale.

Chemin de coût minimum (diapo 43)

Un flot de coût minimum avec $x_{ij}\in\{0,1\}$, $b_s=-b_p=1$ et $b_i=0$ sinon. (Livre, Exercice 4.3.3 : coûts $c_{ij}\ge0$ vus comme des distances, $v=1$, capacités infinies.)

L'idée

Deux problèmes classiques de graphes sont des flots à coût minimum déguisés, donc des programmes linéaires à matrice TU : le simplexe sur le relaxé rend une solution entière — un vrai chemin, un vrai flot en unités entières.

Les remarques des diapos, décortiquées
  • « On rajoute l'arc $(p,s)$ et on maximise $x_{ps}$ » (diapo 40) : c'est l'Exercice 4.3.2. L'arc de retour referme la circulation ($b=0$ partout), le coût $-1$ sur cet arc seul fait de « minimiser le coût » la même chose que « maximiser $x_{ps}=v$ ». « Que l'on fait croître à partir de zéro tant qu'il existe une solution admissible » : $v$ maximal est le plus grand $v$ pour lequel le système (4.34) est compatible.
  • « Les $c_{ij}$ n'interviennent pas » (diapo 41) : seul compte le volume, pas le prix.
  • « $b_p=-b_s$ est nécessaire par conservation globale » (diapo 42) : c'est (4.27), $\sum b_i=0$.
  • « Les solutions optimales sont connexes » (diapo 44) : par Kirchhoff, une unité qui arrive en un nœud $i\ne p$ doit en repartir ; en suivant l'unité depuis $s$ on trace donc un chemin jusqu'à $p$. (La diapo écrit $x'_{ij}$ pour $x_{ij'}$.) Plus précisément, avec les capacités infinies de l'Exercice 4.3.3, une solution basique est un chemin simple : son support ne contient pas de cycle (sinon on pourrait le faire tourner dans les deux sens, L1). Avec la relaxation $0\le x_{ij}\le1$ de la diapo 45, un cycle saturé de coût nul peut s'ajouter au chemin.
  • « Le simplexe donne la solution en relaxant $0\le x_{ij}\le1$ ; Dijkstra est meilleur » (diapo 45) : vrai — la TU garantit l'intégralité, mais l'algorithme spécialisé de Dijkstra exploite la structure (coûts $\ge0$) avec une complexité bien plus faible. Le programme linéaire est la théorie qui explique pourquoi ces algorithmes de graphes sont justes.

Affectation : un problème combinatoire résolu par un PL

Livre · clé

Livre p. 141–142 : modèle, relaxation, intégralité, Birkhoff–von NeumannDiapo 34 : « Applications : affectations, emploi du temps, approvisionnement » — simple mention

$N$ femmes et $N$ hommes, une note d'accord $a_{ij}\ge0$ ; on cherche une permutation $\sigma$ qui maximise $\sum_ia_{i\sigma(i)}$ (Exemple 1.2.2). Il y a $N!$ permutations : $20!\approx2{,}4\cdot10^{18}$, l'énumération est illusoire. Avec $v_{ij}=1$ si $i$ épouse $j$, $0$ sinon :

$$\max_{(v_{ij})}\ \sum_{i=1}^N\sum_{j=1}^Na_{ij}v_{ij}\quad\text{sous}\quad v_{ij}\in\{0,1\},\ \ \sum_{j=1}^Nv_{ij}=1,\ \ \sum_{i=1}^Nv_{ij}=1. \tag{4.35}$$

On relâche $v_{ij}\in\{0,1\}$ en $0\le v_{ij}\le1$ (4.36) : les matrices obtenues sont les matrices doublement stochastiques. Le relaxé est un programme linéaire, déjà sous forme standard ($v_{ij}\le1$ découle des égalités et de $v\ge0$).

Le résultat

En écrivant les contraintes « hommes » sous la forme $0=\sum_iv_{ij}-1$, soit $-\sum_iv_{ij}=-1$, le relaxé devient $\max\{\sum a_{ij}v_{ij} : v\ge0,\ Av=b\}$ (4.37), où $b\in\R^{2N}$ a ses $N$ premières composantes égales à $1$ et les $N$ dernières à $-1$, et où chaque colonne de $A\in\mathbb Z^{2N\times N^2}$ a exactement un $1$ et un $-1$. Par Poincaré, $A$ est TU ; par la Proposition 4.3.3, les solutions basiques de (4.37) sont entières : le simplexe sur le relaxé résout le problème d'affectation.

Remarque 4.3.10.Autre preuve : l'ensemble des matrices doublement stochastiques est un convexe compact dont les points extrêmes sont exactement les matrices de permutation (théorème de Birkhoff–von Neumann), et il est l'enveloppe convexe de ses points extrêmes (théorème de Minkowski). Par linéarité du coût, il existe une solution optimale qui est une permutation.
L'idée

Le même geste que pour les flots : déguiser le problème en loi de Kirchhoff (femmes = sources, hommes = puits) pour obtenir un $+1$ et un $-1$ par colonne. C'est d'ailleurs un problème de transport avec offres et demandes égales à 1.

Le problème du sac-à-dos

Diapos seules

Diapos 46–49 : modèle, NP-complet, heuristique gloutonne, « séparation, évaluation et coupe »Livre : absent

Énoncé des diapos

$N$ objets de poids $p_j$ et d'utilité $u_j$ ; un sac de capacité $L$ :

$$\max_{x\in\{0,1\}^N,\ p\cdot x\le L}\ u\cdot x .$$

$x\in\{0,1\}^N$ est la variable de décision ($x_j=1$ : on prend l'objet $j$). Problème NP-complet (difficile), de complexité exponentielle ; on démarre avec une heuristique, l'algorithme glouton, et on le résout par séparation, évaluation et coupe.

Petite coquille

La diapo écrit la contrainte $p\cdot x\lt L$ (stricte). La formulation usuelle est $p\cdot x\le L$ : le sac rempli exactement à sa capacité est permis. (Avec $x$ binaire, les deux ensembles sont finis, donc fermés ; c'est pour la relaxation continue que « $\lt$ » donnerait un ensemble non fermé, sans maximum garanti.)

L'idée

Le rapport utilité/poids $u_j/p_j$ est le « rendement » d'un objet. Le glouton remplit par rendement décroissant ; la relaxation continue fait de même mais coupe le dernier objet en morceaux. Le premier donne une solution (borne inférieure), la seconde une borne supérieure : l'optimum est entre les deux.

Les trois objets à connaître
  • Glouton (diapo 48) : trier par $u_j/p_j$ décroissant, prendre chaque objet s'il tient encore. Rapide, admissible, mais pas optimal en général.
  • Relaxation continue ($0\le x_j\le1$) : un programme linéaire, dont la solution est explicite — prendre les objets par rendement décroissant et une fraction du premier qui ne tient pas (théorème de Dantzig, 1957 : par un argument d'échange, ou par les écarts complémentaires). Sa valeur majore l'optimum entier (L12).
  • Séparation-évaluation (diapo 49) : on choisit la variable fractionnaire, on sépare en deux sous-problèmes ($x_j=1$, $x_j=0$), on évalue chacun par sa relaxation, et l'on abandonne ceux dont la borne ne dépasse pas la meilleure solution connue.

Pourquoi la relaxation ne suffit pas ici : la matrice de la contrainte, une seule ligne $p$, a des coefficients quelconques ; elle n'est pas TU en général, et le sommet optimal du relaxé est en général fractionnaire (au plus une composante : celle de l'objet coupé).

Le voyageur de commerce

Diapos seules

Diapos 50–52 : le problème, la reformulation binaire, contraintes de degré et de sous-toursLivre : absent

Énoncé des diapos

$N$ villes de coordonnées $x_n$ : trouver la plus courte tournée passant une seule fois par chaque ville. Avec $\mathcal E_N$ l'ensemble des permutations de $\{1,\dots,N\}$ :

$$\min_{\sigma\in\mathcal E_N}\ \sum_{n=1}^Nd\big(x_{\sigma(n)},x_{\sigma(n+1)}\big)\qquad(\sigma(N+1)=\sigma(1)).$$

Reformulation : variable binaire $x\in\{0,1\}^{\mathcal A}$ sur les arêtes ; chaque sommet est relié à deux arêtes, $\sum_jx_{ij}=2$ ; et pour tout sous-ensemble strict $S$ de nœuds, la tournée restreinte à $S$ n'est pas un cycle, donc $\sum_{i,j\in S}x_{ij}\le\operatorname{card}(S)-1$. Problème reformulé : $\min\sum d_{ij}x_{ij}$ sous ces deux familles de contraintes.

Coquilles des diapos 51–52

Les diapos écrivent « $(i,j)\in S\cap\mathcal A,\ x_{ij}\le\operatorname{card}(S)-1$ » et « $\min d_{ij}x_{ij}$ », sans signe somme : il faut lire $\sum_{i,j\in S}x_{ij}\le\operatorname{card}(S)-1$ et $\min\sum d_{ij}x_{ij}$. Le mot « strict » (pour $S$ égal à toutes les villes, la tournée a $N$ arêtes, et c'est voulu) et la convention $\sigma(N+1)=\sigma(1)$ sont des précisions du guide.

L'idée

Les contraintes de degré disent « deux arêtes par ville », mais pas « une seule boucle » : sans les contraintes de sous-tours, la solution peut être formée de plusieurs petites boucles disjointes. Ces contraintes sont en nombre exponentiel ($2^N$ sous-ensembles) : on ne les ajoute qu'au besoin — c'est la « coupe ».

À observer. Avec deux grappes de villes, la solution des seules contraintes de degré est faite de deux boucles : chaque ville a bien deux arêtes, mais le voyageur ne visite jamais l'autre grappe. La contrainte de sous-tour pour $S$ = une grappe est violée ($\operatorname{card}(S)$ arêtes au lieu de $\operatorname{card}(S)-1$ au plus) : l'ajouter « coupe » cette solution. Sur un cercle, la solution des degrés est déjà une tournée, donc optimale. Et toujours : degrés seulement $\le$ tournée optimale $\le$ plus proche voisin — une borne inférieure par relâchement, une borne supérieure par heuristique.

Lien avec le cours. Retirer les contraintes de sous-tours, c'est relâcher (L12) : on minimise sur un ensemble plus grand, donc on trouve moins. Les deux bornes encadrent l'optimum ; c'est le matériau de la séparation-évaluation.

Diapos seules

Les quatre points des diapos (pour le voyageur de commerce)

(1) Description des tours sous forme d'arbre. (2) Calcul d'une borne « m » initialisée à l'aide d'une heuristique particulière. (3) Calcul d'une borne inférieure prévisionnelle en relâchant les contraintes et en utilisant la dualité (relaxation lagrangienne). (4) Parcours de l'arbre en élaguant les branches dont la borne prévisionnelle excède m.

Une confusion à corriger dans les diapos

La diapo 54 appelle « borne inférieure » la quantité $m$ initialisée par une heuristique. Pour un problème de minimisation (la tournée la plus courte), une heuristique fournit une tournée réelle, donc une borne supérieure de l'optimum : $m$ est la longueur de la meilleure tournée connue. La borne inférieure est la borne « prévisionnelle » du point (3), calculée par relaxation. On élague une branche quand sa borne inférieure atteint ou dépasse $m$ : aucune tournée de cette branche ne peut faire mieux que celle qu'on a déjà. (Le point (4) est donc juste ; seul le mot du point (2) est à corriger.)

L'idée

Diviser pour régner, sans tout explorer : on partage l'ensemble des solutions (séparation), on calcule pour chaque morceau une borne optimiste (évaluation), et l'on jette tout morceau dont la borne optimiste est déjà moins bonne que la meilleure solution trouvée.

Les trois mots
  • Séparation (branch) : fixer une variable binaire à 0 ou à 1, ce qui coupe l'ensemble admissible en deux.
  • Évaluation (bound) : résoudre une relaxation du sous-problème — le programme linéaire continu (c'est ici que sert tout le chapitre, et le simplexe), ou une relaxation lagrangienne. Pour le relaxé continu, la borne vient de ce que relâcher agrandit l'ensemble admissible (L12) ; pour la relaxation lagrangienne, c'est la dualité faible (T9, L4).
  • Coupe (cut) : ajouter une inégalité valide pour toutes les solutions entières mais violée par la solution relâchée courante — par exemple une contrainte de sous-tour violée, ou une coupe de Gomory. Chaque coupe resserre la relaxation vers l'enveloppe entière (widget « arrondir »).
La relaxation lagrangienne en deux lignes — approfondissement

Pour $\min\{c\cdot x : x\in X,\ Dx\le d\}$, où les contraintes $Dx\le d$ sont « difficiles » et $X$ « facile » (par exemple des arbres couvrants pour le voyageur, d'où la borne du 1-arbre de Held et Karp), on dualise les contraintes difficiles : pour tout $\lambda\ge0$, $G(\lambda)=\min_{x\in X}\big(c\cdot x+\lambda\cdot(Dx-d)\big)$ minore l'optimum (dualité faible), et l'on maximise $G$ en $\lambda$ — par exemple par l'algorithme du sous-gradient du chapitre 3 (guide 1), puisque $G$ est concave non différentiable.

Ces contraintes sont linéaires : un modèle logique devient un programme linéaire en variables binaires. Sa relaxation ($0\le x\le1$) est un programme linéaire ordinaire, résolu par le simplexe et utilisé pour borner, puis séparer — la boucle complète de la séparation-évaluation.

Un polyèdre à 2n−m sommets

Montrer que l'on peut choisir la matrice $A$ de taille $m\times n$ et le vecteur $b\in\R^m$ de telle façon que $X_{ad}$ soit le cube unité $[0,1]^{n-m}$ dans le sous-espace affine de dimension $n-m$ défini par $Ax=b$. En déduire que le nombre de sommets de $X_{ad}$ est alors $2^{n-m}$.

Réflexe. Une borne $0\le x_i\le1$ s'écrit en forme standard avec un écart : $x_i+s_i=1$, $x_i,s_i\ge0$. Un cube de dimension $d$ demande donc $d$ équations et $2d$ variables.

OutilsL7 forme standardLemme 4.2.5L1
Indice

Corrigé

Remarque sur l'énoncé. La construction n'est possible que si $n\le2m$ : un cube de dimension $d=n-m$ a $2d$ faces de dimension $d-1$ ; or les faces de $X_{ad}$ de cette dimension sont de la forme $X_{ad}\cap\{x_j=0\}$, une par indice $j$ au plus. Il faut donc $2d\le n$, soit $n\le2m$. On suppose cette condition.

1. Construction. Posons $d=n-m\le m$ et, en blocs,

$$A=\begin{pmatrix}\mathrm{Id}_d&\mathrm{Id}_d&0\\0&0&\mathrm{Id}_{m-d}\end{pmatrix},\qquad b=(1,\dots,1)\in\R^m .$$

2. C'est un cube. L'application affine $\varphi(x')=(x',1-x',1)$ est injective et envoie $[0,1]^d$ sur $X_{ad}$ ; $X_{ad}$ est donc une copie affine du cube $[0,1]^d$, contenue dans le sous-espace affine $\{Ax=b\}$ de dimension $n-m=d$.

3. Les sommets. Une bijection affine préserve les combinaisons convexes, donc les points extrémaux. Ceux du cube sont les points de $\{0,1\}^d$ : si une coordonnée $x'_i\in\,]0,1[$, $x'$ est le milieu de $x'\pm\eps e_i$ (L1) ; et un point de $\{0,1\}^d$ n'est milieu d'aucun segment du cube (chaque coordonnée est à une extrémité de $[0,1]$). 4. Vérification par les bases. En un sommet, pour chaque $i\le d$, exactement une des deux variables $x'_i$, $s_i$ vaut 1 et l'autre 0 ; les $z$ valent 1. Les variables non nulles sont $d+(m-d)=m$ : chaque sommet est une solution basique non dégénérée, avec $2^d$ choix de bases admissibles.

À retenir. Le nombre de sommets d'un polyèdre en forme standard peut atteindre l'ordre de $\binom nm$, exponentiel : le simplexe n'énumère pas, il descend.

4. Conséquence. Primal et dual jouent des rôles symétriques ; c'est ce qui permet, dans la preuve du Théorème 4.2.13, de traiter « le dual a une valeur finie » comme « le primal a une valeur finie ».

À retenir. La dualité linéaire est une involution : le dual du dual est le primal.

Exercice 4.2.10

Forme inégalités et écarts complémentaires

niveau 2

Soit $c,v\in\R^n$, $A$ une matrice $m\times n$ et $b\in\R^m$. On considère $\inf\{c\cdot v : v\ge0,\ Av\le b\}$ (4.21). Montrer que le dual peut se mettre sous la forme $\sup\{-b\cdot q : q\ge0,\ A^*q+c\ge0\}$ (4.22), avec $q\in\R^m$. Soient $v$, $q$ admissibles pour (4.21) et (4.22). Montrer qu'ils sont optimaux si et seulement si $(c+A^*q)\cdot v=0$ et $(b-Av)\cdot q=0$ (4.23) — conditions des écarts complémentaires primales et duales.

Réflexe. Dualiser $Av-b\le0$ avec $q\ge0$ en gardant $v\ge0$ ; puis écrire le saut comme somme de deux produits positifs (L5).

OutilsL5L7Th. 4.2.13
Indice

Identité : $c\cdot v+b\cdot q=(c+A^*q)\cdot v+(b-Av)\cdot q$.

Corrigé

1. Le dual. $L(v,q)=c\cdot v+q\cdot(Av-b)$ sur $v\ge0$, $q\ge0$. Fonction duale : $\inf_{v\ge0}\big(-b\cdot q+(c+A^*q)\cdot v\big)=-b\cdot q$ si $c+A^*q\ge0$, $-\infty$ sinon. D'où (4.22). (Même résultat en passant par la forme standard avec un écart $s$ : $Av+s=b$, $(v,s)\ge0$ ; le dual standard $\max\{b\cdot p : A^*p\le c,\ p\le0\}$ devient (4.22) avec $q=-p$.)

2. L'identité clé. Pour tous $v,q$ : $c\cdot v+b\cdot q=(c+A^*q)\cdot v-q\cdot Av+b\cdot q=(c+A^*q)\cdot v+(b-Av)\cdot q$. Pour $v,q$ admissibles, les deux termes sont des produits de vecteurs $\ge0$ : $c\cdot v\ge-b\cdot q$ (dualité faible).

3. (4.23) ⇒ optimaux. Si les deux produits sont nuls, $c\cdot v=-b\cdot q$ ; par la dualité faible, aucun $v'$ ne fait moins que $-b\cdot q$ et aucun $q'$ ne fait plus que $c\cdot v$ : les deux sont optimaux.

4. Optimaux ⇒ (4.23). Les deux problèmes sont admissibles, donc de valeurs finies, et en dualité (étape 1) : par le Théorème 4.2.13 (appliqué à la forme standard), leurs valeurs sont égales. Pour $v,q$ optimaux, $c\cdot v+b\cdot q=0$, somme de deux termes $\ge0$ : chacun est nul.

5. Lecture. Comme les vecteurs sont $\ge0$, « produit scalaire nul » se lit composante par composante : $v_j\gt0\Rightarrow(c+A^*q)_j=0$ (la contrainte duale $j$ est serrée) ; $q_i\gt0\Rightarrow(Av)_i=b_i$ (la contrainte primale $i$ est serrée).

À retenir. Le saut de dualité est toujours une somme de produits « variable × écart » ; il est nul si et seulement si chaque produit l'est.

Exercice 4.3.1

Les matrices d'intervalles sont totalement unimodulaires

niveau 3

Soit $A\in\mathbb Z^{m\times n}$ telle que les premiers éléments de chacune de ses colonnes sont des 1 et tous les autres des 0 : pour tout $1\le j\le n$, il existe $n_j\in\mathbb N$ tel que $a_{ij}=1$ pour $1\le i\le n_j$ et $a_{ij}=0$ pour $n_j+1\le i\le m$. Montrer qu'une telle matrice (appelée matrice d'intervalles) est totalement unimodulaire. Indication : on vérifiera qu'il suffit de démontrer le résultat pour des matrices carrées et on fera une récurrence sur la taille de la matrice.

Réflexe. La propriété « des 1 en haut de chaque colonne » passe aux sous-matrices. Puis une opération sur les lignes de déterminant 1 — remplacer chaque ligne par sa différence avec la suivante — transforme chaque colonne en un vecteur de base : Poincaré, ou presque.

OutilsDéf. 4.3.2Poincaré 4.3.5L10widget TU
Indice

Pour une matrice carrée $M$ de ce type, d'ordre $k$, multipliez à gauche par $T=\mathrm{Id}-J$, où $J$ a des 1 juste au-dessus de la diagonale : la ligne $r$ de $TM$ est « ligne $r$ moins ligne $r+1$ ». Que deviennent les colonnes ?

Corrigé

1. Réduction aux matrices carrées du même type. Une sous-matrice carrée $M$ s'obtient en gardant des lignes $i_1\lt\dots\lt i_k$ et des colonnes $j_1,\dots,j_k$. Dans chaque colonne gardée, les 1 de $A$ occupent les lignes $1$ à $n_j$, donc parmi les lignes gardées ils occupent les premières (celles d'indice $\le n_j$) : $M$ a encore « des 1 en haut, des 0 en bas » dans chaque colonne. Il suffit donc de montrer : toute matrice carrée de ce type a un déterminant dans $\{0,\pm1\}$.

2. Différences de lignes. Soit $M$ carrée d'ordre $k$ de ce type, et $T$ la matrice d'ordre $k$ avec des 1 sur la diagonale et des $-1$ juste au-dessus. $T$ est triangulaire à diagonale unité : $\det T=1$, donc $\det(TM)=\det M$. La ligne $r$ de $D=TM$ est (ligne $r$ de $M$) $-$ (ligne $r+1$ de $M$) pour $r\lt k$, et la dernière ligne est inchangée.

3. Les colonnes de $D$. Une colonne de $M$ vaut $(1,\dots,1,0,\dots,0)$ avec $h$ uns. Les différences successives valent $0$ partout sauf en $r=h$, où l'on trouve $1-0=1$ (si $h=k$, c'est la dernière ligne, inchangée, qui vaut 1). Donc chaque colonne de $D$ est soit nulle ($h=0$), soit un vecteur de base $e_h$.

4. Conclusion. Si une colonne de $D$ est nulle, ou si deux colonnes sont égales (même $h$), $\det D=0$. Sinon les colonnes sont $k$ vecteurs de base distincts : $D$ est une matrice de permutation, $\det D=\pm1$. Dans tous les cas $\det M=\det D\in\{0,\pm1\}$.

5. La récurrence suggérée par le livre (variante). Si une colonne de $M$ est nulle, $\det M=0$. Sinon, soit $j$ une colonne ayant le moins de 1, disons $h\ge1$. Soustraire la colonne $j$ des autres ne change pas le déterminant et laisse dans chaque autre colonne $j'$ des 1 dans les lignes $h+1$ à $h_{j'}$ seulement. La ligne 1 n'a plus qu'un coefficient non nul, le 1 de la colonne $j$ : en développant selon elle, $\det M=\pm\det M'$, où $M'$ est $M$ privée de la ligne 1 et de la colonne $j$. Si $h\ge2$, la première ligne de $M'$ (la ligne 2 de $M$) est nulle, car dans les autres colonnes les 1 commencent à la ligne $h+1\ge3$ : $\det M=0$. Si $h=1$, chaque colonne de $M'$ a ses 1 en haut : $M'$ est du même type, d'ordre $k-1$, et la récurrence conclut. L'argument des différences de lignes fait tout cela en une fois.

6. Généralisation utile : 1 consécutifs. Si chaque colonne a ses 1 sur des lignes consécutives (pas forcément en haut), les mêmes différences de lignes donnent dans chaque colonne un $+1$ (en bas de l'intervalle) et un $-1$ (juste au-dessus du début) : chaque colonne de $D$ vérifie le critère de Poincaré, donc $\det M=\det D\in\{0,\pm1\}$. C'est le cas de la matrice $U$ du centre d'appels (diapo 24 : « $U$ est totalement unimodulaire »).

À retenir. Pour montrer qu'une matrice est TU : stabilité par extraction, puis une transformation de déterminant $\pm1$ qui ramène à Poincaré.

Indice

Établissez une correspondance entre les flots de $s$ à $p$ de valeur $v$ dans $\mathcal G$ et les flots (à $b=0$) de $\mathcal G'=\mathcal G+(p,s)$ ayant $x_{ps}=v$ ; comparez les coûts.

Corrigé

1. Le nouveau problème. $\mathcal G'$ = $\mathcal G$ plus l'arc $(p,s)$, de capacité $u_{ps}=+\infty$ et de coût $-1$ ; tous les autres coûts sont nuls ; flots extérieurs $b'_i=0$ partout. Problème : $\min\,-x_{ps}$ sous Kirchhoff (à $b'=0$) et $0\le x\le u$.

À retenir. Un arc de retour de coût $-1$ convertit un problème de valeur en problème de coût.

Exercice 4.3.3

Le plus court chemin est un flot à coût minimum

niveau 2

Dans le graphe orienté $\mathcal G$ avec une source $s$ (sans prédécesseur) et un puits $p$ (sans successeur), chaque arc a un coût $c_{ij}\ge0$, vu comme une distance. Le problème du chemin de coût minimum est de trouver une suite de nœuds consécutifs reliant $s$ à $p$ de longueur totale minimale. Montrer qu'il se modélise comme un flot à coût minimum avec les flots externes (4.34) pour $v=1$ et des capacités infinies.

Réflexe. Un chemin, c'est une unité de flot de $s$ à $p$. Dans l'autre sens, un flot unitaire entier se décompose en un chemin plus des cycles (un flot fractionnaire, en une combinaison convexe de chemins, plus des cycles), et les cycles ne coûtent rien de négatif.

OutilsKirchhoffTh. 4.3.7remarques des diapos
Indice

Prenez un flot optimal entier (Théorème 4.3.7). Partez de $s$ et suivez des arcs de flot positif : vous arrivez en $p$ ou vous bouclez.

Corrigé

1. Le modèle. $\min\sum c_{ij}x_{ij}$ sous Kirchhoff avec $b_s=1$, $b_p=-1$, $b_i=0$ ailleurs, et $x\ge0$ (capacités infinies).

2. Un chemin est un flot. Pour un chemin $s=i_0\to i_1\to\dots\to i_r=p$, posons $x=1$ sur ses arcs, $0$ ailleurs. En $s$ : une unité sort, $b_s=1$ ✓ ; en $p$ : une unité arrive, $b_p=-1$ ✓ ; en un nœud intermédiaire : une entre, une sort ✓. Coût = longueur du chemin. Donc $\min(\text{flot})\le\min(\text{chemin})$.

3. Un flot optimal contient un chemin aussi bon. Les coûts sont $\ge0$, donc le coût est minoré par $0$ ; s'il existe un chemin de $s$ à $p$, il existe un flot optimal (Lemme 4.2.3), et même un flot optimal entier (Théorème 4.3.7). Partons de $s$ : $s$ émet une unité, donc un arc sortant porte $x\ge1$ ; en tout nœud $i\ne p$ où l'on arrive, Kirchhoff ($b_i=0$) donne un arc sortant de flux positif. On avance ainsi jusqu'à atteindre $p$, ou jusqu'à revenir sur un nœud déjà vu.

4. Retirer les cycles. Si l'on boucle, on a trouvé un cycle d'arcs de flux $\ge1$ ; lui retirer une unité conserve Kirchhoff et la positivité, et change le coût de $-(\text{longueur du cycle})\le0$. On recommence : le flux total diminue, cela s'arrête. On obtient un chemin $P$ de $s$ à $p$ contenu dans le support, et $\mathbb 1_P$ (une unité sur $P$) a un coût $\le$ celui du flot de départ (les arcs ont des coûts $\ge0$ et le reste du flot est une circulation de coût $\ge0$).

5. Conclusion. $\min(\text{flot})=\min(\text{chemin})$, et la solution basique optimale trouvée par le simplexe est un chemin (son support ne contient pas de cycle). C'est la diapo 43 : chemin de coût minimum = flot de coût minimum avec $x_{ij}\in\{0,1\}$, $b_s=-b_p=1$.

6. Pourquoi $c\ge0$. Avec un cycle de longueur négative et des capacités infinies, faire tourner le flot autour du cycle fait descendre le coût sans fin : valeur $-\infty$, et le modèle ne décrit plus un chemin. Avec $c\ge0$, l'algorithme de Dijkstra fait le même travail bien plus vite (diapo 45).

À retenir. Décomposition d'un flot entier de valeur 1 : un chemin plus des cycles. Avec des coûts positifs, les cycles ne servent à rien.

Coût minimal $940$ centaines d'euros, soit $94\,000$ €. Solution entière, comme le garantit le Théorème 4.3.7. Lecture du coût réduit $2$ : faire livrer une voiture de $U_2$ à $C_1$ coûterait 200 € de plus, une fois le reste du plan réajusté.

À retenir. Pour un flot, une base est un arbre d'arcs, un pivot fait tourner le flot le long du cycle créé par l'arc entrant, et les coûts réduits se calculent avec des « potentiels » $p_i$ aux nœuds (la méthode des potentiels, c'est le simplexe spécialisé aux flots).

Synthèse

La méthode, pas à pas

Le plan attendu à l'examen pour un programme linéaire, avec à chaque étape le résultat à citer, puis un exemple traité de bout en bout.

  1. Modéliser. Variables (avec leur signe), contraintes, objectif ; vérifier que tout est linéaire. Si des quantités doivent être entières, le noter (étape 7).
  2. Mettre en forme. Pour le simplexe : forme standard (L7) ; repérer une base évidente (écarts avec $b\ge0$, colonnes identité), sinon phase I ((4.8)) — ou passer au dual si ses contraintes sont plus commodes (centre d'appels).
  3. Existence. $X_{ad}\ne\emptyset$ (exhiber un point) et valeur minorée (borne évidente, ou un point dual admissible) : le Lemme 4.2.3 donne une solution optimale, sans aucune compacité.
  4. Résoudre. Deux variables : dessin et sommets (Prop. 4.2.6). Sinon : simplexe, en notant à chaque pas base, $x_B$, $p$, $\tilde c_N$, ratios (algorithme). Beaucoup de variables et peu de contraintes : résoudre le dual au dessin (Ex. 4.2.7).
  5. Certifier. Écrire le dual (table), trouver $\bar p$ par les écarts complémentaires, vérifier $\bar p$ admissible et $c\cdot\bar x=b\cdot\bar p$ (Rem. 4.2.14). Au simplexe, $\bar p=(B^{-1})^*c_B$ est déjà calculé.
  6. Interpréter. Les $\bar p_i$ sont des prix marginaux : effet d'une unité de plus de la ressource $i$ (tant que la base optimale ne change pas). Une contrainte non active a un prix nul ($\bar p_i=0$) ; la réciproque est fausse : une contrainte active peut avoir un prix nul.
  7. Entiers ? Si $A$ est TU (Poincaré, intervalles, graphe) et $b$ entier, le sommet trouvé est entier (Prop. 4.3.3). Sinon : la relaxation borne, une solution arrondie borne de l'autre côté, et l'on sépare (séparation-évaluation).
