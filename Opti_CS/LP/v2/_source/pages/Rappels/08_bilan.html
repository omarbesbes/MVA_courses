8. Bilan : quel rappel sert où

La page en quelques lignes
  • Algèbre linéaire. Une base du cours, ce sont $m$ colonnes indépendantes de $A$ ; $x_B=B^{-1}b$ sont les coordonnées de $b$ dans cette base ; un pivot du simplexe est un pivot de Gauss–Jordan ; Cramer et « déterminant entier » expliquent les solutions entières ; $p\cdot Ax=A\T p\cdot x$ fait toute la dualité faible.
  • Convexité. $\Xad$ est un polyèdre convexe ; borné, c'est l'enveloppe convexe de ses sommets ; une fonction linéaire (ou concave) y est minimale en un sommet, pas une fonction convexe ; un cône engendré par un nombre fini de vecteurs est fermé.
  • Analyse. $\inf\emptyset=+\infty$ ; fermé + borné (ou infini à l'infini) + continu donne un minimum (Th. 2.2.1) ; une suite minimisante se borne, s'extrait, passe à la limite.
  • Optimisation. Lagrangien = coût + prix des contraintes ; KKT : $-J'(u)$ est une combinaison positive des gradients des contraintes actives ; point-selle ⇔ égalité des valeurs primale et duale ; Farkas : $b$ est dans le cône, ou un hyperplan l'en sépare ; Newton converge quadratiquement près de la solution ; pénaliser, c'est remplacer une contrainte par une amende ou un mur.
  • Graphes, complexité, entiers. Dijkstra fixe les nœuds du plus proche au plus lointain si les coûts sont positifs ; $2^n$, $n!$, $\binom nm$ explosent là où $n^3$ reste raisonnable ; un entier qui divise $1$ vaut $\pm1$ ; arrondir ne suffit pas.

Réflexes

  • Quand vous voyez $x_B=B^{-1}b$ → pensez « coordonnées de $b$ dans la base des colonnes de $B$ » ; admissible si elles sont $\ge0$.
  • Quand vous voyez $p\cdot Ax$ → faites passer $A$ de l'autre côté : $A\T p\cdot x$.
  • Quand on vous demande si une solution est entière → Cramer : un quotient de deux déterminants entiers.
  • Quand un énoncé dit « $J$ convexe, donc minimum en un sommet » → méfiance : c'est vrai pour $J$ concave ou linéaire.
  • Quand il faut prouver qu'un minimum existe → suite minimisante, bornée, sous-suite, limite admissible, continuité.
  • Quand vous écrivez un Lagrangien → vérifiez le sens des contraintes et le signe des multiplicateurs.
  • Quand un système $Ax=b$, $x\ge0$ n'a pas de solution → cherchez un certificat de Farkas $w$ : $A\T w\le0$, $b\cdot w>0$.
  • Quand un algorithme énumère des sous-ensembles ou des permutations → il est exponentiel ; comptez avant de lancer le calcul.

Notes sur les sources

Les coquilles et imprécisions rencontrées en écrivant cette page, chacune vérifiée :

  1. Diapo 20, « Pour $J$ convexe $\min_PJ=\min_SJ$ » : il faut $J$ concave (ou linéaire). Contre-exemple : $x^2$ sur $[-1,1]$, minimum $0$ en $0$, valeur $1$ aux sommets (§2).
  2. Diapo 20, « $P$ est l'enveloppe convexe de ses sommets » : vrai si $P$ est borné. Contre-exemple : le quadrant $\{x\ge0\}$, de seul sommet $0$ (§2).
  3. Diapo 21, « Si $A$ inversible » : il faut $A$ à coefficients entiers (le livre le dit). Contre-exemples : $\mathrm{diag}(\frac12,2)$ et $(\frac12)$ (§7).
  4. Diapo 5, « l'ensemble admissible est un cône fermé » : le cône fermé utilisé est $\{(c\cdot x,Ax) : x\ge0\}$ ; $\Xad$ n'est un cône que si $b=0$ (§2).
  5. Allaire, p. 122 (preuve du Lemme 4.2.3), « D'après le Lemme de Farkas 2.5.19 le cône $C$ est fermé » : la fermeture n'est pas dans l'énoncé du lemme mais dans la première étape de sa démonstration (p. 43) (§2).
  6. Allaire, p. 132, « Théorème de dualité 2.6.12 » (deux fois) : au chapitre 2, 2.6.12 est un Corollaire ; le théorème de dualité est le Théorème 2.6.9 (p. 52) (§4).
  7. Diapo 49, sac-à-dos « NP-complet (difficile). Complexité exponentielle » et contrainte $p\cdot x§6). Le guide v1 situe cette coquille Diapo 46 : elle est sur les Diapos 49–51.
  8. Diapo 46, « algorithme de parcourt de graphe » : lire « parcours ».
  9. Allaire, p. 102, première ligne du §3.5 : « La méthode de Netwon » pour « Newton ».
