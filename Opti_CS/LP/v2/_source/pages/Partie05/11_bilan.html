11. Bilan

La partie sur un écran
  1. Le problème (§1) : pour certifier un optimum, il faut une borne inférieure ; combiner les contraintes avec des poids $p$ admissibles en donne une, $b\cdot p$ ; la meilleure est un programme linéaire, le dual.
  2. Le dual (§2, diapo 13–14, (4.15)–(4.18)) : $L(x,p)=c\cdot x+p\cdot(b-Ax)$ ; $G(p)=\min_{x\ge0}L=p\cdot b$ si $c-A\T p\ge0$, $-\infty$ sinon ; dual $\max\{b\cdot p : A\T p\le c\}$, $p$ libre. Pour les autres formes : le tableau des règles de passage.
  3. Dualité faible (§3, Rem. 4.2.14) : $c\cdot x-b\cdot p=x\cdot(c-A\T p)\ge0$ ; bornes ; certificat $c\cdot\bar x=b\cdot\bar p$ ; non borné $\Rightarrow$ l'autre vide.
  4. Théorème de dualité (§4, diapo 14, Th. 4.2.13) : une valeur finie $\Rightarrow$ deux solutions optimales de même valeur, point-selle du Lagrangien ; optimalité $\iff$ (4.20) ; quatre situations possibles. Preuve : KKT (contraintes affines, toujours qualifiées) pour le primal ; Farkas pour le dual, en vérifiant tout le cône.
  5. Écarts complémentaires (§5) : $\bar x_j=0$ ou $(A\T\bar p)_j=c_j$ ; en forme inégalités, aussi $\bar p_i=0$ ou contrainte $i$ serrée. Méthode : candidat $\to$ équations $\to$ $p$ $\to$ test.
  6. Simplexe (§6) : $p=B^{-\top}c_B$, $c-A\T p=(0,\ct_N)$ ; chaque base vérifie les écarts complémentaires et $c\cdot x=b\cdot p$ ; le simplexe s'arrête quand $p$ est admissible pour le dual.
  7. Prix (§7) : $\bar p_i=\partial V/\partial b_i$ tant que la base ne change pas ; $V$ linéaire par morceaux (convexe pour un $\min$, concave pour un $\max$) ; points anguleux $\leftrightarrow$ dual non unique.
  8. Centre d'appels (§8, diapo 15) : $\min S\cdot x$, $Ux\ge c$ ; dual réduit à $(p_2,p_4)$ et résolu au dessin : $\bar p=(4,0,0,5,1)$, $\bar x=(5,8,4)$, coût 84 ; $\bar p_j$ = coût d'un client de plus sur $I_j$.

Les réflexes à acquérir

  • Prouver qu'un $\bar x$ est optimal → exhiber $\bar p$ admissible avec $b\cdot\bar p=c\cdot\bar x$.
  • Écrire un dual → une variable par contrainte (signe selon le sens), une contrainte par variable (sens selon le signe), transposer, échanger $b$ et $c$, $\min\leftrightarrow\max$.
  • Calculer $G(p)$ → regrouper selon $x$ ; une composante négative de $c-A\T p$ donne $-\infty$.
  • Un $x$ et un $p$ admissibles → la valeur optimale est dans $[b\cdot p,\ c\cdot x]$.
  • Un problème non borné → l'autre est vide (pas l'inverse : les deux peuvent être vides).
  • Un candidat → écarts complémentaires → $p$ → test d'admissibilité ; en un sommet dégénéré, chercher parmi toutes les solutions.
  • Peu de contraintes, beaucoup de variables → résoudre le dual (au dessin s'il a deux variables), puis revenir au primal.
  • Des variables duales qui n'apparaissent qu'une fois → les éliminer (centre d'appels).
  • Coûts réduits $\ge0$ → $p=B^{-\top}c_B$ admissible → valeur certifiée.
  • « Combien vaut une unité de plus ? » → le prix dual, dans son domaine de validité ; au-delà, recalculer.

Et ensuite

  • Partie 6 (nombres entiers) : pourquoi le planning du centre d'appels est entier (totale unimodularité de $U$, diapo 24), et pourquoi, en général, la relaxation linéaire et sa dualité ne donnent qu'une borne.
