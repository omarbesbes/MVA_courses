4. Le vocabulaire : admissible, optimal, valeur optimale Diapo 4 ; Allaire Rem. 4.2.2, p. 122

Une solution admissible vérifie les contraintes, une solution optimale atteint en plus le meilleur coût, la valeur optimale est ce meilleur coût ; et un programme linéaire n'a que trois issues : rien d'admissible, valeur $-\infty$, ou optimum atteint.

Les mots du cours

Dans le cours Diapo 4

Définition

  1. Un point $x\in X_{ad}$ est dit solution admissible
  2. Un sommet de $X_{ad}$ est appelé solution extrémale.
Dans le livre Allaire, Rem. 4.2.2, p. 122

Le vocabulaire de l'optimisation est trompeur pour les néophytes. On appelle solution (admissible) un vecteur qui satisfait les contraintes. Par contre, un vecteur qui atteint le minimum de (4.1) est appelé solution optimale (ou point de minimum).

solution admissible
N'importe quel point de $\Xad$ : il respecte toutes les contraintes, sans être forcément bon. Le mot « solution » est trompeur : une solution admissible ne résout rien.
solution extrémale
Un sommet de $\Xad$ (Déf. 4.2.1, §3). Le livre dit « sommet » ou « point extrémal ».
solution optimale $\bar x$
Un point admissible de coût minimal : $\bar x\in\Xad$ et $c\cdot\bar x\le c\cdot x$ pour tout $x\in\Xad$.
valeur optimale
Le nombre $\inf_{x\in\Xad}c\cdot x$, qui peut valoir $\pm\infty$ (ci-dessous). C'est le coût d'une solution optimale quand il y en a une.
« résoudre » un PL
Trouver la valeur optimale et une solution optimale, ou montrer qu'il n'y en a pas (et dire pourquoi : $\Xad$ vide ou valeur $-\infty$).
Exemple — l'atelier
  • $(20,20)$ est admissible : 60 h de machine, 40 h de main-d'œuvre, 80 panneaux, tout est disponible. Mais il ne rapporte que 1400 €.
  • $(30,40)$ est admissible et optimal, et c'est aussi un sommet (une solution extrémale).
  • $(40,40)$ n'est pas admissible : il demande 120 h de machine sur 100.
  • La valeur optimale est 2400 € (pour le $\max$) ; sous forme standard, $\min(-40x_1-30x_2)=-2400$.

Une solution optimale n'est pas forcément unique : pour l'Exercice 4.2.1 avec le coût $x_1+x_2$, tout le côté de $(5,0)$ à $(2,3)$ est optimal (widget du §3). La valeur optimale, elle, est unique.

La valeur optimale et ses conventions

Dans le livre Allaire, p. 122

Lorsque $X_{ad}$ est vide, par convention on note que

$$\inf_{x\in\R^n\text{ tel que }Ax=b,\ x\ge0}c\cdot x=+\infty.$$

Cette convention est celle du chapitre 2 (Allaire, Déf. 2.1.2, p. 14) : l'infimum est le plus grand des minorants ; si $c\cdot x$ n'est pas minorée sur $\Xad$, il vaut $-\infty$ ; si $\Xad$ est vide, tout nombre est un minorant (il n'y a rien à minorer), donc le plus grand minorant est $+\infty$. Elle a un sens concret : ajouter des contraintes ne peut qu'augmenter la valeur d'un problème de minimisation, et des contraintes incompatibles le rendent « infiniment cher ».

Définition — valeur optimale
$$\begin{aligned}&V=\inf_{x\in\Xad}c\cdot x\ \in\ \R\cup\{-\infty,+\infty\},\\&V=+\infty\iff\Xad=\emptyset,\qquad V=-\infty\iff c\cdot x\text{ n'est pas minorée sur }\Xad\ne\emptyset.\end{aligned}$$

La valeur est finie quand $-\infty

Les trois issues d'un programme linéaire

Trois situations sont évidemment possibles : il n'y a aucun point admissible ; il y en a, mais le coût descend sans fin ; il y en a, et un meilleur point existe. Une quatrième serait possible pour un problème quelconque : la valeur est finie mais n'est pas atteinte, comme pour $\inf_{x\ge0}e^{-x}=0$. Pour un programme linéaire, elle ne se produit jamais : c'est le Lemme 4.2.3 (§5).

Les trois issues (conséquence du Lemme 4.2.3)

Pour un programme linéaire, une et une seule des situations suivantes se produit :

  1. $\Xad=\emptyset$ : le problème est irréalisable (infeasible), $V=+\infty$ ;
  2. $\Xad\ne\emptyset$ et $V=-\infty$ : le problème est non borné (unbounded), il n'a pas de solution optimale ;
  3. $V$ est finie, et il existe au moins une solution optimale.
Exemple — les trois issues, vérifiées
  • (a) Si $x_1+x_2\le1$ et $x_1+x_2\ge3$, alors $3\le x_1+x_2\le1$ : impossible. linprog répond « The problem is infeasible ».
  • (b) Les points $(t,t)$, $t\ge0$, sont admissibles ($-t+t=0\le1$, $t-t=0\le2$) et coûtent $-2t\to-\infty$. Réponse : « The problem is unbounded ».
  • (c) La bande a trois sommets, $(0,0)$, $(0,1)$ et $(2,0)$, où $-x_1+2x_2$ vaut $0$, $2$ et $-2$. Le long de ses deux demi-droites (direction $(1,1)$), le coût augmente de $1$ par unité de $t$. Le minimum est $-2$, en $(2,0)$ ; linprog renvoie $x=(2,0)$ et la valeur $-2$.
Piège — « $\Xad$ non borné » n'est pas « valeur $-\infty$ »

Les figures (b) et (c) ont le même ensemble admissible, non borné ; seule la direction du coût change. Un ensemble non borné permet une valeur $-\infty$, il ne l'impose pas. Dans l'autre sens, une valeur $-\infty$ exige un $\Xad$ non borné : sur un polyèdre borné (fermé, donc compact), une fonction continue atteint son minimum.

Réflexe

Avant de chercher un optimum, posez-vous les deux questions dans l'ordre : y a-t-il un point admissible ? (sinon, $V=+\infty$) ; y a-t-il une demi-droite admissible le long de laquelle le coût baisse ? (si oui, $V=-\infty$). Pour un programme linéaire, c'est même la seule façon d'avoir $V=-\infty$ : on l'admet ici, c'est une conséquence du lemme de Farkas et de la dualité faible (partie 5). Si les deux réponses sont « oui » puis « non », la valeur est donc finie, et un optimum existe : c'est le Lemme 4.2.3 (§5).

Pour chacun de ces programmes ($x\in\R^2$), quelle est l'issue ? (i) $\min x_1$ sous $x_1+x_2=1$, $x\ge0$. (ii) $\min -x_1$ sous $x_1-x_2=0$, $x\ge0$. (iii) $\min x_1$ sous $x_1+x_2=-1$, $x\ge0$.

Réponse

(i) Optimum atteint : $x_1\ge0$ donc $V\ge0$, et $(0,1)$ est admissible de coût $0$ ; $V=0$. (ii) Non borné : $(t,t)$ est admissible et coûte $-t\to-\infty$. (iii) Irréalisable : $x_1+x_2\ge0>-1$ pour tout $x\ge0$ ; $V=+\infty$.
