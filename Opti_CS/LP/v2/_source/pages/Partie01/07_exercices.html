On le résout ici graphiquement et par énumération des sommets ; sa résolution par l'algorithme du simplexe, sur la forme standard (c'est l'Exercice 4.2.3 du livre), est dans la partie 3. Exercice 4.2.1 du livre — résoudre un programme linéaire à deux variables ★
Dans le livre Allaire, Exercice 4.2.1, p. 124

Résoudre le programme linéaire suivant

$$\max_{x_1\ge0,\,x_2\ge0}\ x_1+2x_2$$

sous les contraintes

$$\left\{\begin{aligned}-3x_1+2x_2&\le2,\\-x_1+2x_2&\le4,\\x_1+x_2&\le5.\end{aligned}\right.$$
Indice

Dessinez les trois droites et les axes, hachurez le polygone admissible, puis faites glisser la ligne de niveau $x_1+2x_2=k$ dans la direction $c=(1,2)$ (méthode du §3). Calculez les coordonnées des sommets en résolvant des systèmes $2\times2$. Pour une preuve d'optimalité sans dessin, cherchez à écrire $x_1+2x_2$ comme une combinaison à coefficients positifs des membres de gauche de deux contraintes.

Solution

1. L'ensemble admissible. On numérote les contraintes (1) $-3x_1+2x_2\le2$, (2) $-x_1+2x_2\le4$, (3) $x_1+x_2\le5$. L'origine les vérifie toutes ($0\le2$, $0\le4$, $0\le5$) : le polygone est du côté de l'origine pour chaque droite. Il est dessiné au §3 (figure).

2. Les sommets. Un sommet est l'intersection de deux droites (parmi les trois contraintes et les deux axes) qui vérifie toutes les contraintes. Il y a $\binom52=10$ couples de droites :

Par exemple, (1) et (2) : en soustrayant $-x_1+2x_2=4$ de $-3x_1+2x_2=2$, on obtient $-2x_1=-2$, donc $x_1=1$ et $x_2=\frac{4+1}2=\frac52$. Le polygone a donc cinq sommets : $(0,0)$, $(5,0)$, $(2,3)$, $(1,\frac52)$, $(0,1)$.

3. L'optimum. Les valeurs aux sommets sont $0$, $5$, $8$, $6$, $2$. Le polygone est borné (il est dans le triangle $x\ge0$, $x_1+x_2\le5$), donc le maximum existe ; il est atteint en un sommet (§3, et partie 2). Le maximum vaut $8$, atteint au seul point $(2,3)$. Graphiquement : la ligne de niveau $x_1+2x_2=8$ ne touche le polygone qu'en $(2,3)$, et $c=(1,2)$ est strictement entre les normales $(1,1)$ de (3) et $(-1,2)$ de (2).

Piège — ne pas oublier de tester l'admissibilité

Deux intersections ont une valeur plus grande que $8$ : $(\frac85,\frac{17}5)$, qui vaut $\frac{42}5$, et $(0,5)$, qui vaut $10$. Elles ne sont pas admissibles. Énumérer des intersections sans les tester donne une réponse fausse.

4. Une preuve d'optimalité sans dessin. Pour tout point admissible $x$,

  1. $$x_1+2x_2=\tfrac13\,(-x_1+2x_2)+\tfrac43\,(x_1+x_2)$$On développe : $\big(-\frac13+\frac43\big)x_1+\big(\frac23+\frac43\big)x_2=x_1+2x_2$. Les coefficients $\frac13$ et $\frac43$ s'obtiennent en résolvant $\alpha(-1,2)+\beta(1,1)=(1,2)$.
  2. $$\le\tfrac13\cdot4+\tfrac43\cdot5=8$$Contraintes (2) et (3), multipliées par des nombres positifs (ce qui conserve le sens des inégalités).
  3. Égalité si et seulement si (2) et (3) sont serrées, c'est-à-dire $x=(2,3)$.Les deux inégalités utilisées doivent être des égalités ; leur seule solution commune est $(2,3)$.

Les multiplicateurs $(0,\frac13,\frac43)$ donnés aux contraintes (1), (2), (3) sont une solution duale : ils certifient l'optimalité sans dessin. C'est la dualité faible (partie 5) ; linprog les renvoie d'ailleurs (au signe près) dans res.ineqlin.marginals : $0$, $-\frac13$, $-\frac43$.

5. La forme standard. Avec les écarts $x_3,x_4,x_5\ge0$ (notation de l'Exercice 4.2.3 du livre) :

$$\min\ -x_1-2x_2\quad\text{s.c.}\quad\begin{pmatrix}-3&2&1&0&0\\-1&2&0&1&0\\1&1&0&0&1\end{pmatrix}x=\begin{pmatrix}2\\4\\5\end{pmatrix},\quad x\ge0,$$

avec $m=3$, $n=5$, $\rg A=3$. L'optimum est $x=(2,3,2,0,0)$ : l'écart de (1) vaut $2-(-6+6)=2$, les deux autres sont nuls. La valeur du $\min$ est $-8$, donc celle du $\max$ est $8$.

6. Vérification par script. Le script suivant (fractions exactes) refait le tableau, puis appelle le solveur :

from fractions import Fraction as F
from itertools import combinations
from scipy.optimize import linprog

cons = [(-3, 2, 2), (-1, 2, 4), (1, 1, 5), (-1, 0, 0), (0, -1, 0)]   # a x1 + b x2 <= r
noms = ["(1)", "(2)", "(3)", "x1=0", "x2=0"]
for (i, c1), (j, c2) in combinations(enumerate(cons), 2):
    (a1, b1, r1), (a2, b2, r2) = c1, c2
    det = F(a1 * b2 - b1 * a2)
    if det == 0:
        print(f"{noms[i]} et {noms[j]} : parallèles"); continue
    x = ((r1 * b2 - b1 * r2) / det, (a1 * r2 - r1 * a2) / det)
    ok = all(a * x[0] + b * x[1] <= r for a, b, r in cons)
    print(f"{noms[i]} ∩ {noms[j]} = ({x[0]}, {x[1]})  {'sommet' if ok else 'hors de Xad'}  x1+2x2 = {x[0] + 2 * x[1]}")
res = linprog([-1, -2], A_ub=[c[:2] for c in cons[:3]], b_ub=[c[2] for c in cons[:3]])
print("linprog :", res.x, -res.fun)
