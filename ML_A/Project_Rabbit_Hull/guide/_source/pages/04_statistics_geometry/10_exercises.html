Exercise 1 — Slots taken by dense concepts ★

Two concepts fire on $29\%$ of the tokens each, and $k=8$. (a) How many of the $8$ slots do they take per token on average? (b) What share of all activations? (c) How does it change if $k=32$?

Hint

The expected number of active entries among the two is $2\times0.29$. A token has $k$ slots on average.

Solution

(a) $2\times0.29=0.58$ slots per token. (b) $0.58/8=7.25\%$. (c) $0.58/32=1.8\%$: the same dense concepts weigh four times less when the code has four times more slots. This does not use independence: expectations add.

Exercise 2 — Reference values of a dictionary ★

For $c=10{,}000$ unit atoms in $d=100$: give the Welch bound, the tight-frame singular value, and the Marchenko–Pastur band for random atoms.

Hint

$\sqrt{(c-d)/(d(c-1))}$; $\sqrt{c/d}$; $\sqrt{c/d}(1\pm\sqrt{d/c})$.

Solution

Welch: $\sqrt{9900/(100\times9999)}=0.0995$. Tight frame: $\sqrt{100}=10$. $\sqrt{d/c}=0.1$, band $=10\times[0.9,1.1]=[9,11]$. Check: $\sum\sigma^2=100\times100=10{,}000=c$.

Exercise 3 — A signed feature with non-negative codes ★★

The activation is $\va=x\vu$ and the dictionary has atoms $\vu$, $-\vu$ and a third atom $\vw$ with $\ps{\vu}{\vw}=0$. (a) Give the code for $x=-2$. (b) Give $\cos$ and $\abs{\cos}$ for the antipodal pair, and the coherence of the three atoms. (c) A clustering by cosine puts the pair in the same cluster or in different clusters?

Hint

Write $x\vu=z_1\vu+z_2(-\vu)$ with $z_1,z_2\ge0$.

Solution

(a) $z=(0,2,0)$, because $2\cdot(-\vu)=-2\vu$. (b) $\cos=-1$, $\abs{\cos}=1$, coherence $\mu=\max\abs{\ps{\cdot}{\cdot}}=1$ (the pair), although the three atoms represent only two directions. (c) A cosine-distance clustering sees $\cos=-1$ as maximal distance: different clusters. Using $\abs{\cos}$ would merge them. Which is right depends on whether the sign carries meaning.

Exercise 4 — The trace identity on a small example ★★

$\mZ=\begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}$, $\mD=\begin{pmatrix}1&0\\0.6&0.8\end{pmatrix}$. Compute $\mG=\mZ\T\mZ$, $\mK=\mD\mD\T$, $\tr[\mG\mK]$ and $\norm{\mZ\mD}_F^2$.

Hint

$\tr[\mG\mK]=\sum_{ij}G_{ij}K_{ij}$ for symmetric matrices.

Solution

$\mG=\begin{pmatrix}2&1\\1&2\end{pmatrix}$, $\mK=\begin{pmatrix}1&0.6\\0.6&1\end{pmatrix}$. $\tr[\mG\mK]=2+0.6+0.6+2=5.2$. $\mZ\mD$ has rows $(1,0)$, $(0.6,0.8)$, $(1.6,0.8)$ with squared norms $1,\ 1,\ 3.2$: sum $5.2$. They agree. Note that the two diagonal terms give $4$ of the $5.2$: the diagonal dominates.

Exercise 5 — Stable rank against $R^2$ ★★

Show $\mathrm{srank}(\mP)\le2/R^2$ where $R^2$ is the share of the squared Frobenius norm held by the top two singular values. Apply it to the last layer of Fig. 14 ($R^2\approx1.00$, stable rank $2.7$) and say what follows.

Hint

Write $\sum\sigma_r^2=(\sigma_1^2+\sigma_2^2)/R^2$ and use $\sigma_2\le\sigma_1$.

Solution

$\mathrm{srank}=\sum\sigma_r^2/\sigma_1^2=(\sigma_1^2+\sigma_2^2)/(R^2\sigma_1^2)\le2\sigma_1^2/(R^2\sigma_1^2)=2/R^2$. For $R^2=1$ the bound is $2$, so $2.7$ is impossible on one matrix; even for $R^2=0.99$ it is $2.02$. The two panels are not computed on the same object (e.g. raw versus centred); the paper does not say.

Exercise 6 — Place code and axis code ★★

(a) The place code of a $16\times16$ grid is $\mP=\mI_{256}$. Compute the stable rank and the $R^2$ of the top two components of the centred matrix. (b) The axis code has two columns, the row index and the column index (centred and scaled to equal norm). Same questions. (c) Which is closer to layer 0 and which to layer 11 of Fig. 14?

Hint

Centring $\mI_{256}$ removes one direction (the all-ones vector). All remaining singular values of the centred identity equal $1$.

Solution

(a) $255$ equal singular values: stable rank $255$; $R^2=2/255=0.8\%$. (b) Two equal singular values: stable rank $2$, $R^2=1$ (the two ramps are orthogonal after centring, since rows and columns are independent coordinates). (c) Layer 0 is far from the place code too ($R^2=0.63$, stable rank $9$): even the first layer already has a few dominant directions; layer 11 is close to the axis code. The paper's place-cell wording is an analogy, not a measured match.

Exercise 7 — What a smooth PCA map implies ★★★

(a) Prove that a projection $\mP$ with orthonormal rows satisfies $\norm{\mP\vx-\mP\vy}\le\norm{\vx-\vy}$. (b) Give two tokens with identical colour in a PCA map that are far apart in $\R^{768}$. (c) What does a smooth map then prove about the tokens?

Hint

For (a): $\mP\T\mP$ is an orthogonal projector. For (b): move along a direction orthogonal to the three components.

Solution

(a) $\norm{\mP\vv}^2=\vv\T\mP\T\mP\vv=\norm{\mP\T\mP\vv}^2+\dots$; more simply $\mP\T\mP$ is the orthogonal projector onto the row space, and a projector does not increase the norm: $\norm{\mP\vv}=\norm{\mP\T\mP\vv}\le\norm{\vv}$ with $\vv=\vx-\vy$. (b) $\vy=\vx+10\,\ve$ with $\ve$ a unit vector orthogonal to the three principal directions: same three coordinates, distance $10$. (c) Only that the three coordinates vary slowly: closeness in $\R^{768}$ implies closeness in colour, not conversely. Connectedness in $\R^{768}$ needs a separate argument.

Exercise 8 — How spread is an atom with Hoyer $0.2$? ★★★

An atom has $k$ equal non-zero entries and $768-k$ zeros. For which $k$ is its Hoyer score $0.2$ (about the Gaussian value) and $0.25$? Is an atom with score $0.25$ "sparse"?

Hint

For $k$ equal entries, $\norm{\vx}_1/\norm{\vx}_2=\sqrt k$, so $H=(\sqrt n-\sqrt k)/(\sqrt n-1)$. Solve for $k$.

Solution

$\sqrt k=\sqrt n-H(\sqrt n-1)$, with $\sqrt{768}=27.71$: $H=0.2$ gives $\sqrt k=22.37$, $k\approx500$; $H=0.25$ gives $k\approx442$. So a score of $0.25$ corresponds to an atom with about $442$ of its $768$ coordinates equally active: very spread. "Slightly sparser than Gaussian" means "slightly less spread", and the atoms are far from neuron-aligned ($k=1$).
