8. The lab: how the experiments are organised

Every number of this page comes from one of eleven scripts in code/; each writes one results file with its versions, seeds and running time. The DINOv2 ones read a feature cache written once by r0_extract.py.

Data, model, conventions

  • Model. DINOv2 ViT-B/14 with 4 registers (dinov2_vitb14_reg, LVD-142M weights), and a random-weights twin (same architecture, torch.manual_seed(0), no pre-training). CPU only.
  • Data. Imagenette (ten ImageNet classes), 320 px validation split. 1,000 “statistics” images (the first 100 file names of each class, sorted) and 200 held-out images (the next 20 per class). Preprocessing: shorter side 256 (bicubic), centre crop 224, ImageNet mean and standard deviation. Each image gives 256 patch tokens; the image lists are in r0_image_lists.json.
  • Toy data. Synthetic, generated inside each script; all seeds are fixed, so a rerun reproduces the files exactly.
  • Files. Every DINOv2 JSON file has a versions block (package versions, model identifier, weights SHA-256), a written date and runtime_s. Large features live outside the repository and are written by r0_extract.py.

How to rerun

From code/: python toy/t1_chords.py (and t2–t4), then once python dino/r0_extract.py (it needs the model weights and the Imagenette validation split, and writes the cache), then python dino/rN_*.py in any order. The shared code is in code/rh/ (aa.py archetypal analysis, interp.py chord test and neighbour graph, nulls.py null models, dino.py model loading) and code/dino/common.py; code/tests/test_core.py tests the core functions.

What would be needed to go further

  • The paper's dictionary. We did not have the 32,000-atom SAE. The experiment that our analysis calls for, a test of box or simplex on its codes, needs it: for groups of atoms, do the codes fill a square or a triangle (section 2)? Ideally on factors of known value, categorical (a simplex is plausible) against continuous (position is additive across coordinates, one arc per factor, but the test cannot tell box from simplex).
  • Before the last normalisation, or with convexity understood along the ellipsoid (section 4).
  • Per-head analysis. With the attention weights as codes, look for tiles head by head, keeping in mind that all heads are active and the polytopes move with the image.
  • Scale. We used one model, 1,000 images of ten classes and at most 50,000 tokens; null models match first and second moments only. These are checks, not benchmarks.
