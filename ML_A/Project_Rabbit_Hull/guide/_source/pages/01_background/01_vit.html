1. Vision transformers

A ViT cuts the image into patches, turns each patch into a vector (a token), and repeatedly lets tokens exchange information (attention) and transform themselves (MLP), each time by adding an update to the token. The paper analyses the final token vectors of DINOv2.

1.1 From pixels to 261 tokens

Problem. A transformer takes a sequence of vectors, an image is a grid of pixels. The solution is to cut the grid into square patches and treat each patch as a word.

In the paper §2 · p. 5 and App. K · p. 52

"A pretrained Vision Transformer $f:\mathcal X\to\R^{t\times d}$": any image $\vx$ yields activations $\va=f(\vx)\in\R^{t\times d}$, "i.e. $t$ token embeddings of dimension $d$". "We used DINOv2-B with 4 registers as $f$, with $d=768$, $t=261$." The tokens are "256 spatial patches arranged in a $16\times16$ grid plus one classification token and four register tokens."

  1. $224/14=16$ patches per side, so $16^2=256$ patch tokens.patch size 14 for DINOv2 ViT-B/14.
  2. Each patch (14×14×3 = 588 numbers) is multiplied by a learned matrix to give a vector of dimension $d=768$.this is the patch embedding.
  3. A learned position embedding is added to each patch token.without it the network could not tell where a patch comes from; page 4 studies this position signal.
  4. One class token (cls) and four register tokens are added, giving $t=256+1+4=261$.they have no pixels; they are learned vectors that can store global information (§1.4).

The result is a matrix $\mX\in\R^{261\times768}$: 200,448 numbers per image and per layer. "Activations of a layer" means this matrix at that depth. In the paper's row convention one token activation is a row $\va\in\R^{768}$.

1.2 Attention: a weighted average of values

Problem. Tokens must exchange information; a patch of fur needs to know there is a rabbit elsewhere. Attention lets each token read the others.

A head of ViT-B has three learned matrices $\mW_Q,\mW_K,\mW_V\in\R^{768\times64}$. For the token matrix $\mX$:

$$\begin{aligned}\mQ&=\mX\mW_Q,\quad \mK=\mX\mW_K,\\ \mV&=\mX\mW_V\quad(261\times64\text{ each}).\end{aligned}$$

Token $i$ is the query, token $j$ offers a key (what it is) and a value (what it gives). The output of the head is

$$\begin{aligned}\mY&=\softmax\!\Big(\frac{\mQ\mK\T}{\sqrt{64}}\Big)\mV=\mA\mV,\\ \mY_i&=\sum_{j=1}^{261}\alpha_{ij}\,\mV_j,\\ \val_i&=\softmax\!\big(\mQ_i\mK\T/8\big)\in\simplex^{261}.\end{aligned}$$
$\mQ_i\mK_j\T$
score: how much token $i$ wants token $j$ (a dot product of two 64-dimensional vectors).
$/\sqrt{64}=/8$
keeps the scores of order one, so the softmax does not saturate.
$\softmax$ (per row)
turns the 261 scores into non-negative weights $\alpha_{ij}$ that sum to 1.
$\mY_i$
a weighted average of the value vectors: a point inside their convex hull. This is exactly what §7 of the paper uses (page 5). Here $\mA$ is the attention matrix, not the activations.
Reminder — softmax

$\softmax(s)_j=e^{s_j}/\sum_l e^{s_l}$: all weights are strictly positive and sum to 1, so the output is never on the boundary of the hull of the values. Dividing the scores by a small temperature makes the weights concentrate on the largest score. more

Worked example — three tokens

Scores $(2,1,0)$ give weights $(0.665,0.245,0.090)$. With 2-D values $(3,0)$, $(0,3)$, $(-3,-3)$ the output is $0.665(3,0)+0.245(0,3)+0.090(-3,-3)=(1.726,0.464)$, inside the triangle of the three values.

What to look at: raise one score: its weight tends to 1 and the output slides to that value. Lower the temperature: same effect. Put all scores equal: the output is the plain mean of the five values. The output never leaves the dashed polygon.

Multi-head. A block has $H=12$ heads of dimension 64 ($12\times64=768$). Each head has its own $\mW_Q^{(h)},\mW_K^{(h)},\mW_V^{(h)}$. The outputs are concatenated and projected back to 768 dimensions with $\mW_O$; equivalently the update is a sum over heads of $\mW_O^{(h)}$ applied to the head output, $\sum_h \mW_O^{(h)}\mY^{(h)}$. This sum is what leads to Minkowski sums on page 5.

Pitfall — the values depend on the image

The values $\mV_j=\mW_V\,\mathrm{LN}(\vx_j)$ are computed from the tokens of the current image. The convex hull of values is rebuilt for every image. Our reading, page 6.

1.3 The block and the residual stream

Problem. A deep network must stay trainable and each layer should refine, not replace, what exists. The answer is the residual connection: a layer outputs an update that is added to its input.

$$\begin{aligned}\vx'&=\vx+\gamma_1\odot\mathrm{Attn}(\LN(\vx)),\\ \vx''&=\vx'+\gamma_2\odot\mathrm{MLP}(\LN(\vx')).\end{aligned}$$
$\LN$
LayerNorm: for each token separately, subtract the mean of its 768 coordinates, divide by their standard deviation, then apply a learned scale and shift. "Pre-norm" means it is applied before the branch, not after.
$\mathrm{Attn}$
multi-head attention (§1.2): the only place where tokens interact.
$\mathrm{MLP}$
two linear layers with a GELU in between, 768→3072→768, applied to each token alone.
$\gamma_1,\gamma_2$
LayerScale: a learned per-coordinate multiplier, initialised very small, that eases training of deep networks. DINOv2 uses it (initial value $10^{-5}$ in the official configuration).

After 12 blocks a token is $\vx_{12}=\vx_0+\sum_{l}(\text{attention}_l+\text{MLP}_l)$: the residual stream is a running sum of updates. A final LayerNorm is applied to the output of the last block; the paper writes $\va=f(\vx)$, the output of the network $f$; whether this is before or after this final LayerNorm matters for the geometry (our reading, page 6).

How many numbers are in the attention matrix of one head for one image?

Answer

$261\times261=68{,}121$, one weight per (query, key) pair; each row sums to 1.

1.4 Registers

Problem. Darcet et al. (2023, arXiv:2309.16588) observed that large ViTs produce "high-norm tokens appearing during inference primarily in low-informative background areas of images": the network recycles some patch tokens to store global information, which corrupts feature maps. Their fix is to "provide additional tokens to the input sequence". These extra tokens, the registers, are never read as an output; they are free memory slots that attention can use. The paper uses the DINOv2 model with four registers (the abstract of Darcet et al. does not give the number; four is the paper's choice of model).

Why it matters here §4 · p. 9, App. K · p. 52

Registers give the dictionary a place to find concepts that are about the whole image: the paper finds concepts that fire only on register tokens and capture "global scene properties like illumination and motion blur" (page 3).
