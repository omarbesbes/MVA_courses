3. Interpretability: from neurons to concepts

One wants to know what a representation contains. Single neurons are a poor unit because each fires for several unrelated things; the likely reason is superposition, where more features than dimensions are stored as nearly orthogonal directions. The linear representation hypothesis packages this into a model that a dictionary can be fitted to.

3.1 "Where" versus "what"

Attribution methods (saliency, gradient × input, RISE, toolbox) answer where: which pixels or tokens a prediction depends on. They do not say what the model sees there. Concept-based methods answer what: they find directions of the activation space that stand for human-readable notions (fur, shadow, "left side"). The paper does both: concepts give the "what", importance scores and RISE maps give the "where" (page 3).

Why not read concepts off single neurons (coordinates)? A coordinate of the 768-dimensional token is a neuron-like unit. The paper's §2 states the empirical finding: features "behave as nearly orthogonal directions, active only in restricted contexts, while neurons themselves are polysemantic". A neuron is polysemantic when it responds to several unrelated features. This motivates two conclusions: "(i) neurons are not the appropriate locus of interpretability, and (ii) one must recover the latent basis along which the model effectively operates."

3.2 Superposition

Problem. A $d$-dimensional space has only $d$ orthogonal directions, yet a model must represent far more features (objects, textures, positions). Elhage et al. (2022, Toy Models of Superposition) show in toy networks that when features are sparse (rarely active at the same time) a model stores more features than dimensions, in superposition: each feature gets a direction, and the directions are not orthogonal. The paper cites this as "a recurring phenomenology of large models".

Worked example — interference

Take $d=2$, atoms $\vd_1=(1,0)$, $\vd_2=(-\tfrac12,\tfrac{\sqrt3}{2})$, $\vd_3=(-\tfrac12,-\tfrac{\sqrt3}{2})$, so $\vd_i\cdot\vd_j=-\tfrac12$.

  • Only feature 1 active, $\va=\vd_1$: read-outs $(1,-\tfrac12,-\tfrac12)$. The true code is $(1,0,0)$; the others read $-\tfrac12$ (interference).
  • Features 1 and 2 active, $\va=\vd_1+\vd_2=(\tfrac12,\tfrac{\sqrt3}2)$: read-outs $(\tfrac12,\tfrac12,-1)$. The true code is $(1,1,0)$: both active features read $\tfrac12$ instead of 1.

Interference is the price; sparsity is what makes it affordable: with 5 features each active with probability 0.1 independently, two or more are active together only $8.1\%$ of the time. Smaller $\max_{i\neq j}|\vd_i\cdot\vd_j|$ (the coherence) means less interference; this is why the paper asks for quasi-orthogonality and recalls optimal packings (toolbox).

3.3 The linear representation hypothesis

Linear Representation Hypothesis Def. 1 · §2 · p. 5

A representation $\va\in\R^d$ satisfies the LRH if $\va=\vz\mD$ with a dictionary $\mD\in\R^{c\times d}$ and coefficients $\vz\in\R^c$ such that (i) $c\gg d$ (overcomplete), (ii) $\mu(\mD)=\max_{i\neq j}|\mD_i\mD_j\T|\le\varepsilon$ with unit rows (quasi-orthogonal), (iii) $|\supp(\vz)|\le k\ll c$ (sparse).

In words: a representation is a sparse sum of a few nearly orthogonal feature directions drawn from a large list. This is the toy of §3.2 made precise. The formal statement, its three conditions decoded and its geometric motivation (Tammes, Thomson, spherical codes, Grassmannian frames) are on page 3. The hypothesis is useful because it can be turned into an inverse problem: if it holds, finding the concepts means finding $\mD$, which is the subject of §4.

The paper adopts the LRH "as a working baseline"; its later parts study what that baseline misses (page 4).
